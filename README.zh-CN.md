# 小球对决 · ORB DUEL

## 手动技能对战（PC）

打开 **[manual.html](manual.html)**，或从现有模式页进入。玩家可选射手、普通、吸血、陷阱、毒液、激光、回旋、时间球，敌方可选任意现有角色并保持自动AI。射手保持原操作：鼠标瞄准，左键完整一轮，觉醒后右键选狙击/散射（仍需满校准）。满足原奥义条件时左右同按，沿光标方向执行合法侧闪并消耗奥义。闪后一秒内左键启动原1.08秒穿甲蓄力，蓄力时鼠标瞄准，末0.16秒锁定；不点则失效且不发射。射手不再使用E/WASD控制奥义。双方仍自动运动，普通WASD不能移动。原自动模式、伤害、冷却及音效保持不变。见[规则、隔离、备份与验证](docs/design/MANUAL_MODE.md)。

普通球：左键在真实擦肩机会追击，右键准备满拳势重击。吸血球：左键追猎（血海中改为逐次放血浪），右键血契。陷阱球：左键在本体位置布雷，右键与鼠标选中节点置换。这三球左右同时按使用奥义，陷阱球则切换碰撞触发待命。保留原冷却、资源与技能演出，F切换专用全屏战斗布局。

## 动画回看

三个模式均可按 **V** 暂停并回看最近约20秒画面：方向键逐帧，Shift+方向键跳10帧，按钮跳回5秒/10秒，拖动时间轴定位，支持¼×/½×/1×慢放。回看中空格播放/暂停回看，V返回原暂停位置；随后空格继续对局。静音回看不重复结算战斗，重开清空缓存。缓存的是实际显示帧（最高800像素宽），有64 MiB预算，复杂场景可能不足20秒，高倍速不补帧。详见 [实现与限制](docs/design/ANIMATION_REVIEW.md)。

## 当前调整（20261017-poison2）

毒液球身体碰撞施毒新增按“施毒者→敌人”独立计算的1.2秒世界时间冷却；冷却内正常碰撞伤害、原满毒引爆照常，但碰撞不会额外叠毒或刷新毒持续时间。换一个敌人有独立计时，毒池和毒液弹不受此计时影响。完全被盾/无敌抵消的碰撞不消耗施毒冷却。重开清空计时；时间球奥义使敌方进入完整CD时也包含此冷却。

## 最新：腐生·万毒缓蚀（20261017-venom1）

毒液球独立奥义模式生命 **220**，经典/团队仍 **112**。首次真实生命降至30%自动激活，无需觉醒，每局一次；跨阈值攻击只立即扣到30%，所有溢出及随后应承受的生命伤害转入伤害池。池每0.5秒结算剩余量20%，最低1且不超过余量；池清空后仍永久接纳新伤害。例：220生命承受200伤害，立即降到66，余46入池，随后先扣9.2、再扣7.36。既不回血也不无敌，大池可以在第一跳直接致死。

原护盾先正常吸收，已经入池的伤害不再被后续盾减免；慢扣不递归入池，不二次触发吸血/反伤。原有毒池、毒液弹、毒爆与伤害数值保留，运动和施毒不中断。时间回溯仍恢复位置/生命及历史奥义资格，但不会抹掉已经承诺的伤害池。常驻缓蚀按既有奥义规则免受时间减速和沉默；没有额外位移保护。

激活会快速鼓胀，黑绿色裂纹与内部液面随池量加强；每次慢扣同步裂纹闪烁和低沉腐蚀脉冲。血条用斜纹标记当前生命中待扣的部分，面板分别显示待结算量、下跳量与致死风险；超过现有生命的池量仍在数字中完整显示，不伪装额外血量。

## 最新规则（20261017-rewind3）

- **离场**：血海从液化至血柱启动显形前没有可选中/受击本体。敌方射击、脚下放置时间领域等需要锁定的主动攻击保留就绪状态，待其返回；已蓄势且仍依赖锁定的释放也等待。陷阱、毒池等自主布置继续运行，离场身体不会触发陷阱或被领域侵蚀。血柱冲天、身体出现和展翼同时开始，才恢复受击；血池随漩涡以带潮汐起伏的圆形收尽。血浪只累计待回血量，显形并出现总回血字时才统一恢复血条。蝙蝠追猎一次8基础伤，按原吸血规则治疗。
- **时间球**：奥义模式生命与上限215，经典/团队仍120；领域每0.5秒2基础伤，运动时间10%，技能冷却/装填/充能按70%流逝（延缓30%），飞行时钟保持1.2秒沉默，正在充能/等待的攻击额外延后1秒。时间减速、冷却延缓与沉默对奥义中的敌人无效，护盾球、反伤球除外。

## 角色完整循环

- **毒液球：铺毒 → 叠层 → 引爆 → 再铺毒。** 碰撞也会上毒；触池有独立叠层节奏，满层再撞引爆但保留一层，并结算部分剩余毒伤。觉醒后毒池也能引爆，共用冷却，不能因为两片重叠池连续爆炸。上方显示每层毒伤、毒爆、引爆 CD、留池 CD 与池数，对手状态栏显示层数 / 剩余时间。
- **加速球：积速 → 高速强撞 → 击退 → 撞墙追击 → 恢复。** 强撞需双方的法向接近速度 ≥430、自身迎撞速度 ≥250，且造成实际生命伤害；沿接触法向施加 40～145 的额外速度，使敌人失衡 0.7 秒。失衡后的首次撞墙消耗窗口，法向撞墙速度需 ≥160；追加伤害为 0.75×0.5×敌人质量×撞墙法向速度²/18000 ×加热，基础上限 9，速度不足 160 不伤。普通撞墙不扣血；普通强撞只有实伤才有追击，觉醒冲撞的动量仍可穿过护盾，但伤害继续由盾抵消。上方显示实际速度、动能增伤、巡航速限、恢复和无敌 / 冷却时间，对手显示失衡状态。
- **回旋球：投出 → 去程留印 → 回程斩印 → 接回 → 近战重击。** 去程锁定施放时的预判终点，最大射程 230，基础沿 0.65 秒、觉醒沿 0.58 秒曲线飞出；随后曲线返程、有限转向追随主人，2.8 秒没接回则消失。每程对同一目标限命中一次；去程实际扣血留下 3.2 秒刃印，回程伤害 ×1.5 后消耗。盾完全吸收时不留印、不消耗印记。接回后的八秒内可兑现近战重斩；完整接回 +40%，部分接回仍有 +20% 较弱奖励。上方显示刃伤、回斩基准、武器是否在外、接刃强化和投掷 CD；一次投掷最多返还 0.35 秒。
- **普通球：接触 → 攒拳势 → 重拳 → 拳劲追击。** 盾接触只积半格，重拳只在有效碰撞时消耗；觉醒后的拳劲沿碰撞方向短程飞行、每目标只命中一次，不会追踪或无限穿透。
- **吸血球：留血印 → 积血能 → 等待距离 → 血契脉冲 → 收束。** 范围外不花冷却；发动和每次脉冲都消耗血能，链伤不反向补资源。完整七跳才消耗血印收束，断链按缺失连接时长有限返还。
- **护盾球：开盾 → 承伤积压 → 盾击或破盾释放。** 压力来自实际吸收值，碰撞盾击与觉醒压力波共享同一份资源；一旦兑现即清空，无法用一次承伤触发两次伤害。
- **射手球：三连点射 → 命中校准 → 装填空窗 → 枪阵展开 → 后坐突击。** 校准来自有效命中并会过期；满校准在装填时转化为下一弹匣，每轮重新预瞄，中心弹保留可靠输出，侧弹覆盖；重弹按自身弹速独立预瞄，产生实际后坐，随后承担更长装填。普通落空不返还。
- **激光球：充能 → 短暂跟踪 → 锁线预警 → 开火 → 散热。** 充能可被接触有限干扰，锁线后方向固定；觉醒保留精准主炮，再追加有限扫射余波和推动，不按渲染帧重复扣血。
- **反伤球：预警 → 镜面姿态 → 截弹 / 返伤 → 空窗 → 反击刃。** 姿态外没有反伤；镜片把子弹、反击弹、飞刃、时钟、毒液弹、破片沿来路折返并保留能力。折返弹和反击刃都带防递归标记，不能再次截获、反伤或蓄能。
- **陷阱球：布节点 → 结感应线 → 触线起爆 → 延迟传播。** 节点被拆立即断线；觉醒连锁逐跳进入队列，桥接节点在起爆前被拆可截断后续传播，并用命中预算防止同一目标吃满整网。

球的常驻扩散光晕移除，球面渐变与清晰轮廓保留，**原来的小球拖尾绘制完全保留**。状态轮廓、护盾、蓄势和命中瞬间特效继续作为技能反馈。新增毒爆刺裂、法向冲击线、墙面裂纹、回刃斩线与接刃反馈；毒爆、撞墙追击、完整接刃各有专属音色。

## 衰减冲撞与场地稳定

觉醒冲撞先预警 0.7 秒，再沿锁定方向以 900 起速。速度按 `900 × exp(-0.95 × 经过秒数)` 连续衰减，到 `max(275, 发动时巡航速度 + 20)` 或最多 1.5 秒结束；撞墙只镜面反弹方向，不停止冲撞、不重新锁敌。期间免疫攻击，首个有效敌人接触立即结束冲撞并恢复普通移动，不会让球永久静止。同一冲击步的敌人普攻和反伤仍按冲撞无敌处理，下一步恢复可受伤。即使接触处于碰撞冷却中，也结束冲撞，但不能重复伤害或刷返还。

觉醒冲刺命中采用18点基准伤害，保留种子浮动和加热，普通碰撞仍走巡航动能与蓄力规则。物理引擎沿法向传递动量，敌人保留 1.1 秒惯性 / 撞墙追击标记；撞墙伤害取墙面法向速度的动能，斜擦墙比正面撞墙轻，最多结算一次，基础伤害上限 9。贴墙命中的碰撞和墙伤可在同一步公平结算；护盾可以抵消两段伤害，无敌目标不获得追击标记。每次冲撞结束巡航速度回落到82%，上限285、下限205；命中有0.6秒恢复标记。只有自然耗尽且全程没接触敌人才返还最多10点实际损失的巡航速度，下一轮冲刺冷却另返还2秒；命中或中断不返CD。

结束时缩场的原因是结果栏被计入竞技场的高度预算，现在结果栏独立占位，准备 / 战斗 / 暂停 / 结束 / 重开采用相同场地尺寸。宽屏改为双方侧栏夹着场地，场地与球仅做显示层等比例放大，逻辑场地仍为 360×340、球半径 23，原来的小球拖尾保持不变。

## 结算与相互作用

同一步攻击先快照、同时结算：先盾再血，然后一次反伤，最后存活的吸血球治疗。过量伤害按各攻击比例分配，消除顺序偏差；双方同时阵亡判平局。

反伤不减免承受的伤害，仅在姿态中返还实际扣血。完全抵消的伤害不反弹、不蓄能。返还不能递归；反击弹也不能触发二次反伤或蓄能。觉醒后新进入的姿态采用延长时长，正在进行的姿态不回拨计时。

子弹 / 光束可拆除敌方已布防陷阱，拆除不爆炸；子弹同时消耗，按扫掠路径上先碰到的对象判定。飞刃返程碰到主人会回收，不伤自身，未接住则过期。重叠毒池共用叠层计时，不会一帧叠满或重置脉冲；离池后至少保留 1.5 秒中毒，碰撞上毒可延长到 3 秒，上方显示层数和剩余时间。满毒引爆用固定伤害，可被护盾 / 无敌抵消，不能无限连爆。技能共用护盾、无敌和一次反伤规则。

## 运动与反馈

场地 360 × 340、球半径 23，网页中同比例放大。固定步长 1/240 秒，墙面仍按法线镜面反射；球间沿中心连线的法向施加弹性冲量，按质量交换动量，切向速度保留。撞后惯性约 0.8 秒逐渐回到巡航速度，保留方向，避免立刻抹掉击退。正常短时速度上限 800，冲刺上限 900。没有长期不碰撞后的轨迹偏移。冲刺发动时沿预警方向转向，期间正常反弹、不追踪。

经典、团队与奥义模式的加速球觉醒冲刺统一基准18伤害（原±20%种子浮动、加热及防御照常），普通身体碰撞不变；奥义起手复用该冲刺。蓄力时以4.5弧度/秒有限速跟瞄，末0.12秒锁定。麻痹除既有枪械/激光/时钟外，也作用于普通追击、追猎、飞刃、彗星、盾波、落雷/魔爪落点和活体毒液的方向修正；区域、随机布置及已锁定/已发射的不追踪攻击不会被额外强行改向。奥义瞄准独立豁免，射手奥义通过Aim.track的arcana参数明确声明；不因此解除时间减速或改变普通技能沉默。

### 2026-10-18 激光短喷与免伤
觉醒激光球预判未来0.12秒的敌方身体接近，额外留20单位余量；短喷侧移0.16秒、名义速度520、冷却8秒，消耗6%电容，结束后仅预测可命中时出光刃反切、消耗8%。未觉醒光刃仍15%。子弹、时钟和陷阱只触发光刃，不触发短喷。短喷没有无敌，保留真实碰撞、墙和障碍限制；沉默可以打断、时间减速继续生效。必要时可中止主炮瞄准并保留电容；主炮持续扫射期间不短喷。

新增通用“免伤”：所有收到的伤害减少30%，在盾吸收前只计算一次，穿盾、反伤及持续伤害同样适用；不会把免伤误当作无敌。激光球奥义全程免伤30%，保留原挥斩前0.14秒无敌，正常收招后短喷CD清零、下次短喷免费，后续光刃仍需电容。吸血追猎改为觉醒前后均可用，保留连续6秒无印与10秒CD。常规机制同步经典、奥义、团队，模式专属奥义不迁移到旧团队模式。

定点验证：`node tests/verify-laser-jet.cjs`、`node tests/verify-laser-blade.cjs --quick`、`node tests/verify-blood-hunt.cjs --quick`。追猎快速检查跳过已过时的历史快照比较和完整对局回放；光刃快速检查跳过两局长模拟。见[设计与表现检查](docs/design/experiments/laser-evasion.md)。
