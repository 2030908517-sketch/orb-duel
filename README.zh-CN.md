# 小球对决 · ORB DUEL

[English](README.md)

完全本地运行的 Canvas 2D 自动对战游戏。十种小球可任选，包括同种对决；无需联网、安装依赖或构建。

## Windows 启动与操作

完整解压 ZIP，进入包含 `index.html` 的项目文件夹（GitHub 下载通常为 `orb-duel-main`，本地打包为 `orb-duel`），双击 `index.html`，用 Edge、Chrome 或 Firefox 打开。保留整个文件夹结构即可，不需要服务器或 Node.js。

- 主按钮开始 / 暂停 / 继续，页面空白处空格键也可操作。
- ↺ / R 完整重置同种子，回到准备状态；“新种子，再来一局”生成新种子并开场。
- 1× / 2× / 4× 改变模拟时间流速，不改变规则；喇叭按钮控制音效。
- 对局中配置锁定，打开规则或切后台自动暂停。暂停 / 静音 / 重开立即停止当前声音。

## 角色完整循环

- **毒液球：铺毒 → 叠层 → 引爆 → 再铺毒。** 碰撞也会上毒；触池有独立叠层节奏，满层再撞会消耗毒层。觉醒后毒池也能引爆，共用冷却，不能因为两片重叠池连续爆炸。上方显示每层毒伤、毒爆、引爆 CD、留池 CD 与池数，对手状态栏显示层数 / 剩余时间。
- **加速球：积速 → 高速强撞 → 击退 → 撞墙追击 → 恢复。** 强撞需双方的法向接近速度 ≥430、自身迎撞速度 ≥250，且造成实际生命伤害；沿接触法向施加 40～145 的额外速度，使敌人失衡 0.7 秒。失衡后的首次撞墙消耗窗口，法向撞墙速度需 ≥160；追加伤害为 0.5×敌人质量×撞墙法向速度²/18000 ×加热，基础上限 12，速度不足 160 不伤。普通撞墙不扣血；普通强撞只有实伤才有追击，觉醒冲撞的动量仍可穿过护盾，但伤害继续由盾抵消。上方显示实际速度、动能增伤、巡航速限、恢复和无敌 / 冷却时间，对手显示失衡状态。
- **回旋球：投出 → 去程留印 → 回程斩印 → 接回 → 近战重击。** 去程锁定施放时的预判终点，最大射程 230，沿 0.72 秒曲线飞出；随后曲线返程、有限转向追随主人，2.8 秒没接回则消失。每程对同一目标限命中一次；去程实际扣血留下 3.2 秒刃印，回程伤害 ×1.5 后消耗。盾完全吸收时不留印、不消耗印记。完整接回后 3 秒内一次近战 +40%；双刃任一过期就失去这次完整回收奖励。上方显示刃伤、回斩基准、武器是否在外、接刃强化和投掷 CD；一次投掷最多返还 0.35 秒。
- **普通球：接触 → 攒拳势 → 重拳 → 拳劲追击。** 盾接触只积半格，重拳只在有效碰撞时消耗；觉醒后的拳劲沿碰撞方向短程飞行、每目标只命中一次，不会追踪或无限穿透。
- **吸血球：留血印 → 积血能 → 等待距离 → 血契脉冲 → 收束。** 范围外不花冷却；发动和每次脉冲都消耗血能，链伤不反向补资源。完整七跳才消耗血印收束，断链按缺失连接时长有限返还。
- **护盾球：开盾 → 承伤积压 → 盾击或破盾释放。** 压力来自实际吸收值，碰撞盾击与觉醒压力波共享同一份资源；一旦兑现即清空，无法用一次承伤触发两次伤害。
- **射手球：三连点射 → 命中校准 → 装填空窗 → 过载重弹。** 校准来自有效命中并会过期；满校准在装填时转化为下一弹匣，末发重弹后承担更长装填。普通落空不返还。
- **激光球：充能 → 短暂跟踪 → 锁线预警 → 开火 → 散热。** 充能可被接触有限干扰，锁线后方向固定；觉醒重炮只有三次伤害预算，不按渲染帧重复扣血。
- **反伤球：预警 → 镜面姿态 → 截弹 / 返伤 → 空窗 → 反击刃。** 姿态外没有反伤；镜片把普通实体弹沿来路折返。折返弹和反击刃都带防递归标记，不能再次截获、反伤或蓄能。
- **陷阱球：布节点 → 结感应线 → 触线起爆 → 延迟传播。** 节点被拆立即断线；觉醒连锁逐跳进入队列，桥接节点在起爆前被拆可截断后续传播，并用命中预算防止同一目标吃满整网。

球的常驻扩散光晕移除，球面渐变与清晰轮廓保留，**原来的小球拖尾绘制完全保留**。状态轮廓、护盾、蓄势和命中瞬间特效继续作为技能反馈。新增毒爆刺裂、法向冲击线、墙面裂纹、回刃斩线与接刃反馈；毒爆、撞墙追击、完整接刃各有专属音色。

## 衰减冲撞与场地稳定

觉醒冲撞先预警 0.7 秒，再沿锁定方向以 900 起速。速度按 `900 × exp(-0.95 × 经过秒数)` 连续衰减，到 `max(275, 发动时巡航速度 + 20)` 或最多 1.5 秒结束；撞墙只镜面反弹方向，不停止冲撞、不重新锁敌。期间免疫攻击，首个有效敌人接触立即结束冲撞并恢复普通移动，不会让球永久静止。同一冲击步的敌人普攻和反伤仍按冲撞无敌处理，下一步恢复可受伤。即使接触处于碰撞冷却中，也结束冲撞，但不能重复伤害或刷返还。

冲撞伤害系数为 `0.65 + 0.85 × (瞬时速度 / 900)²`，另计入巡航动能增伤、蓄力、种子浮动和加热。物理引擎沿法向传递动量，敌人保留 1.1 秒惯性 / 撞墙追击标记；撞墙伤害取墙面法向速度的动能，斜擦墙比正面撞墙轻，最多结算一次，基础伤害上限 12。贴墙命中的碰撞和墙伤可在同一步公平结算；护盾可以抵消两段伤害，无敌目标不获得追击标记。冲撞碰到敌人后消耗 12 巡航速度、恢复 0.6 秒；只有耗尽且全程没接触敌人才返还 1 秒 CD。

结束时缩场的原因是结果栏被计入竞技场的高度预算，现在结果栏独立占位，准备 / 战斗 / 暂停 / 结束 / 重开采用相同场地尺寸。宽屏改为双方侧栏夹着场地，场地与球仅做显示层等比例放大，逻辑场地仍为 360×340、球半径 23，原来的小球拖尾保持不变。

## 机会补偿与平衡

只针对依赖接触或投入较大冷却的能力提供有限补偿；击中护盾 / 无敌属于有效对抗，不能当作“空放”刷返还。

| 球种 | 补偿规则 |
|---|---|
| 普通 | 6 秒未造成实际伤害后，每秒碰撞蓄力 +3%，最多 +30% |
| 加速 | 同为 6 秒，每秒 +2%，最多 +20%；觉醒冲刺全程无接触返还 1 秒冷却 |
| 护盾 | 8 秒后每秒 +2%，最多 +16%；只增加碰撞攻击，破盾波不享受蓄力 |
| 吸血 | 敌人不在 220 范围内时等待，不消耗血能与冷却；发动后断链按缺失连接时长返还最多 1.2 秒，完整连接不返还 |
| 激光 | 连续两次既未命中也未拆雷，返还 0.6 秒；有效命中或拆雷清空计数 |
| 回旋 | 真正接回飞刃返还 0.35 秒；觉醒双刃同次投掷只返还一次；过期不返还 |
| 陷阱 | 未触发陷阱自然到期返还 0.4 秒；被拆除、超上限替换不返还 |
| 毒液 | 从未被敌人踩过的毒池自然到期返还 0.35 秒；被盾 / 无敌抵消仍算踩过，替换不返还 |
| 射手 | 普通弹匣 / 过载弹匣落空不返还 |
| 反伤 | 姿态与蓄能按真实受伤工作，防御空窗不返还、不凭空给反击弹伤害 |

蓄力在实际造成伤害时清空，完全抵消时保留；同一步双方攻击先快照，公平结算。返还只修改对应技能冷却，不增加伤害、技能持续时间或冲刺无敌。所有返还后至少保留 0.2 秒等待。上方显示蓄力、落空计数和累计返还 CD，倒计时是下一次发动的剩余时间；蓄力还有金色环形反馈。

本轮将普通、吸血、护盾、射手、激光、反伤和陷阱补成完整角色循环，并与已有毒液、加速、回旋机制统一平衡。两组共 8,000 局样本用于检查整体强度，完整逐配对统计见 `tests/balance-latest.json`；保留角色差异与克制。

## 结算与相互作用

同一步攻击先快照、同时结算：先盾再血，然后一次反伤，最后存活的吸血球治疗。过量伤害按各攻击比例分配，消除顺序偏差；双方同时阵亡判平局。

反伤不减免承受的伤害，仅在姿态中返还实际扣血。完全抵消的伤害不反弹、不蓄能。返还不能递归；反击弹也不能触发二次反伤或蓄能。觉醒后新进入的姿态采用延长时长，正在进行的姿态不回拨计时。

子弹 / 光束可拆除敌方已布防陷阱，拆除不爆炸；子弹同时消耗，按扫掠路径上先碰到的对象判定。飞刃返程碰到主人会回收，不伤自身，未接住则过期。重叠毒池共用叠层计时，不会一帧叠满或重置脉冲；离池后至少保留 1.5 秒中毒，碰撞上毒可延长到 3 秒，上方显示层数和剩余时间。满毒引爆用固定伤害，可被护盾 / 无敌抵消，不能无限连爆。技能共用护盾、无敌和一次反伤规则。

## 运动与反馈

场地 360 × 340、球半径 23，网页中同比例放大。固定步长 1/240 秒，墙面仍按法线镜面反射；球间沿中心连线的法向施加弹性冲量，按质量交换动量，切向速度保留。撞后惯性约 0.8 秒逐渐回到巡航速度，保留方向，避免立刻抹掉击退。正常短时速度上限 800，冲刺上限 900。没有长期不碰撞后的轨迹偏移。冲刺发动时沿预警方向转向，期间正常反弹、不追踪。

接触分离后才能再次攻击，冷却 0.22 秒，墙边交替投影保持分离和边界。暂停冻结所有运动、伤害、技能、实体与特效，结束后停止结算。60 秒起伤害渐增至 2.5 倍，150 秒起每秒流失 3 HP，无视盾 / 无敌，不吸血 / 反伤，保证极端轨迹结束。

血条上方始终预留攻击 / 速度、六个技能数值槽、觉醒与临时状态。没有临时状态时显示“正常”。宽屏侧栏两列高度 111px、中等窗口四列高度 60px、561～700px 三列高度 81px、手机两列高度 111px；切球种、中毒结束、技能就绪和觉醒不会改变血条或竞技场位置。宽屏将左方状态 / 配置和右方状态 / 记录移到场地两侧，释放上方高度；窄屏将状态放回场地上方。竞技场按窗口剩余高度同比例缩放，最大显示宽度 1080px，计时、倍速和操作按钮留在首屏；结算栏在侧栏 / 场地下方独立显示，不挤小场地，控制按钮也预留最长文案宽度。能力详情默认折叠，点击即可展开。缩放不改变物理场地或球与场地的比例。

| 激光 | 双菱形收束预警、三层重炮光束、命中裂光 |
| 毒液 | 腐蚀释放阵、毒池旋流与实际毒伤脉冲 |

觉醒特效与技能结算分离。释放有音效，实际扣血才触发伤害命中特效；完全吸收时显示防御反馈。关键文字位于场外血条上方，不遮住场内。59 种本地合成音色，最多 8 个并发，倍速限流合并，优先重招声音，避免普通碰撞音同时叠加。系统“减少动态效果”关闭震动与压缩；表现层随机数独立，不影响战斗复现。

## 开发验证

正常玩不需要 Node.js。已有 Node.js 时在本文件夹运行：

```text
node tests/verify-engine.cjs
node tests/verify-world.cjs
node tests/verify-awakening.cjs
node tests/verify-mechanics.cjs
node tests/verify-feedback.cjs
node tests/verify-spectacle.cjs
node tests/verify-recovery.cjs
node tests/verify-characters.cjs
node tests/verify-dash.cjs
node tests/verify-roster.cjs
node tests/measure-balance.cjs 40 acceptance
node tests/measure-balance.cjs 40 holdout
```

第一项跑 100 个有序组合 ×40 种子，共 4,000 局，逐步验证物理、伤害、结束冻结与多帧率 / 倍速复现。其余专项覆盖技能边界、拆雷、暂停 / 重开以及表现层不影响战斗。`verify-roster` 分三批覆盖 30 / 25 / 26 项角色定点边界，并对 100 个有序组合执行共 411,746 项生命期、资源、命中预算和结束冻结检查。`verify-dash` 另外覆盖 945 项衰减反弹、命中截停、无敌、动量 / 动能墙伤、贴墙 / 角落、冷却、暂停与重开边界。

`verify-spectacle` 在当前规则下对照 300 局开启 / 关闭觉醒表现，检查战斗结果完全一致、特效上限与暂停 / 重开。`verify-recovery` 专项验证 111 个补偿边界，覆盖一次返还、上限、完全吸收、双刃回收、暂停重开等。`verify-characters` 覆盖 63 个角色边界：实际扣血上毒、叠层时钟、满毒消层和共享冷却；法向动量 / 能量 / 切向保留、击退消耗、一次撞墙；弧线去回、印记互斥、回收资源、暂停 / 重开、固定属性槽、光晕移除和原拖尾保持。平衡统计另用 80 个种子 ×100 有序组合共 8,000 局，含独立的 holdout 种子组；总体得分为胜局加半数平局占比，不代表每个对手的胜率。

浏览器打开 `tests/roster.html` 查看九个新角色机制的真实战斗帧，成图为 `preview-roster.png`；`tests/dash.html` 查看连续墙反弹、命中截停和动能追击；`tests/theatre-ui.html` 检查 11 种窗口的准备 / 战斗 / 暂停 / 结束 / 重开尺寸一致。`tests/audio.html` 验证 59 种声音波形并试听；`tests/feedback-ui.html` 验证真实界面；`tests/status-stability.html` 验证桌面 / 320px 窄屏在中毒出现、结束和觉醒时场地位置固定。`tests/compact-ui.html` 验证六种窗口尺寸、十种球的属性显示与完整操作区。最新记录见 `VALIDATION.md`。

同球种、左右、种子在本版本内复现；更新规则后，旧版同种子结果可能变化。属性经过批量样本初步平衡，保留明显克制，不承诺每个配对都为 50% 胜率。
