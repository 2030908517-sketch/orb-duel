# 单体血刃小样

目标：锐利、危险、绷紧的液体弧刃。先判断单体造型与形成/挥出动作，再决定是否用于技能。当前只运行独立小样，不修改正式玩法或既有三球演出。

造型：一片连续弧刃，凸刃朝右；深红主体、局部绯红刃锋、向后撕散的血流。保留负空间和不均匀明暗。拒绝双叶片、奶油粉色、等宽白描边、中央白棍、圆环烟花。

动作：刃锋局部显形 → 血体沿不同位置凝聚 → 短暂保持完整刃形 → 加速挥出、尾部滞后 → 不规则破散。图形从一开始就使用最终显示尺寸，不从小图整体等比例长大。形成和消散使用纹理引导的遮罩，尾部进行局部 UV 扭曲。单体观感先审，不在本小样添加声音掩盖动作问题。

参考：用户提供的血刃截图为视觉方向；本次查阅 [Geri 的 Electric Red Slash/原效果分解](https://realtimevfx.com/t/electric-red-slash/18973)，借鉴主体与纹理/遮罩职责分离；[Christiane La 的 Trails 制作说明](https://christianela.artstation.com/projects/lRr8zG)，借鉴手绘纹理配合 dissolve 的工作方式。只读取可访问说明，没有宣称观看嵌入视频。采用的是这些制作原则，不复制作者素材。

`blood-blade-v1.png` 由内置 imagegen 新生成，透明 RGBA，1536×1024。原生成文件保留在 Codex generated_images 中，本地副本为实际使用素材。完整生成提示见 `prompt.txt`。没有使用第三方游戏素材作为运行资源。`asset.js` 内嵌同一 PNG 的字节，用于本地文件模式的 WebGL 纹理，避免文件来源限制；没有另做素材加工。

本次检查：Edge 下本地文件/HTTP、1360/390 宽视口、暂停、录制锁定和 WebM 解码通过；已检查完整造型、六阶段有序帧、实际录屏解码帧、浅色透明底和小球比例。浅色底未见黑色底框；局部先显刃锋，血体补入，尾部后续破散。仍保留纹理细节偏密、小尺寸暗部不够突出的问题，尚未做真实对局适配；这是待审单体样品，不宣称最终品质通过。无音效，不做听感评价。

直接双击 `index.html` 或由本地服务打开。需要支持 WebGL 的现代浏览器；未启动时显示完整单体造型，播放后才进行阶段动作。按钮提供暂停、重放、完整造型、实际比例、背景切换、PNG、WebM 与时间线导出。此页无伤害判定、无战斗模块和网络依赖。
