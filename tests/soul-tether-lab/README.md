# 灵魂与魂线机制实验（非正式规则）

入口：`index.html`，可直接打开，或经现有静态服务器访问 `/tests/soul-tether-lab/`。本目录完全隔离；正式入口不加载它，不改变恶魔球、伤害、版本或历史审计。

## 实验意图与临时规则

看懂“魂在独立运动、线被抽长、宿主在回收、恶魔接触线才能继续争夺”。这是可推翻的实验假设，不是新角色定案，不含伤害、Debuff、觉醒或奥义，也没有胜负条件。

- 同尺寸360×340场地、1/240秒固定步，直接加载正式 `config.js` 与 `physics.js` 的基础运动、限位、肉身碰撞；只在本页的独立全局环境运行。没有加载正式Engine、恶魔、技能或伤害模块。
- 肉身与恶魔按原弹墙/弹性碰撞函数运动，无生命/伤害回调；灵魂半径14，独立速度与方向，无质量、不挡肉身、不调用球间接触；只与外墙反弹。
- **L=已抽取长度**是独立账本，单位为实验场地单位，范围0～上限。**d=肉身到灵魂中心距离**由坐标测量。靠近不会令L减少或归零。
- 抽离按钮令灵魂从肉身位置开始、以固定种子方向运动，L设为初始抽取量；初始已有线接触不记夺魂，须离开后再次接触。
- 有效触线期间每世界秒抽取 `拉扯速率`，宿主持续以 `回收速率` 收回。持续接触按时间算，不按帧数或进入次数发奖。L到0无伤归魂；满额只封顶，不触发处刑、伤害或胜负。
- 当d>L，使用弹簧加速度把魂往肉身拉：`a = 扯魂强度 × (d-L)`；只改变魂的运动，不推肉身。魂速受上限约束，L不会因拉伸自动增加。这个单向软约束是本实验的可调假设，不代表正式抽魂规则。
- 当L>d，线用连续弧线表现松弛（弯曲量有限以保持可读性）。**弧线弧长不严格等于L**，L是抽取进度而非完整绳模拟；d、L与拉伸量同时显示。接触检测与绘制共用同一折线，避免画弯线却判直线。
- 魂线两端各排除14单位，避免贴着肉身/魂就被当作触线；对固定步内的球和线做插值采样。接触阈值=恶魔半径+可调容差，不使用整屏命中。
- 参数热调立即生效；改变初始长度/种子须重置。暂停时可单步和拖动恶魔，但拖动不在暂停中产生夺魂，继续后按真实当前位置结算。

## 操作

默认自动运行、自动抽离。拖动红色恶魔可以试探魂线，也可勾选“恶魔跟随光标”（按目标速度移动，不瞬移）；关闭则自动反弹。空格暂停/继续，N推进一帧（1/60秒、4个物理步），R同种子重置。按钮可重新抽离、切换预设、导出参数/时间线JSON。预设包括平衡拉扯、快速回收、容易接触、零回收观察；均是机制观察配置，非角色平衡结论。

“固定肉身”可隔离魂运动；“暂停回收”只用于观察进度不随d变化。参数包括三者运动速度、魂速上限、回收、拉扯、弹簧、容差、初始量与上限。图表记录最近12世界秒L与d，接触变色，日志记录接触开始/结束、抽离/归魂和调参，导出包含参数变化与固定种子。

## 表现依据与边界

沿用已审阅的正式 `demon-render.js` 魂外相和魂线：淡蓝半透明宿主轮廓、暗底细亮线；触线段红色强调、魂身没有HP条。沿用 `docs/design/experiments/demon-soul-01.md` 的TetherGeist连接层级参考及已确认代码2D锚点，本次没有新魔爪、法阵、粒子或声音，不新造演出语汇。调试色和图表只用于测量，不能当作最终美术验收。没有新音效，也无试听结论。

## 自动检查

在正式项目目录运行 `node tests/soul-tether-lab/verify.cjs`。覆盖长度/距离解耦、回收、持续触线与帧率、出生重叠基线、端点排除、单向弹簧、独立魂运动与边界、固定种子复现、暂停/重置、无伤害与正式文件隔离。浏览器观察证据另见本目录 `REVIEW.md`。
