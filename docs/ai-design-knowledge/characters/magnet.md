# 磁力球 magnet

116HP/8.8身体基伤/210速度/质量1.35，各模式一致；**无独立奥义/手动玩家**。来源：[magnet.js](../../../js/magnet.js)全部、[flyers.js](../../../js/flyers.js) `physical`、[team-runtime.js](../../../js/team-runtime.js)。

| 能力 | 触发/流程 | 数值、限制与伤害 |
| --- | --- | --- |
| 极性脉冲 | 首次2.4、每5.8，从0.28预警结束时距离重判 | 距目标>132吸，否则排；吸径向期望690、排780，替换当前径向分量、保留切向；惯性1.25/drag1.3，限速后实际速度不必等于配置。目标强制位移并非通用吸引力场/追踪 |
| 吸引迎撞 | 1.25秒来源标内目标身体碰回同源磁力球 | 只额外伤敌，基于目标迎撞速≥160：min(18,0.5质量×速度²/18000)×标记时热度；不替代双方原身体交换 |
| 排斥墙伤 | 标期首次墙撞法向速≥160 | 上式能量×0.75，最高13.5×热度；归orb可反伤。消标只一次，不角落无限刷 |
| 吸偏撞墙 | 吸标期首次墙撞 | min(7,能量×.4)×.75×热度，最高5.25，wall来源不可反伤；不是撞墙就算吸回自己成功 |
| 吸偏补偿 | 本次标窗口结束未发生与自己的有效身体接触 | 下次吸力+12%至36%，并减目标切向残余（最多75%）改善吸回；接触重置；墙伤仍可能获得下轮补偿 |
| 飞行物偏转 | 脉冲时半径270内通用实体对象 | 影响projectiles与timeClocks中的shot/counter/boomerang/venom/shard/comet/旧实体血刃等；改径向、武器速上限720；飞刃0.32强制偏转后接回曲线。激光/光柱/领域/魂影不在此表，`noMagnet`穿甲弹例外；非实体活毒也未在遍历表 |
| 觉醒磁极过载 | 醒后0.6首次，11周期，0.35预警 | 锚定本体静止，760吸维持0.5（重施力）→900排；仍走普通限速/动能标，普通脉冲至少后移2秒；没有给本体全程无敌。沉默会取消锚定 |

普通force拒绝幽灵/冲刺/部分奥义不接触形态；霸体不吃冲量。排/吸决定的是径向速度，不是把球扔向精确自己中心；所以有切向偏差及补偿。磁力本体目标force没有通用270距离过滤（270明确用于飞行物），不要把视觉脉冲半径直接当本体受力射程。团队包装只影响敌方武器，1v1通用遍历也可能偏转自己的飞行物（若场上有）。

**联动/设计含义**：真正收益由冲量后路线、法向墙速与1.25标时限决定；高质量本体身体交换也有差别，但墙伤用受撞目标质量。吸力越来越大改善切向而非无条件必中。强制撞墙与反伤的归因按具体包判，不能统一称“墙伤都不反”。多目标/障碍下实际吸回率待测，不宣称全局克制射手。
