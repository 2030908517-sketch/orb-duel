# 星辰球 orbital

120HP/8.3身体基伤/215速度/质量1；代码键仍`orbital`，显示名星辰球；**无独立奥义/手动玩家**。来源：[stellar.js](../../../js/stellar.js)全部、[world.js](../../../js/world.js)彗星路由、[magnet.js](../../../js/magnet.js)。

超新星是**常规觉醒技能**，不是独立低血奥义。本体召回/坍缩/核态没有额外免伤/无敌，仍受伤；沉默可中断准备，已飞出彗星并不一起消失。返回速度900与公转能量时间不能混写成所有动作受相同倍率；实际返回分支用世界dt。

内部体系：在轨能量决定投射性能，等待伙伴换共振机会；发射空窗→真实回收→再充。超新星先收武器暂缓普攻，再扩环、重生发散，恢复普通循环。原星轨球挡弹、护主星能、双星阵/交汇光束**已不在当前Stellar执行器**；Cosmic残余字段不代表保留。

设计含义：彗星反弹但会超次数/时间返回；不能直接估“每5.4秒三发”忽略回收时间。重生三方向是真实弹，不保证三颗打同敌；一轮两颗实伤的频率与障碍下回归可靠性待实战，未做全局平衡结论。
