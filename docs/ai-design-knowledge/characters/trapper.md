# 陷阱球 trapper

114HP/9.2身体基伤/210速度/质量1.1，独立奥义232HP。来源：[mines](../../../js/mines.js) 全部、[world](../../../js/world.js) `placeTrap/clearTrap/update`、[trapper](../../../js/trapper.js)全部、[awakening](../../../js/awakening.js) `trapOptions`。

| 能力 | 触发/时机 | 参数与边界 |
| --- | --- | --- |
| 自动布雷 | CD就绪且本体位置合法、离己方现有节点≥70 | 未醒2.1秒/上限5，醒后1.45秒/7；半径12、布防0.55、爆半径45、伤4.2 roll（布置时快照）。**寿命Infinity**，满额回收最早id，不能重叠；找不到位置保留CD就绪等走远 |

| 直接踩雷 | 实体敌人接触布防节点 | 立即爆炸，不等待捕获；非虚化 |
| 捕获牵引 | 穿线选择近端节点，动态线用其端点 | 0.3秒，以2500/目标质量加速度拉；仍正常反弹运动/可被霸体挡；结束只在目标进入爆炸半径时炸，否则保留节点、0.6秒禁止重捕，失败延长下次0.05/0.1秒，上限0.4捕获 |
| 连锁与破片 | 节点爆炸 | 同主节点85内已布防近邻且自身范围有敌才预约0.09秒连锁；到期复查，敌已走则取消保留。共享0.8秒链，每目标最多2爆、原始预算8.5×热度，次级伤×0.5；每爆4片，速度310、半径2.5、射程180/寿命0.7、各0.45×热度，墙消失、不替代主爆 |

普通节点能被原子弹/主炮/光刃等合法清除；拆除不等于引爆；过期返0.4秒代码仍在，但Infinity普通节点不会自然走过期分支。

## 独立奥义：诡匣·替身收监

已醒HP≤30%，进入 `trapReady`不消耗；下一有效敌对身体接触优先代替双方此次身体伤害，才commit。两陷阱同时合格以种子随机选一个。

- 本体随机从20间距候选网格的较远合法区脱身；选距敌≥min(230,最远×.82)，无候选则不能触发，不传进墙/球/囚笼。
- 敌人困于128×120临时矩形3秒；它能运动/施法，外部本体也不能穿笼。不是沉默或无限挤压。
- 倒数结束一次18×热度炸弹包和强击退330基础，囚笼移除。不是支架/碎片多重伤害；仍尊重盾、无敌、反伤。
- 同时在本体附近找间距合格地点放唯一中枢：半径16、爆半径50、7.2 roll、0.3布防、寿命Infinity，计入7上限；满额移除最早节点。空间实在不足可以没有中枢，不能保证每次部署成功。
- 中枢和所有通视普通节点连线，不受180普通距离；不是穿墙全连。`Priority.protectedEntity`保护中枢，**普通拆除不能移除，奥义级切割可以**。旧设计“任何原合法拆除可清中枢/有限寿命”不是当前代码。

手动左键本体布置，右键选中节点换位；双键待命可开关，不是按即触发；不开不替身、碰撞才耗机会。普通置换不会抢先同tick奥义。

**闭环/设计含义**：更多节点增加路线捕获，不按数量直接乘DPS；预算限制同轮爆伤，破片另外计算。网络依赖身体/节点真实几何，不能假定玩家或AI会主动走入。密集网络与70间距/小场地有竞争，旧囚笼与中枢改写合法部署区。1v1与有柱团队的实际覆盖率待验证。
