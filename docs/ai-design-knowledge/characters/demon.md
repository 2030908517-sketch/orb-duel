# 恶魔球 demon

122HP/9.5身体基伤/215速度/质量1.1，各模式基础生命；**无独立奥义/手动玩家**。来源：[demon.js](../../../js/demon.js)全部、[adaptive.js](../../../js/adaptive.js)、[temporal.js](../../../js/temporal.js)。

| 能力 | 真实触发/时机 | 参数与限制 |
| --- | --- | --- |
| 地狱烙印 | 自己非沉默身体包生命伤或吸盾成功 | 留7秒、同源刷新、无DOT。与旧稿“必须HP伤”不同：`hit`判断actual+blocked>0 |
| 地狱魔爪 | 首次2.8、每6.3秒、未醒 | 0.55预警，最后0.20锁点；有限预测至0.7，从敌预测点前65附近生成，0.18伸爪、半径13、回撤；8×热度再独立±10%；真实扫到目标才伤 |
| 灵魂锁链 | 魔爪实伤且起手快照带印/当前仍有印/同轮已有链 | 锚在魔爪起点3.2秒，55松弛区；拉力随距离/径向速度变化，单链上限850、合力1200；不是冻结/瞬移，敌仍反弹，霸体抗牵引 |
| 普通处刑 | 早于当前tick建立的链，随后另一次有效生命伤，非同cast另一魔爪 | 消印，追加8×热度，最多一次；不立即解除剩余链，不刷新3.2期限；首爪不能自触发；纯盾不触发 |
| 自然断链 | 原到期且该cast未处刑 | 2.5×热度终结并消印；沉默/目标虚化/冲刺/离场等解除链不送终结伤 |
| 觉醒地狱之门 | 醒后0.8首轮、每10秒，替代普通爪调度 | 两相对边随机横/纵门，各6.5×热度±10%；间0.26，预警0.55/0.81、飞行0.30。合格同cast双锁形成后1秒处刑9×热度，普通处刑互斥；单cast每敌爪+处刑/终结原始预算22×热度 |

敌非带印仍可被爪打伤；没有印便通常无后续锁链。新印可由护盾交换获得，但抓中仍需实际生命伤才能成链。期间另一普通身体攻击可促成处刑；同轮双爪不偷触普通处刑。后续执行请求在afterBatch单独结算，源/目标死亡清理需按该模块而非假定所有追加包完全同步。

AI先按当前目标定位，在lockAt前有限更新落点；不会选择绕障路径，团队伸爪按障碍射程截断。失败补偿有限等敌虚化/冲刺最多1.2秒错开周期，不自动穿无敌上锁。

**闭环**：接触烙印→爪捕→实际拉力创造二次伤机会→处刑；觉醒双门创造双向受力与一次特殊处刑，仍有预算/躲避。锁链长度本身不会直接提供额外伤，牵引也不等价磁力瞬时排斥。虚化可清链，沉默能移除普通爪/链，护盾防实伤成链；这些是机制关系，不证明恶魔必输给某角色。实际锁成率/追加攻击机会需定点长段实战。
