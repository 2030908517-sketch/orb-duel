# 电荷球 charge

118HP/8.8身体基伤/225速度/质量1；所有模式相同，**无独立奥义、无手动玩家**。来源：[charge.js](../../../js/charge.js) 全部；[arcana-defense.js](../../../js/arcana-defense.js)临时墙坐标适配；[engine.js](../../../js/engine.js)特殊移动接入。

| 能力 | 触发/时机 | 数值与限制 |
| --- | --- | --- |
| 撞墙蓄电/带电点 | 有效外矩形墙撞、非沉默、每0.45秒最多一次 | 电荷+1上限6；点留6秒、同主相邻周长12内刷新、最多10点。内部障碍不走`coordinate`成功分支，不充电/接地 |
| 沿墙双向放电 | 首次nextDischarge3.8，其后4.8；有≥2电与活点 | 花2，从**最后记录点**（不是智能最近敌人点）双向发实际电流，速度440、2.3秒；用同一周长坐标过角，0.7秒带电痕；不是隔空定时扣敌血 |
| 电弧跳跃 | 电流/墙点与目标足够接近、视线通、非虚化/冲刺 | 一般reach38+目标半径，自有导电则+28；同源-目标至少0.65秒。电流每个方向每敌限一次3.6×热度；静态点/痕1.1×热度，共享间隔防叠；达到条件即弧伤，不是另发可躲弹 |
| 导电 | 身体生命实伤 | 自己的导电5秒，不持续掉血，可刷新、延长电弧reach；与雷霆三层导电是**不同数据结构** |
| 接地短路 | 带导电敌撞有效外墙 | 消本源导电，固定4.5×热度，不按速度；墙点4秒供传导；虚化/冲刺不接地，同源按条件一次 |
| 觉醒雷化·沿壁疾行 | 已醒、≥4电、form CD就绪，下一次合格墙撞 | 花4、760速度沿距外墙半径的矩形周长跑1.75秒，10秒CD；0.16检查近敌、每敌最多2次3.8弧，共享0.65间隔；本体隐为电流、不进行球接触，**仍受弹/束/DOT伤害**；结束从墙边向内重凝回普通速度，沉默会结束雷化 |

闭环：普通接触导电→目标外墙短路→留下点→双向传导→附近跃迁；自己墙碰同时养4电发动雷化。墙面距离决定技能机会，和从天落雷主题不同。王城期间专门用临时矩形周长适配，不改变全局Constants；笼墙等不应凭名字类推成可雷化墙。

设计边界：电弧有距离/间隔/次数，不能按所有点每帧叠伤；雷化只有不身体接触，不是无敌，可被远程惩罚。点/痕持续独立于普通沉默源的后续状态（按world分支），主人死清理。团队大地图目标离墙时间不同，其实际收益待实测，不推断强弱。
