# 普通球 normal

定位：接触型拳势角色，用擦肩追击及久未伤人蓄力补偿接触不稳定。基础126HP、11攻击、235速度、质量1；独立奥义280HP，团队280HP。来源：[config](../../../js/config.js)、[skills](../../../js/skills.js) `Skills.normal/Recovery`、[roles](../../../js/roles.js) `normalHit/finishImpacts`、[pursuit](../../../js/pursuit.js)、[awakening](../../../js/awakening.js)、[arcana](../../../js/arcana.js) `near/blink/punch/update`。

**内部闭环**：身体接触积拳势→下一次强化→觉醒拳劲也可补远处实伤；追击增加一次接触机会，闲置增伤补偿实际缺伤。闲置会被拳劲命中重置，不能等价成“没碰撞就一直加伤”。

**手动**：左键仅原擦肩窗口追击，右键满格后才准备重击；不准备就保留满格正常碰撞。双键可主动选时机，取消自动防御择机，可浪费在无敌/离场；离场用安全落空，不非法瞬身。不会画无用途瞄准线。

**设计含义/待验证**：伤害来源以接触为主，击退会让下一接触延后；需要观察追击窗口实际出现率，不能只按7秒CD估DPS。自动版奥义防御等待可能持续，但不是无限保证必中：合法瞬身失败会收势、手动可以错放、执行时还受原防御。团队使用旧奥义节奏，见模式页。
