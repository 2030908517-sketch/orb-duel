# 毒液球 venom

112HP/6.5身体基伤/215速度/质量1，独立奥义220HP。当前是**双毒三态+活体感染+永久进化**，不是旧“满层自动毒爆/池爆喷三弹”。

来源：[characters.js](../../../js/characters.js) `G.Venom`、[living-venom.js](../../../js/living-venom.js) 全部逻辑、[venom-evolution.js](../../../js/venom-evolution.js)、[flyers.js](../../../js/flyers.js)、[arcana-venom.js](../../../js/arcana-venom.js)。

## 双毒储存与结算

| 机制 | 实际规则 |
| --- | --- |
| 公用槽位 | 目标全体4槽、同类型最多3层；层带source owner、创建时间、期限和基础raw。这里同类上限按类型而非每个来源分别3层，团队多毒会竞争归属 |
| 施毒间隔 | 同来源-目标1.1秒，同一时刻多个感染体不能瞬叠满 |
| 侵蚀毒 | 一般6秒，浓缩来源7.5；每0.5世界秒每层0.55基础伤（醒后新层0.65）×施加时热度；按owner及noReflect归组结算。持续时不能用当前热度直接重算旧层 |
| 麻痹毒 | 5.5秒，本身无DOT；每层移速−4%、普通接触−8%、普通瞄准转向−14%；总速率下限60%。普通瞄准还受身处毒雾±5°连续摇摆，奥义瞄准豁免；霸体抗这些控制 |
| 刷新/争槽 | 同类已3层则刷新该类最短层；4槽满且要换另一类，需两次合格施毒尝试、替换CD2秒，换对立类型最短剩余层，不无限新建槽 |
| 浓缩副毒 | 同来源浓缩成功施毒计数，每2次额外尝试加麻痹；不是每跳总生效双毒 |

麻痹只削弱普通身体包，冲刺/奥义/已标识强化接触等有豁免。普通瞄准影响的不止射手：激光、时钟、冲刺、爪落点、血猎、投刃/活毒转向等走相应 `Aim/Venom`接口。不是所有独立实体的飞行速度都被直接按层减速。

## 基础攻击载体

| 能力 | 触发、数值、持续、CD、限制 |
| --- | --- |
| 毒液弹 | 首次1.6秒，CD9；限角4rad/s跟瞄，距离增大散布从0.10到0.28rad，Adaptive最多减20%；300速度、半径5、220行程、2秒寿命、2.4 roll直伤。出膛不追踪；生命实伤命中产生附着感染，未命中撞墙/到程按原生合法放池，不自动保证落点原地 |
| 本体施毒 | 身体生命实伤且源非沉默时创建touch感染，不立刻无条件塞毒层；血盾全挡普通接触不会从此路线立即感染 |
| 放池 | CD3.2、最多4；原请求位置为本体，普通半径46、0.5布防；3.5秒普通→3秒浓缩半径30→4.5秒雾半径62，总约11.5（含布防）；射弹池以36/46缩放。为预留最大雾尺寸与8间隙，重叠会找切线/网格合法点，实在无处失败；达上限找到新点后才替换最早池 |
| 活体感染 | 池按敌接近生成实际tendril/glob/mist攻击，不是每帧站在池内立刻上层。普通触须约0.16预备（0.82～1.18变化）、245速度/8rad转向；浓缩团0.20预备、315速度直飞；雾虫0.12预备、190速度追向。飞行最多0.72秒，附着0.22（雾0.28）才施毒；同来源目标至多一个待感染体、尝试间隔0.85。遮挡/过远/免疫等可使附着失败 |
| 雾内侵蚀 | 每0.5秒0.18×热度轻伤，另有麻痹感染；不把每个雾触须再算额外直伤 |

攻击伸展额外可达池边42/72/30单位再加目标半径。活体感染、绑定/虫群存于 `livingVenom`，**不全在`engine.projectiles`**；当前磁力遍历不覆盖它们，不能因看着脱手就声称能偏转。

未被接触的池到期可返0.35秒放池CD；主体处于敌离场状态时仍可布池。毒池/雾被物理内墙裁切，不能穿笼持续感染。

## 觉醒：同巢共鸣与毒素进化

- 目标已有侵蚀毒且进入己方合格池，建立2.6秒根系绑定，CD4.5，牵引与外向速度衰减，仍有真实运动；拉过池半径+90持续0.18可挣断。绑定时该来源侵蚀伤+15%，每1.1尝试再感染；变雾/墙隔/霸体/逆命强制控制会清绑定。
- 目标已有麻痹且在雾条件下可生3.2秒虫群，CD4.5，220速度追上后附体视作雾、再感染；不能把发出虫群当作已经附体成功。
- 每次同池同敌一次访问中成功侵蚀绑定/麻痹附体，对应类型进化+2%；有效觉醒身体撞到带对应毒者+1%，对吸血球+1.5%；被吸血链/收束有效伤或吸盾时，两类各+0.5%。同类上限+20%，本局永久。
- 进化增强对应侵蚀系数与麻痹权重/雾瞄摆。时间救命回溯专门保存进化，不像临时毒层一起清；新局重置。

**当前不生效的旧能力**：`Venom.resonate`为无操作，旧觉醒毒池引爆/三向喷弹没有在当前活毒更新里恢复。旧描述/特效分支不能视为拥有此招。

## 独立奥义：腐生·万毒缓蚀

自动、无需觉醒、首次伤害将HP压过30%时立即commit；当次最多立即扣到30%，超出部分及之后未被防御挡住的伤害入待扣池。若早已≤30%也会在更新启动。**不是回血或无敌。**

每0.5世界秒直接付 `min(池量,max(1,池量×.2))`，不再走护盾/减伤/反伤/普通命中钩子；空池后仍保持永久缓蚀状态。控制/沉默/净化不移除池，时间救命回溯保留未付债及累计收付。已入池伤害不能再次护盾减免。`Combat.actual`可记20而本帧HP只扣2.2，其余17.8入池（本次定点确认）；吸血/统计等按记账值，勿据HP条推断。

手动L毒弹/R本体请求池；无毒雾独立按键，缓蚀自动。普通感染与觉醒被动继续执行。

**设计含义/待验证**：小场地池扩张及合法点搜索改变覆盖，不能按4个圆简单加面积；有预测但感染附着可被拉断，站池不等于必上毒。双毒需要真实访问与施毒节奏，进化/四槽争夺的实战频率、缓蚀记账与吸血的净效果需专项而非胜率猜测。
