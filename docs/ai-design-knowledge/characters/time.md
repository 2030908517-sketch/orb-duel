# 时间球 time

120HP/6身体基伤/215速度/质量1，独立奥义215HP。来源：[temporal](../../../js/temporal.js) 全部、[time-rewind](../../../js/time-rewind.js) 全部、[arcana-priority](../../../js/arcana-priority.js)、[manual-four](../../../js/manual-four.js)。

| 能力 | 触发/流程 | 数值、资源、条件 |
| --- | --- | --- |
| 局部时滞 | 首次2秒、每6.5秒，在目标位置预警0.25 | 半径58，生效2.2秒，同源最多2领域；运动/普通施法速率20%，CD/装填/充能速率70%（减慢30%），不是最新聊天里曾提的90%/50%；自己不受影响。同类取最慢不叠乘 |
| 领域侵蚀 | 生效后每0.5秒 | 每跳2×当前热度，按来源-目标0.5全局间隔防重叠多扣；不是一进就每帧掉血 |
| 离域回溯 | 任何已生效领域内记录过进入，后续离开 | **全期常规机制**，每个领域总共一次，把离开者放回领域中心，经物理钳制；不是返回刚进入点。霸体免疫，领域自然消失不拉；不是奥义死亡回溯 |
| 觉醒飞行时钟 | 首次醒后0.6准备、每7秒，0.35预警，末0.08锁角 | 限角6rad/s、330速度、半径9、行程250；碰人/边界/内墙/极限距爆，原始12 roll、爆半径46，并留下同类领域；敌人只有实际爆范围且视线通才受伤/沉默，领域不持续沉默 |
| 沉默与攻击延后 | 时钟爆炸几何范围内调用，免疫等条件过滤 | 沉默1.2秒，强行中断普通前摇/引导等；若原列举充能/等待攻击的时间戳有效，**每项+1秒**，不是旧需求的2秒。可能同时nextShot和reload被推后，按具体字段而非统一整招CD。印记/独立已发武器等按其规则，奥义豁免 |

控制并不是直接把所有timer乘0.2。`slowTimers`区分CD0.7与施法0.2，逐项补时间戳，其他模块还有补充。普通领域/时钟投射物用世界时间；霸体/离场等免运动控制逻辑受 `Priority`最终覆盖。时间领域的伤害与控制是两条判定，控制免疫不自动表示免疫侵蚀伤。

## 独立奥义：终焉·命运重启

**首次致死自动触发，不需觉醒、不要求30%。** 在胜负检查前找未用且未在spent的死亡时间球；同时多个死亡者都消费，首个主持演出。

- 冻结0.6、沿真实记录倒播1.8、重启0.4；期间不接受伤害/正常技能。历史保留10模拟秒，不足取最早帧。
- 仅恢复双方**位置、生命及当时的奥义used资格**；不是完整快照回滚。**engine.time并不退回10秒**，热度/统计/已觉醒事实继续保留，速度重新种子初始化。
- 丢弃弹丸、陷阱、毒池、领域、光束、魂影、圣阵、锁链、临时资源/负面状态等；直接清而不引爆、不返CD、不播放回收收益。资源重新初始化。
- 敌方进完整技能冷却；主持时间球的领域/时钟/觉醒施法冷却置就绪。自己本次奥义spent永久保留，对手在被撤销窗口内消费的奥义可重新获得；已觉醒不撤。
- 当前后置包装还保留**毒液缓蚀待扣池/已收付事实**及毒素进化，不能说清光所有长期积累。手动待命/未发指令清空。

手动L时钟需觉醒、R鼠标合法中心领域（明确例外，其他本体生成技能不类推）；领域内部/致死回溯都自动。时钟不因玩家点击跳过0.35预警。

**闭环/反制**：领域拖慢与离域拉回提供有限驻留机会，时钟对普通施法有中断价值；飞行时钟可偏转/切断，目标可免疫沉默，奥义不受普通沉默。死亡回溯不是免死后恢复全套敌我状态的“读档”，研究连锁必须看重建清单。当前UI状态“80%/30%”与代码一致，旧对话数值不作当前依据。
