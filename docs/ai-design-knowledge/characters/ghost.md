# 幽灵球 ghost

110HP/11身体基伤/220速度/质量1，各模式相同；**没有独立奥义/手动玩家**。来源：[ghost.js](../../../js/ghost.js)全部、[skills.js](../../../js/skills.js) `applyDamage`、[engine.js](../../../js/engine.js)接触过滤、[adaptive.js](../../../js/adaptive.js)。

| 能力 | 触发/阶段 | 数值、条件与限制 |
| --- | --- | --- |
| 周期虚化 | 首次nextPhase2.2，预警0.25；基础周期6.4从预警起 | 虚化1.4秒，穿身体/实体攻击/感应线/团队柱，外墙仍反弹；期间所有扣血被applyDamage硬拒绝，新沉默/磁推等普通控制也过滤。预警可沉默取消，不同于已经进入phase的免伤 |
| 恐吓 | 虚化本体真实扫过敌人 | 每目标0.25秒一次2.1×热度，不发生普通互撞伤；不是全场恐惧DOT |
| 魂影回响 | 本次虚化结束，记录路径至少两帧 | 一个不碰撞回响按原时间、原路径重走，以同样2.1/.25独立命中；不复制下一代魂影，不自寻敌。源死清理；不因本体已变实体就失效 |
| 觉醒追魂虚化 | 基础周期增加1.6→8秒，激活时也推迟下一相位1.6 | 虚化延1.9秒，至多三次0.12预备/末0.04锁向、560速度0.23冲刺，间约0.45；不是额外奥义 |
| 退相魂爆 | 本次进入虚化时记录已醒，结束原位置 | 半径95+敌半径，(5+min(3,本体恐吓实伤次数))×热度一次；魂影走完可重放相同强度魂爆，回响恐吓不回增本体计数 |
| 失败错拍 | Adaptive本轮既无输出也没占到真实危险几何 | 下次相位延0.35/0.70，最多两层；是错开固定周期，不是空技能返冷却 |

进入虚化清惯性/失衡/磁标，解除局部时间速度缩放；已有毒层等继续走世界期限，虚化时它们请求伤害会免掉，而非全部负面状态被净化。退相同tick不马上给双方补身体碰撞，防止实体重叠异常。

**真实边界**：当前没有外墙传送穿越，已经移除旧灵界穿墙设想。魂影是技能回响，不属于通用飞行物，不吃磁偏转/普通切弹。`bypassInvulnerability`也不能越过当前幽灵硬分支（本次定点确认）；不能把同标志在加速球的行为推广到它。

**设计含义**：固定相位可和敌固定蓄力周期重合，失败错拍缓解但不证明任何配对已平衡。长持续区域可等到实体期，单发可能正好被虚化避掉；魂影要求未来敌人路径与历史重合，不是再必中一轮。实际回响命中率和退相爆伤发生率待验证。
