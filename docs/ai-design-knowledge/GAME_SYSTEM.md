# 游戏底层规则

证据范围与版本见 [入口](README.md)。本文默认经典/独立奥义的360×340场地；团队及手动差异见 [模式](MODES_AND_MANUAL.md)。所有距离、速度使用逻辑世界单位，不是显示像素。

## 1. 空间、运动与接触

来源：[config.js](../../js/config.js) `Constants/makeBall`；[physics.js](../../js/physics.js) 全部；[engine.js](../../js/engine.js) `step`；[arena-walls.js](../../js/arena-walls.js)；[trapper.js](../../js/trapper.js) `bounds/projectWalls`。

- 1v1/奥义/手动：360×340。常规半径23，直径46，因此球心可用区域314×294。团队640×440，球仍半径23。
- 初始1v1位置为宽度26%/74%、高度42%/58%，每球由种子随机方向；团队有四个固定分离出生点。没有全局“太久不撞就偏转轨迹”的追敌机制。
- 常规巡航是恒定目标速率，不用真实摩擦把球停住。`normalizeSpeed` 从当前方向恢复巡航；速度为0时有方向兜底。惯性期向巡航混合，衰减系数通常4，特殊冲量可用1.3/1.55/2.2等；存在100×时间/毒速率的惯性低速下限。
- `ball.speed` 是巡航资源，不等于即时 `hypot(vx,vy)`。`maxSpeed` 也不是强制动作的通用上限。普通冲量默认限速800×时间与毒速率；显式 `motionSpeed`、幽灵冲刺、奥义自定义 mover 可覆盖。
- 外墙：球心钳在边界内，法向速度反号，切向保留。角落同一次记录最大法向墙速，供后续墙伤使用。
- 球间：按质量交换弹性碰撞的法向动量，切向保留；重叠按逆质量分离并留0.02间隙。**不是每个球各自以碰撞法线独立镜面反射。** 对方速度、质量、霸体与后续击退都会改变结果。
- 霸体视作零逆质量，抵抗普通冲量；两个都霸体时不能按普通质量分离。虚化、离场/不接触动作、沿壁雷化等有独立跳过接触规则。
- 有效身体伤害需要“新接触”，同一对球至少间隔0.22秒；球心距离超过两半径和+1才重新视为分离。一次贴住不会每帧打伤害。
- 主流程在移动和碰撞后最多32次交替投影，处理墙边重叠。球体是240Hz离散接触，不能宣称任意速度下连续碰撞绝不会穿透；投射物另有扫掠判定。
- 临时王城边界、囚笼和团队圆柱是实际阻挡。囚笼内目标受内边界，其他球（包括陷阱球）受外侧墙阻挡。内墙也影响射线/多数武器，不能只改画面尺寸。

**设计含义**：常速球跨球心活动宽度约1.3～1.5秒；900速度约0.35秒，这是量级推导而非相遇周期。小地图让长前摇与多次反弹交织；“击飞远一点”很快变成墙反弹。近身连续技能不能假设目标一直贴身；需要检查射程、转向、惯性恢复和下一段锁线时机。地图显示放大只改善观看，不改变机会；真正缩小边界会改全体命中分布。

## 2. 三种时间与随机源

`Constants.dt=1/240`，`tick` 整数决定 `engine.time`。`Clock.advance` 将真实帧时间（每次最多0.1秒）乘1/2/4/8倍积累，反复执行固定步；倍速不改dt。掉帧超过0.1秒不会全部追赶。

- **世界模拟时间**：技能、弹丸、DOT、印记、结束过渡主要依赖它。
- **角色局部时间**：时间领域使运动/施法速率0.2、CD/装填/充能速率0.7；通过移动缩放、dt缩放、推后时间戳实现。不是整个世界减速，已飞出独立武器、印记等通常走世界时钟；须检查每个模块。
- **真实表现/音频时间**：Clock的顿帧暂停模拟推进；表现尾迹的部分包络可用 `presentationTime` 继续。Web Audio有独立真实秒时钟，音量去重不是技能CD。

暂停时Clock不进模拟，隐藏页/规则弹窗会由app暂停并停声音。直接调用 `Engine.step` 的无界面验证**不会等待真实顿帧**；可检验战斗顺序，不能据此评价停顿观感或录制时长。

种子RNG决定初始方向、伤害浮动、部分随机技能落点等。`fxRng=seed:effects`、瞄准散布独立序列和 `Presentation`事件哈希隔离表现随机数；同一种子还需相同代码、模式、角色、地图及手动输入才可复现。新美术不得消耗战斗RNG。

## 3. 伤害不是统一一个公式

来源：[skills.js](../../js/skills.js) `Combat.attackValue/rollAttack/applyDamage/resolveBatch`，角色 `hit` 钩子， [arcana.js](../../js/arcana.js) `mixedDamage`及 [arcana-priority.js](../../js/arcana-priority.js)。

### 攻击生成

`attackValue` 组合技能倍率、角色倍率、身体压力/闲置增伤、觉醒倍率及热度。`rollAttack` 再乘种子随机的0.8～1.2。许多DOT、圣光、磁力、电弧、彗星、奥义直接写 `raw×heat`，没有这层随机；恶魔魔爪有独立0.9～1.1。不要把所有浮动归因于±20%，也不要把面板攻击当作所有技能伤害。

加速球首次觉醒冲刺接触走早返回：18×热度再±20%，不叠原来的速度增伤；非冲刺普通碰撞才使用巡航速度增伤。回旋球身体平时仅基础70%、飞刃在外再80%；它的重斩是独立武器判定。

### 同步批次结算

1. 过滤不可选目标、友伤及零伤包；对王城专盾调整穿盾/碎盾优先级；麻痹削弱普通身体包；清算预判可在受击前启动。
2. 采样神圣盾接触灼伤资格，然后按**目标聚合同时攻击**；普通/穿盾分组。
3. 无敌/离场分支先拦截。普通免伤30%在护盾前应用；专属盾与普通盾吸收，记录吸伤压力与破盾行为。穿盾不等于无视减伤，也不等于不可反伤。
4. 减去吸收的生命伤害进入 `applyDamage`；缓蚀可能把它记入待扣池。`actual` 是结算记账伤害，`hpLoss` 才是即时HP变化；大多数普通角色两者相同，毒液奥义例外。
5. 按原始伤害比例分摊批次实际伤害、吸收和回避。不会因攻击包迭代顺序让第一包独占盾/最后一包独占过量伤害。
6. 执行各角色命中钩子、上印/施毒/蓄能/连锁请求；反伤依据可反伤来源和 `actual` 计算，存反击弹；治疗按各包比例或角色吸血请求。
7. 聚合即时反伤并通过 `applyDamage`一次结算，**不再递归生成反伤**。再应用强打击与真实击退、成功血契收束净化、存活者治疗。
8. 有效身体接触回调最后给吸血球血能/加速球增速等；冲刺无敌保持到同次交换及反伤后才结束。电解、星辰共振等追加包可在 `afterBatch` 开下一批，不等于同一批互杀完全对称。2026-10-22恶魔已移除旧二次处刑；其afterBatch仅负责爪结果确认和接力。

2026-10-22增量：失魂在入批时按source统一缩放可归因攻击，反伤同样按返伤者入批状态；自然衰减不受影响。扯魂包携带trueDamage/bypassShield，mixedDamage只对其跳过普通减伤，原王城优先级仍可降阶阻断。混合包分别分配盾与生命损失，普通包不能沾到穿盾；团队旧结算增加新包兼容分支，旧包路径不变。详见[当前恶魔](characters/demon.md)。

例：20原始伤害打有30%免伤和10盾的普通目标，先减到14，再挡10，即时扣4（本次定点验证）。若改成毒液缓蚀，14中未被盾挡的部分又可能入池；来源吸血/反伤统计可能依据记账值，不能据HP条不动推断攻击没有生效。

### 防御语义必须拆开

| 状态 | 当前效果/边界 |
| --- | --- |
| 普通护盾 | 先扣盾再扣HP；一般不抵抗真实物理动量；并非免疫沉默、印记或技能命中 |
| 王城专盾 | 24、不与普通盾叠加；普通穿盾/碎盾失效，奥义穿/碎盾降一级；沿用压力机制 |
| 免伤 | 当前统一30%，护盾前应用；激光奥义期间自动存在，其他角色不能凭名称获得 |
| 霸体 | 主要抗运动控制/冲量，部分时间/麻痹控制也被免疫；**仍可扣血**，不是全局无敌 |
| 幽灵虚化 | 拒绝所有 `applyDamage`，连 `bypassInvulnerability` 也无效；穿球/武器但仍反弹外墙；已有状态按各自时间到期 |
| 加速冲刺 | 冲刺期无敌，身体互击先保持此状态再收冲；部分明确绕过标志能越过，不能类比幽灵 |
| 猎蝠穿行 | `noContact`，不结算普通身体伤害；**仍能受技能伤害** |
| 血海离场 | 不进入普通选敌/受击；显形后恢复受击，不能把整招都叫无敌 |
| 射手侧闪 | 短暂无敌且穿球；落点/蓄力恢复受伤，蓄力霸体不等于无敌 |

`damageOrigin:'wall'`、`wallSlam`、吸引偏航墙伤及 `noReflect` 排除即时反伤；排斥墙伤仍归敌人来源可反伤。反伤球当前不重新定向敌方弹丸，`Roles.intercept/Flyers.reflect`直接返回null。回血不能超最大生命；普通吸血仅在自己HP>0时发放，不能救已在本批死亡者。

## 4. 一帧内的主要执行顺序

`Engine.step`：推进tick → 表现年龄 → 保存旧位置 → 幽灵进/退相 → 时间领域/时钟、局部时钟修正（含离域回溯）→ 王城/囚笼准备、恶魔魂身有效性清理（binding-02有印链缚另在移动后执行75上限限位） → 每球状态过期/角色更新/闲置压力/觉醒/普通技能 → 奥义 → 飞刃追猎/身体移动/墙钩子 → 猎蝠命中 → 身体对碰（替身奥义可先取代）→ 重叠修正 → 机关置换/普通追击 → 魂影、圣水圣光、恶魔、雷霆、电荷、星辰、奥义世界 → 飞行物/光波/光束/陷阱/毒世界 → 同步伤害批 → 失败补偿观察 → 胜负检查 → 后期衰减 → 再检查。

后加载包装还会在 `World.update`前插入光刃、在时间 `begin/world`插入回溯、在 `checkEnd`插入缓蚀和救命回溯。完整加载图见指纹文件。**不存在对所有攻击通用的“先伤害、后状态、再击退”一句话顺序**：例如飞行时钟爆炸在批次扣血前调用沉默，而恶魔烙印在命中钩子里确认。

## 5. 觉醒、奥义与收尾

觉醒条件：存活且世界时间≥15秒 **或** HP≤最大50%，一局激活后不因回血撤销。角色各自替换技能/增加机制。时间回溯保留已觉醒事实，而非重新判断历史是否觉醒。

独立奥义通常觉醒且HP≤30%，每局一次、资源/防御/当前动作附加条件各异。普通球严格HP<10%可补满拳势，但自动版仍受目标防御等待。毒液缓蚀不需觉醒，在跨30%时拦截；时间球首次致死自动，不走30%。沉默不得取消奥义，`Priority`还区分霸体、奥义实体及清算运动控制；不是所有普通技能跟着免疫沉默。

自动择机的`Arcana.protected`检查可选性、无敌、主动反伤及`target.shield`普通盾；它**不直接检查`target.arcana.royalShield`专盾**。因此“等待盾结束”在本库默认指普通盾字段，不能推断AI也会识别王城专盾并延迟。同样，射手/加速的普通盾等待有角色例外，详见角色页。

时间回溯首先拦截致死结算；否则同批双方归零可平局。进入 `ending` 后只完成致命一击已有动量/表现，禁止新伤害、世界技能及其他飞出攻击抢死后击杀。默认收尾约0.7秒，按致命攻击种类可到1.9秒，之后定格显示结果；不得把这一段计作继续正常战斗。

60秒后 `heat=min(2.5,1+max(0,t−60)/60)`；150秒后每模拟秒3HP衰减，穿盾、请求绕过部分无敌，但幽灵/离场硬阻挡仍有例外（已定点确认幽灵）。没有硬时间截止、没有代码保证每种对局严格在某秒结束。

## 6. 自动 AI 的实际能力

来源：`World.targetFor/aim/sweep`、`Aim.*`、角色update、`Adaptive.*`。

- 1v1选其他存活可选目标。2v2优先可直视的近敌；忙于链/炮/磁极等动作时保留原目标。不会全局搜索最优组合或规划长期胜率。
- 普通身体自由反弹，不做通用寻路/避毒/避陷阱。普通擦肩回头、追刃、短喷、射手奥义反击、沿壁雷化等是各角色专门的局部策略。
- 预瞄使用当前速度、延迟、外墙反弹和有限预测时域；解弹丸拦截并非读未来。1v1不预测下一次球间碰撞/敌方未来技能；团队对圆障碍用60Hz短期试移预测。
- `Aim.track`约每4tick（60Hz）更新目标方向、每tick限角转动；`direct`通常立即设方向；位置预警 `point`平时立即更新、麻痹时限位移。发射前锁定不等于出膛追踪。
- 射手普弹有限跟瞄、±9/6/3/0°；普通狙击满校准无散布，瞄准受伤本发零校准±21°。毒液弹随距离散布约±5.7～16°；落空还可成池。加速冲刺从移动方向转向，末0.12锁线。高移速会扩大预测误差，但不自动降命中数值。
- 角色专有威胁扫描只看列举的武器/预警和短期接近，不是通用危险感知系统。例：激光短喷只看身体，不因子弹/陷阱短喷；射手奥义可识别实体、血潮、近身和锁线激光，不能因此假定能避所有场地机制。
- `Adaptive`不是机器学习。按一轮是否造成有效伤害/吸收或指定成功事件，失败补偿最多2层；可稍延防御、调瞄准/散布、等敌方虚化/冲刺至多1.2秒、改变部分节奏/落点。不同角色成功标准不同，不能说每次落空都返CD。
