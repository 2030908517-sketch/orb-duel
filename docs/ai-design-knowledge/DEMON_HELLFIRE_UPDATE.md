# 2026-10-22 hellfire-03：地狱火焚契

覆盖binding-02奥义的门/爪/真实斩线落空规则。基础、觉醒和永久仆从参数保持。

- 起手仍需已觉醒、≤30%、自己的魂线、每局一次、合法瞬身位置及原有择机条件。有效起手后确定同化，不再进行概率/几何斩空判定。
- 约2秒局部演出：0.16秒瞬身；本体起燃喷火，0.6–1.12秒魂线从中部烧蚀、缺口向两端扩大、亮断端/焦屑；1.12–2.0秒灵魂脚下逆五芒星染色，完成后成为有原生基础能力的独立恶魔化仆从。
- 演出期间不推进世界time/tick、双方CD、移动、弹丸、伤害和普通AI；仅局部演出计时推进。使用现有Clock固定步驱动，暂停同时暂停演出；重开清空，结束/死亡仍可清理。起手当个已经形成的固定步完成原同步结算，之后进入时停。手动输入禁用、不缓存。沉默不取消奥义。
- 奥义不再创建门/魔爪。法阵在灵魂脚下并置于主体后层；烧断不是斩击弧。普通灵魂颜色取宿主本色、透明度提高，非统一蓝色。移除肉身倒十字及种印贴身脉冲；旁侧原三角烙印槽换为倒十字。

主改demon-arcana.js、demon-render.js、renderer.js，demon-runtime.js输入锁与demon.js重开清理为必要接入。没有修改版本号、伤害/CD/仆从参数或普通双门。
