# 神圣球独立奥义：启示录·七重圣印（2026-10-24）

本页为当前源码增量，优先于旧审计中“神圣无奥义”的记录；不改写历史快照与旧测试结果。实现参数是首版，功能通过不代表平衡或主观观感已通过。

## 入口与模式

- 正式 `arcana.html` 以及手动模式的自动神圣敌人：240HP，沿用觉醒且生命≤30%、每局一次。当前可选目标存在便起手，消费后进行8.5世界秒仪式（创作者追加：终审慢下来，末段延为2.5秒）；普通沉默不阻止启动、阶段推进或三段释放。
- 经典与团队仍为120HP，无本奥义；不新增神圣手动操作，不改版本号。
- 起手时保存自身位置与运动方向，仪式期间定点施法，仍会受到伤害，没有新增无敌、霸体或减伤。期间 `Holy.seal` 拒绝生成新圣阵天使，已有圣阵不删除，原有天使/觉醒功能不被替换。结束后恢复原方向运动。

## 七印实际规则

时间从正式消费奥义开始；固定240Hz下按世界时钟推进，暂停/全局命中顿帧遵循原Clock。

| 时间 | 封印 | 当前实现 |
| --- | --- | --- |
| 0 | 缚速 | 巡航速度和速度上限乘0.5；不反复折半速度，不降低世界或奥义时钟 |
| 1 | 绝护 | 普通护盾暂不吸收、不新获取；保留原盾量与原到期时间。禁止普通治疗/吸血/赐福/觉醒补血，普通减伤与常规格挡失效。王城专盾和合法奥义特殊保护保留；玩法回溯是特殊恢复，不当普通治疗删除 |
| 2 | 禁触 | 该目标对施法者的接触伤害包过滤；接触前按真实法线将目标投影到球外并反弹，施法者保持定点。神圣对敌人的正常身体攻击不因此取消；这不是无敌 |
| 3 | 禁术 | 借现有普通技能禁止查询阻止起手；绝对冷却期限补偿世界步长，局部冷却用cooldownRate=0。只停普通CD；已发出的弹丸、光束、魔爪、已开始的光刃/追猎等执行过程仍推进，不因本封印直接抹掉；原本真正沉默的中断规则仍保留。与时间领域叠加时只补剩余差额，避免重复冻结 |
| 4 | 净世 | 从场地中心用0.65秒扩张波真实清理该目标可清除的普通攻击对象；持续至本阶段结束扫清后续接触波面的对象。保护奥义等级、hub、prison、arcanaOwner等标识的实体 |
| 5 | 禁奥 | 阻止新的奥义入口，包含自动缓蚀及死亡回溯。已经合法进入预警/执行的奥义允许继续，不是按used一个字段粗略取消 |
| 6 | 终审 | 固定本次十字中心，尝试定身至8.40秒；霸体、虚化、无敌冲刺、有效奥义免疫等沿现有规则抵抗。之后才获得的合法特殊保护也可解除定身 |

持续效果到第8.5秒清除。目标或源死亡、结束/重开/死亡回溯会停止新伤害并清理约束，无额外终结伤、治疗或返还。回溯后奥义资格仍按现有回溯历史规则处理。

### 破印

`HolySeals.breakCheck` 查看目标已使用的奥义**实际**授予的 `Priority.armored` 或 `Arcana.immune`；仅普通冲刺、觉醒/普通地狱降临、仅奥义预警均不冒充破印条件。成功后持续封印永久退出本轮，后续净世不再清理其对象，已清掉的对象不复原。仪式和第七印定身尝试仍继续；若保护已结束，敌人仍可能在第七印再次被合法定身。不能把破印理解成整招取消或必定躲过全部审判。

### 清场边界

清理普通弹丸/飞刃、飞行时钟、陷阱、毒池、光束、冲击波、时间领域、机关连锁、幽灵回响；普通圣水/圣阵/圣光/圣灼对象、落雷、超新星波、墙上电流/残留点，普通魔爪也在适配范围。飞刃/彗星使用既有脱离回收接口，普通魔爪取消本轮后门续接；不额外引爆或返CD。

不删除：角色本体、资源、普通卫星槽位、恶魔魂身/永久仆从、已附着毒素等角色状态、奥义场地及受保护实体。净世针对攻击对象，不是清空所有角色数据。刚刚在同一批形成的合法伤害按既有同步批次结算。

## 三段实际判定

- 6.72秒：纵向条带，9基础伤。
- 7.36秒：横向条带，9基础伤。
- 8.14秒：两条条带的**并集**，16基础伤；交叉中心只发一个第三段攻击包。
- 条带半宽36，各自跨整个场地宽/高；属于区域神罚而非飞行物，不拆除或移动临时墙（区域判定本身不被墙切短），计入目标半径；中心在第七印时锁定，随后不追踪。三段分别生成 `arcHolyJudge` 原生伤害包，只乘热度，正常经过无敌、护盾与反伤等公共结算；不是直接扣总血或无条件必中。
- 成功定身的受控样本完整34基础伤；破印/免控制目标可以运动躲开其中某段。几何命中与实际免疫分别记录，免疫不播放成功命中重音。

## 动画与声音

`holy-seals-render.js`：七种符文随阶段落下/展开/闭合；持续金环与十字枷逐步增加；施法者背十字与地面经文呼应。第七印汇聚为白金实体圣剑，七枚冠状圣徽响应，剑锋有短促扇形残辉，十字有约0.66秒经文汇流蓄能，抬剑蓄势后以固定剑柄为支点旋劈（不沿剑轴直推），劈过形成纵痕，再连续收剑、侧转横扫；剑痕保留、经文蓄能，整个十字条带共同向外喷发与消散。墙角处调整巨剑关键持位，避免关键命中帧只剩剑柄。效果为代码2D，不调用天使或觉醒光柱作为本招主形。

15个独立合成音色：七印、破印、反弹、纵/横/十字三种释放和三种真实命中。第七印用现有总线短暂压低背景，三段的出手与命中重音分离；排除普通holyHit的重复配音。实际受伤的纵/横顿帧0.035秒，最终0.065秒；免疫/落空不触发这些命中顿帧。

客观混音：48kHz真实 `Audio.consume` 和原输出图校准，碰撞基准50ms能量窗及180–5500Hz频段，15音色均有独立trim；50个同帧最终命中请求实际只播放1个，密集样本峰值约0.114。未人工试听，不宣称听感验收。
