# 2026-10-22 control-05：仆从、目标与霸体解控

本记录覆盖 gate-04 中对应条目。没有修改版本号、经典/团队本体生命、伤害数值、音效或奥义次数。备份：项目外层 `work/demon-control05-before/`，保留此前未提交实现。

## 当前实现

- 仆从初次生成及每次重凝聚均为 **50/50HP**，仍为半径18、55%原伤、5秒等待和0.75秒重凝聚。
- **射手反击目标漏洞**：`RangerArcana.update` 原先把 `threat.owner` 当反击目标，因此仆从的子弹/身体威胁会覆盖统一选敌。现在仍根据真实威胁选择侧闪路线；若来源是仆从，反击目标使用 `World.targetFor`，优先合法恶魔。手动鼠标瞄准不被AI接管。
- **另一独立分支**：`LaserBlade.stopJet` 原先优先反打短喷所躲的身体。现在自动光刃优先可实际命中的恶魔；够不到仍按原合法近身目标处理。没有增加射程或强制命中。
- 已核查常规射击/狙击、主炮、飞刃、冲刺、时钟、魔爪与各主动奥义的统一选敌或锁定入口。既有 `World.targetFor` 优先恶魔规则保留。**真实碰撞、范围波及、反伤返给真实来源、已发出的飞行物首个碰撞对象，不等于AI主动选敌**：穿甲弹仍可能被路径上的仆从真实截中，不能据此称为锁错目标。已经锁线/发出的攻击没有追踪改轨。
- 穿刺绘制改为宽锻铁钉头、笔直细杆和尖端，沿用原路线、时长和判定。预警出钉→飞行→命中→驻留；移除命中事件、飞行对象与驻留钉的重复制图。

## 霸体奥义解除控制

以 `Priority.armored` 当前真实范围为依据，适用于普通球、射手球、激光球的带霸体奥义，**不把所有奥义改为霸体**。

- `Priority.clearControls` 在这三类奥义 `Arcana.commit` 时清除现有失魂静止、魂球锁链拘束、逆命回返、地雷捕获索、活体毒液缠缚、麻痹层、光刃减速、沉默及受击失衡/残余冲量控制。
- 侵蚀毒伤、血印、普通伤害状态、护盾、既有消耗与真实场景墙体保留。麻痹层属于控制，侵蚀层属于毒伤，两者分开处理。囚笼是物理墙，不因解控而凭空消失。
- 若正在被动能轮回控制，通过原 `Overdrive.finish` 完整收束双方状态，避免仅删除受控标记而使施法者卡住。
- 射手从侧闪进入蓄力的共用 `prepareCharge` 再清一次当前控制，覆盖自动与手动分支。没有延长原霸体阶段。
- 失魂期间只允许上述奥义决策/预警推进；正式消费时才解控。普通球前置预警不提前获得霸体。没有就绪或条件不足时，不能凭奥义键免费解控。
- 手动左右键组合可进入该奥义入口，普通按键仍被控制挡住；暂停、全局顿帧、玩法回溯、离场等输入限制仍在。其他没有霸体的奥义不因此获得解控权限。
