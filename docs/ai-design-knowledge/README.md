## 游戏概况

ORB DUEL 是本地浏览器 Canvas 2D 自动小球战斗。身体按初始随机方向持续运动，外墙反弹，球间碰撞交换动量；角色技能在固定模拟步中产生真实弹丸、范围判定、领域、资源、状态及特殊运动。常规方向并非一直追敌；多数角色依赖被动运动提供接触机会，技能局部接管方向。

当前注册 **18 个角色**、**4 个正式页面**。经典 1v1 无角色奥义；独立奥义及手动页有 11 个奥义角色；2v2 保留三个旧版奥义与更高的三角色生命。手动页开放 8 个玩家角色，其他角色仍可作为自动敌人。不是所有角色都有奥义，也不是所有模式共享同一生命与奥义。

当前没有联网、账号、服务器、关卡或手机操作系统。实验室是重复观看/调参工具，不是额外正式玩法。

4. 新验证记录写明模式、种子、夹具与实际观察；理论机制克制不能升级为统计胜率。
