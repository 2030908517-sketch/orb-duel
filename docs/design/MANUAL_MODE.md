# 手动技能对战（PC 1v1）

## 规则与操作

入口为 `manual.html`，现有经典、自动奥义、团队模式全部保留。新页面复用现有奥义1v1引擎及生命配置：玩家可选射手、普通、吸血、陷阱、毒液、激光、回旋、时间球（沿用各自奥义模式生命），敌方可选现有18个角色，保留自动技能与奥义。没有新的平衡数值、音色或伤害判定。

- 双方自动运动、弹墙和身体碰撞；WASD不操纵日常移动。
- 对局开始后，普通窗口与全屏均可在整个页面内移动鼠标瞄准、左键发起一整轮、右键切换；场地外按相同坐标射线瞄准。暂停、重开等交互控件的左键保留原用途。对局中阻止页面文字拖选、拖拽、右键菜单与可拦截的右键拖动事件；浏览器或扩展在网页外部处理的原生手势仍需在对应设置中关闭。三连发各颗出膛前重新读取鼠标方向，已发射实体不跟踪鼠标。
- 觉醒前固定三连发；觉醒后右键选择狙击/散射。**仍需满校准**才可实际使用高级武器；校准不足时左键执行三连发，已选偏好保留。右键会同步切换头顶弹药图标（显示所选的下一轮枪型），复用原弹药切换动画；切换期间装填期限与实际弹药不变。原装填、发射间隔、扰动、受伤清校准、弹丸实际命中结算和散射重弹全部复用。
- 狙击仍经历原有预瞄、锁定、发射流程；锁定后方向沿用原规则。装填结束不自动开火，每轮等待新的点击；不以按住左键重复发起。
- 原奥义条件（觉醒、生命≤30%、未消耗、当前狙击/目标状态允许）满足时，左右键同按直接沿光标方向调用原侧闪，不再经过E待命/WASD选择。采用已有35毫秒组合优先识别；先左或先右均不会附带普通技能。
- 保留原路线合法性、距离、无敌、穿球和墙体检查；方向由本体到光标决定，不能穿墙或进入非法落点。有效侧闪才消耗奥义，非法方向不自动替选路线。
- 侧闪结束进入**一秒战斗时间**的点击窗口。左键启动原1.08秒蓄力，末0.16秒锁定，之后由原执行器发射。预锁定阶段随鼠标瞄准，锁定后不跟随。不点击则收势，不蓄力、不发射、不返还；重复点击不能重启蓄力。保留原穿盾/碎盾、不可磁偏/镜返、伤害、弹速、霸体和后续装填。
- 暂停及原Clock的时停不推进窗口；被禁止时的按键直接丢弃。普通技能仍受沉默与麻痹影响，奥义沿用沉默豁免。普通球不可躲避的瞬身轰拳预警/执行期间不接受提前奥义侧闪，但不额外禁用普通射击；实际时停期间所有命令均被拒绝。

## 最小接入与隔离

- 新增 `js/manual-ranger.js`：仅新页面加载，以 `engine.manual.playerId` 区分玩家；其他球及没有手动控制器的引擎直接委托原函数。调用原Ranger选择/更新、RangerArcana路线/起手/架枪/发射，不复制子弹、伤害、碰撞或状态系统。
- 新增 `js/manual-ui.js`、`manual.css`：PC输入、只读侧栏、沿用已有线条风格的鼠标准星与穿甲待发强调。没有新增或改动音效。
- `js/ranger.js` 只为原选择函数增加可选武器参数；满校准与觉醒检查仍在原函数中。未传参仍按距离自动选择。
- `js/arcana-ranger.js` 只为原路线函数增加可选固定方向；默认仍搜索原来的24个方向，保留路径、落点、墙及囚笼检查。
- `js/app.js` 仅按页面标记设置固定玩家、创建控制器、重开清输入、锁定玩家选球。现有页面不加载手动模块；旧引擎、Clock、角色配置、声音、命中、物理和状态结算均未修改。
- 三个原页面仅增加新模式链接；手动页面独立复用脚本。手动模式使用独立的PC全屏布局（F），不使用自动模式的横/竖录制循环；没有手机触控或其他玩家角色。

## 血印、追猎与手动信息微调（2026-10-20）
