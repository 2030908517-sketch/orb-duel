# 统一角色状态面板

版本：20261017-status1。经典、奥义、团队模式共用 `js/status-panel.js` 的 `G.StatusPanel.collect` 和 `render`，只读战斗事实，不修改角色能力和时钟。取代原先两个App各自拼接状态的实现。

## 审计修正

原面板遗漏电荷球的导电印记、雷暴球的电解叠印，以及若干临时强化和特殊形态；经典面板还沿用旧中毒“/3”字样。已统一清单，并区分持续状态与原技能数值/冷却槽位。

- 通用：离场、霸体、虚化/冲刺/奥义无敌、普通盾和王城专属盾、机械囚禁、陷阱牵制、逆命牵返、时间减速/技能延缓、沉默、热切减速、失衡、刃印、血印、磁力印记、神圣灼伤。
- 双毒：侵蚀中毒、麻痹中毒、实际生效的移速/碰撞/瞄准削弱及雾中扰动。没有恢复球旁毒层文字，也没有重新显示旧3层上限；层数仍由球旁图形识别。
- 其他敌方印记：导电（电荷球）、电解叠印（雷暴球）、地狱烙印和魂锁分别列出，不因同一角色已有另一种状态而漏掉。校验剩余时长和来源存活。
- 普通球：拳势/重击就绪、回身追击、攻击蓄力；吸血球：血契和追猎阶段；反伤球：预备、反伤姿态、预判就绪、奥义预测资格和蓄能反击；护盾球：盾压蓄势。
- 射手：有效校准、装填、狙击预瞄/锁定/受创偏移、枪阵强化；回旋：接刃重击；激光：主炮预瞄/锁定、热刃、散热和防连震窗口；毒液：共鸣催化与缓蚀伤害池/致死风险。
- 加速：冲刺蓄势及永久超速挡位；幽魂：虚化预备与突进；磁力：锚定、动能强化和磁力阶段；电荷：电流化；卫星：塌缩/核心/重生；圣光：圣裁蓄势；时间：全场回溯。奥义通用阶段独立显示，不把奥义保护误写成所有角色霸体。

判负角色只显示停止行动；临时状态到期不再展示。基础被动、攻击数值、弹药/血能等资源及普通冷却沿用原面板，不把场上的每个独立技能实体都算成角色Buff。

## 布局与维护

原状态槽固定保留两行，状态多时可上下滚动，标签完整保留且可键盘聚焦，不再只依赖省略号或悬停标题。更新时复用列表节点，保持滚动位置/键盘焦点；状态数量变化不会挤动竞技场。样式集中在 `status-panel.css`。

新增角色状态、印记、临时强化或特殊形态时，必须接入此统一清单，并验证开始、结束、到期、来源死亡、霸体豁免及三个模式；不要只加球体图形或单独给某模式追加字符串。

## 实际验证

114项专项通过，覆盖18角色读取不修改战斗快照、导电/电解/多印记同时存在、到期与来源死亡、双毒效果、霸体豁免、护盾/囚禁/强化/各角色形态。三个正式入口分别验证导电等状态出现、列表完整可滚动、刷新后滚动与焦点保留、状态到期移除、竞技场不位移及390宽不横向溢出。

实际打开桌面及手机截图查看，含团队界面。证据在本聊天outputs/status1；没有进行平衡对局，没有改伤害、技能CD、角色机制或球外标记样式。
