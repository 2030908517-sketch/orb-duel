# 时删·命运断章（2026-10-29）

本次为正式常规技能，覆盖经典、团队、独立奥义及手动模式。未修改游戏版本号，也未改时间球原有领域、时钟伤害或死亡回溯机制。

## 机制与执行

- 飞行时钟真实爆炸命中的攻击计时延后从1秒改为0.5秒；沉默仍为1.2秒，其余爆炸规则不变。
- 时删基础阶段即可使用。首轮6秒可用；2026-10-30更新：自动角色只在即将受身体碰撞、实体飞行物或直击伤害时发动，排除陷阱/破片、领域持续伤害、毒池/毒雾、中毒与灼烧。手动玩家同样需要来袭条件并按中键，AI不代放。
- 完成后开始12秒独立CD。新CD接入原有时间领域减速、失魂冻结、圣印禁术冻结及回溯冷却规则；时删不能绕过沉默、失魂或当前不可打断的奥义演出。
- `TimeDelete.run` 通过当前实际模式的 `engine.step()` 执行240个固定步（1/240秒）。期间递归保护阻止所有时删再次起手，整个循环内不渲染、不播放积累音效或补播命中顿帧。结束后正常显示最终仍存活的实体及有效预警。
- 时间、运动、墙反弹、技能、觉醒、陷阱、弹丸、毒池、领域与历史记录都运行原逻辑，不直线外推。伤害入口 `Combat.applyDamage` 与 `Arcana.mixedDamage` 在扣盾、扣血及入池前免伤；已入池缓蚀按原计划消耗该次账款但本次生命损失为0，不留延迟补伤。治疗、非伤害控制及实体消耗仍按真实模拟结算。
- 时删不改变实际无敌字段、不触发死亡回溯，也不把临时免伤遗留到跳跃之后。奥义使用资格不额外返还。

## 表现设计与参考

观众应读懂“世界缺了一秒”，而不是时间球闪避了。使用约0.42秒的短演出：真实前一显示帧被不等宽切片打散，各区先后切换到当前战场；细亮时间裂隙切开画面，两组带刻度、暗面与亮边的钟环断段错位，碎刻度迅速消退。没有角色分身、额外位移或整屏白闪。残留预警仍然服务实际攻击状态。

实际检查了项目的光刃与同化火焰基准，以及 `work/arcana-comparison-20261026/time-sheet.jpg` 的既有时间球画面：借用时间刻度、分层边缘和阶段收束语言，不复制奥义的大钟与倒流残影。外部检索 Katana ZERO 只返回普通战斗静帧，未证明其时间跳跃过程，未把它采用或宣称为已观看的动作参考。本次没有新增或替换音色，跳过的声音请求不在结束时堆叠播放。

复查发现初版旧帧透明混合会产生分身错觉、水平接缝过亮，已改为不透明切片依次切换，并压低接缝，突出裂隙及断裂刻环。
