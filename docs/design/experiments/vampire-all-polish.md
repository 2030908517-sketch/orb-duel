# 吸血球「血海重生」全流程精修（2026-10-28）

目标：观众看懂血肉化海、血海卷起围猎、万血回流、血柱重塑和蝠翼复生的连续因果。沿用正式机制与0.6秒液化、各真实波次、0.85秒逆流、1.1秒重生时钟，不新增伤害、控制、无敌或声音事件。

采用当前已审过的 Nami 连续浪墙、VFX Apprentice 液体明暗/空腔和 Torbach Waterfall 旋流漏斗参考（见 blood-sea-01.md）；本次实际重看本地顺序参考。取宽厚浪身、卷唇与暗腔、下陷旋层，不照搬水色、三维场景或镜头。蝠翼取既有骨架和内凹翼膜构造，严格保持正向。材质向已认可恶魔同化火焰的内外层与运动完成度看齐，保持血液自身的湿、重、连续。

阶段：预兆以裂纹和血珠牵出；液化用连片流体向外铺开，海面以大暗层/少量湿反光组织；浪从真实生成点抬升卷曲，明暗随同一卷面运动，拍落接回海面；逆流让血海形成多层有深度的漏斗、流层逐步向心抽入；血柱从同一涡眼爆起，柱面内的上涌流与冠部外翻同步；血柱撕开后，蝠翼先展开腕骨再绷开翼膜，随后血雾收束。高潮在重生，持续阶段保持角色和命中可辨。

验收：逐阶段与基准并排，连续动作无完成图等比缩放、无整齐复制条带；血海不只是静色底，漩涡不是线圈，血柱不是火焰条，蝠翼有骨膜结构；首尾不跳变；实战中心/角落、1～8倍和暂停/结束清理正确；绘制不改变快照、声音或随机数。记录实看与未试听边界，未通过项继续修正。
