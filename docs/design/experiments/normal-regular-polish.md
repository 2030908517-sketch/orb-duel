# 普通球常规表现精修

范围为普通接触、拳势积累、三层待发、破阵重拳、觉醒及觉醒短程拳劲、擦肩回身追击。保留现有拳势点数分区，不新增悬浮图标；奥义、技能数值、物理与声音保持现状。复用regular-duel-art，普通球分支独立绘制，不改吸血球共用材质。

参照已实际查看的激光光刃形成/扫击序列、同化火焰current列的连续翻卷，以及CartoonCoffee二维风弹V3/V4/V7公开顺序图（来源与检查范围见normal-air-study6）。学习聚厚与薄尾、明暗和内部流动共享受力方向、形成后接上释放；不移植激光实体亮芯、金色机械环、火焰舌或侧视人物。此前拳风材质继续作为空气基准，常规技能的规模服从短程机制，精度不降为占位圆环。

普通接触在接触点产生小而清晰的压缩前缘，沿受力方向展开、剥离；拳势每增加一次有向内吸收的球面流光，过渡到当前层数的体内压力。三层全部点亮后，三片不等的蓝白压力纹持续贴着球面起伏，并有短的外缘空气剪切，使玩家不看点数也能看出待发。重击消耗后压力在约0.15秒内向出拳方向释放，球面余势逐渐消退；接触压缩源与觉醒真实拳劲共用色彩、流动速度与厚薄关系，避免两个不相关特效同时生成。

觉醒由球内压力向外短促排开，然后收回贴体流动；擦肩回身的尾流依赖本体真实轨迹，转向处展开，后段拉细，不新增瞬移或运动控制。对免疫/盾防的反馈服从现有实际结算，不凭动画补成功。

验收：四入口常规能力一致；逐层、满层、消耗在球身连续变化；轻重攻击尺度有层次；追击曲线和本体轨迹相符；命中/未命中、暂停/重开/死亡不残留；正式页面顺序采集与受影响专项，必要时修正再观察。保留源码快照于work/normal-regular-20261029/。

## 六项最终方向与连续叠层环

创作者要求六项全部优化。当前规则取代上文“三片分离压力纹”：一个连续的压缩空气环，从顶部顺时针按拳势/3填充，0.5层为六分之一周；内部三个压力起伏属于同一环，不留分段缺口。增量按实际变化平滑汇入，满层保持连续流动，消耗时整环沿释放过程退去。原点数与觉醒虚线圈保留。

重击改为近身窄而厚的压缩面，在接触处短促挤开；不再放出与拳劲相似的大团空气。源球有很短的纯视觉出拳形变，真实位置不动。拳劲保持真实实体坐标、伤害与速度，出生时露出较薄前缘，随实际行进展开，重击变淡后成为视觉主体，不新增等待时间。追击使用实际轨迹的平滑尾流和转向外侧空气剥离，结束后延续0.18秒淡出，并平滑接回普通拖尾。

觉醒常驻为球面内部的低频蓝白流纹，区别于外周资源环与虚线圈；觉醒瞬间的实际回血另有青绿色贴体汇入，仅读取此次真实恢复量，不恢复或改写生命。继续复用已检查的光刃/同化火焰完成度及二维风弹的聚厚、薄尾和受力方向，不采用实体刀刃或火舌造型。备份before-six.js保留上一版。
