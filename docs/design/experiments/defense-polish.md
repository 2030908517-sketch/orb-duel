# 王城与旧债：奥义表现优化

2026-10-27。只重做表现，保留王城真实边界、盾与时序，以及旧债真实弹道、命中、牵返、预判和音效。护盾要呈现有重量的分层盾墙：沿真实边界逐段升起并合锁，内沿亮线连续，收缩时能量向内流，回收时碎片沿原轨迹离场。墙面采用暗青实体与青金薄边、局部六边结构，主战场保持可见；盾量变化不伪装为护盾额外获取。

实际修改盾墙亮边、局部层次和连贯承重线，反伤清算锋增加跟随真实弹道的尾迹，前摇加入收束纹路，命中碎片改为沿命中方向裂开。1倍速中心场景实机采集两招完整阶段、无页面错误，修改前后同场景阶段时间线与声音请求一致。画面复查发现王城仍存在明显重复盾片，反伤高潮的规模和造型仍不足以达到光刃/同化火焰的创作者确认标准；本版仅为未完成候选，不得标为品质验收通过。未人工试听，未开展平衡或长期性能验证。

旧版专项截取运行时遇到断言失败：现有伤害结果增加了 `hpLoss` 和 `deferred` 字段，旧测试仍要求对象完全相等；这是旧夹具与现有返回结构不一致，不能声称该专项通过。没有修改战斗实现或为通过测试而删除结果字段。

## 第二轮重设计意图

退回上一轮：城墙仍是等距复制盾牌，清算仍是小箭头和细链，既不够庄严也缺少能量重量。王城改为连续分层城墙与四个锁定角塔：基础暗面、逐段金属楔形装甲、稀疏盾徽、内沿薄能量屏障形成完整结构；升起、向内推移、闭锁、扩张均随原边界与阶段变化，角塔只出现在真实边界四角。反伤改为不对称的多层裂隙与长锋，亮芯从身体真实朝向聚合并沿实际弹道释放；命中后让裂纹在真实接触点向两侧及后方张开，锁链仅随真实牵返出现。保留声画时钟及所有玩法；实际核对中心与边缘，重点看完整动作和画面遮挡，比较光刃和火焰基准。

## 第二轮结果（仍待品质验收）

第二轮把重复小盾片改成连续墙体、三段嵌合装甲和角部锁柱，补充内侧光幕与闭锁脉冲；反伤清算锋增加分层亮芯、真实轨迹尾迹，命中增加方向性裂开光幕，蓄势增加向攻击方向收束的裂纹。正式页面采集中心成功场景，逐阶段截图已检查、无页面错误；落空场景确认没有命中音效。中心场景与本轮前基线的阶段时间线、声音事件及结束状态一致。仅检查有序帧，未能确认完整速度下的审美和音画主观质量，未试听；不能因逻辑检查通过宣称达到光刃与火焰的质量标准。墙体仍偏规整，反伤蓄势仍显得线条化，需继续实际播放和打磨。

## 第三轮：推翻不合格候选

第二轮的城墙在画面上仍像普通矩形边框，缺少堡垒的体积与阶段高潮；反伤蓄力依然以尖线为主，缺乏承受伤害后集中返还的能量材质。本轮重画大型盾形墙面、锁柱和能量推进，用真实墙边界驱动，不修改边界；反伤以重叠的撕裂能量面和亮芯替代简单线条，命中时展开具有方向性的裂痕与碎片，锁链仅对实际成功牵返可见。继续按已存的盾面/链节参考与认可的光刃、火焰基准复查。

## 第三轮修改和检查

将墙体增加更厚的分层装甲、盾形徽记、立体加强肋及围绕真实边界的光层。反伤蓄势删除两套重叠的旧线条，重新绘制逐渐汇聚的半透明裂隙面、内部断面及高光；命中增加真实接触点向前延伸的不规则裂纹，牵返链换为交错链节及沿链流动的光。第一版出现规则长角和盾墙光层硬边，已重画裂隙并将光层改为渐隐。正式页面实际查看了中心、靠边和命中关键帧；采集了完整录像但没有对连续播放做主观验收，也未试听，不能仅凭关键帧宣称已达到视觉基准。
