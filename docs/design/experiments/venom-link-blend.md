# 毒雾连接衔接与毒标视觉重量

沿用三态绿色卷片材质、世界坐标密度和已确认的二维明暗；不另画规则连线。两片雾配对后，先保留原先各自的雾面，0.55秒内由两侧边缘向中间伸出稀薄卷片，接触后逐渐加深到既有连片材质；主体纹理交叉过渡，避免配对瞬间切换整片轮廓。动画以模拟时钟驱动并只写表现缓存，暂停不动，重置/重新显示时正确初始化；实际配对、连接带判定和共享消失时刻不延后。临时隔墙恢复后重新出现柔和连接。

毒槽仍4个固定分区，不动圆点、间距或其他标记。仅将菱形权重1.19减至1.05作为首轮观感校准，比较实战尺寸及放大实画中的2圆2菱与3圆1菱，不以外接框或面积数值代替观察。沿用既有四入口层数/只读检查，采集0到0.55秒衔接、实际原速和0.25倍，检查已成熟雾、浓缩转雾后配对和暂停。必要专项通过且实画无硬切后收尾。
