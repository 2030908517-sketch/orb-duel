# 天使转向与实体持械动作

目标：替换固定正面的剪纸天使。创作者明确要求以原二维插画为主，仅在侧身和攻击时有2.5D前后关系与透视缩短。保留原头部、羽翼和服饰轮廓；肩臂与握持点使用深度坐标，身体只做浅转向，不制作低多边形模型或常态全三维转身。维持已确认的白金代码色块、圣剑/圣枪和半透明虚影身份，不引入依赖或贴图模型。

动作按原时钟：圣剑先回肩蓄势，躯干反拧；挥出时胸肩先转、手沿弧线送出，剑刃轴随握柄一起运动，随后随惯性收回。圣枪先引到身侧，枪尖对准，躯干前送和肘部伸展共同把枪推出；沿原轴抽回再回待机。非攻击手一直持械。手掌为武器父节点；肩根为上臂父节点，拒绝固定握点上的武器自转。可跨身动作不再套用旧版“手必须永远留在同一屏幕半区”的限制。

身体转向不改变任何战斗瞄准。保留剑/枪原前摇、锁定、有效攻击窗口、真实判定、范围和伤害；超出小型实体兵器范围的原判定用连接至实际轨迹的圣光表现。守护、白火、回血、音效、版本和角色范围不变。中断时只平滑回收视觉姿态，不能延长技能。

参考：LPC Extended Weapon Animations的挥斩/突刺前后层关系；此前看过的Coello圣米迦勒画像用于肩臂持械关系与圣兵风格。Spineboy官方瞄准示例用于“头、胸、前臂共同瞄准”的控制思路。GDQuest浮动剑示例只能参考蓄势和收招节奏，不能再用作本次人形挥剑依据。实际查看的图帧与未看部分在收尾记录中分开说明。

验收：浅侧身及转向跨角度不翻面跳变；手臂连体、骨长稳定且握柄固定；挥剑手掌有弧形位移、胸肩有反拧/释放，刺枪有明显沿轴前送/回抽；远近遮挡顺序合理；普通尺寸可读；渲染不改战斗快照，暂停不继续转身；保留原攻击时钟并验证四入口加载。


后续确认：创作者否决了低多边形全三维候选，要求大部分时间保持原二维画风，并明确不要透明角色或暴露拼接色块。正式版本恢复原二维天使，完成形体按不透明方式合成，衣袍和面部改用连续渐变/曲线轮廓；转向仅用浅侧身与分层遮挡，手臂深度动作和武器透视单独保留。粒子消散及法阵辉光不是实体拼接的替代品。
