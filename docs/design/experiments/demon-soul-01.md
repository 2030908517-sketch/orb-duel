# 灵肉分离 / 冥契·夺魄在握（2026-10-21）

目标是让观众看懂“爪抓的是谁、魂属于谁、为什么下一爪落空”。魂身保持宿主的小球轮廓和图案，以半透明冷白内层、宿主色薄边与恶魔红色拘束爪区分肉身；不画第二条血条。魂绳仅连接宿主与魂，细暗底衬亮芯，近身时不增加遮挡；归体时轮廓沿绳方向碎成少量尖片收回，不产生爆炸。

普通爪沿用裂隙、实体爪和锁定路线的表现语汇，先张指、伸爪，真实实伤后灵魂才从肉身剥离。未命中收爪、盾挡薄膜、免疫消隐和成功撕离分开反馈，不能播放同一成功重音。两门接力而非同时齐射：第一爪确认后，另一侧门才出现第二条预警线。锁点后线不再追魂，魂移动导致抓空必须可见。

奥义用固定的巨爪掌心建立拘魂点，0.55秒蓄势时掌指依次收拢，灵魂到位后才启动对侧收割门。宿主反击使魂身向肉身实际回移，掌指随之松开，魂绳逐渐拉直；不添加常驻回收资源条。实际拘魂成功只强调一次0.08秒；普通抽魂≤0.035秒、处刑≤0.065秒。伤害、防御、世界秒计时由战斗负责，渲染不得反向驱动。

声音复用已校准恶魔声纹：裂隙低频上扬、撕离短促粗糙瞬态、锁扣绷紧金属尾、处刑下坠重音；无伤归体复用轻的既有状态音，不使用处刑重音。没有试听接口时只核对请求及混音策略，不宣称听感通过。
