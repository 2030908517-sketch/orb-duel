# 神圣圣域：天使审判（2026-10-23）

意图：让圣阵成为有明确守护者的领地。天使是白金色、长发与冠饰的人形上半身，羽翼从肩胛伸出；低饱和暗面托住白亮羽尖，待机半透明，举剑和护翼时提高实体感。尺寸随阵半径变化，法阵固定在地面，不让主体整张等比缩放充当降临。阵纹先分段刻亮，羽翼逐片展开，身体从下向上显影。

动作链：敌入阵→抬剑反向蓄势→宽弧挥砍→腕部收招→枪尖聚光→短锁线→高速直刺→收枪。剑负责宽覆盖，枪负责集中可靠攻击；出手后都不追踪。真实伤害只在武器扫掠触达时进入已有伤害系统。受到有效伤害/吸盾且本体在阵内，守护优先打断审判：羽翼收拢包围本体，圣火前沿实际向外扩散、清理合法敌弹与陷阱，逐目标驱逐和施灼伤。没有目标也没有守护时才微量赐福。觉醒全屏柱维持原算法。

形状与节奏依据（实际查看）：[RO Valkyrie多姿势图](https://static.divine-pride.net/images/spritesheets/npc/20534.png)的肩翼、长发、持剑、合翼和羽片消散序列；只学轮廓与关节，不复制像素资产。[Pipoya法阵展示](https://fantia.jp/products/37462)实际查看正面/落地多层环与逐段显现示意；不采用五芒星符号，改为神圣十字与放射冠纹。[GDQuest原作者挥剑演示](https://www.gdquest.com/library/juicy_attack/)实际浏览器播放并查看三张连续帧，采用反向蓄势、剑尖先行、只在挥击阶段出现薄拖痕、命中与空挥区分。BOOTH守护天使预览只加载页面与缩略图，未作为已看完整动画证据；独立枪刺图被站点验证拦截，枪的关节形状以已看的Valkyrie持长兵器姿势和直线突刺几何为初版。羽毛、淡光碎片沿已看多姿势图的羽片分组；圣火波沿法阵同心层级传播，不堆遮挡粒子。

声音：显形为低声泛音渐起；挥剑为宽带空气切开与短金属回响；枪刺为短聚焦高频前导、紧实刺入重音；护翼为低中频展开与圣火升腾，清理物体用短促净化声；赐福不循环播声。新声独立命名，经统一consume路径校准；未试听就明确标记。

验收：边角圆场内面积拒绝；大小两阵的体型/判定；往返移动目标的交替攻击与实际命中/落空；攻击中守护打断且不并行回血；清弹/雷/友伤/墙挡；暂停、沉默、失魂、死亡、回溯；原圣裁斜排时序保留。正式代码定点复现，连续画面与实际尺寸截图共同审核。首版数值不是平衡已通过。
