# 吸血表现06：读得清的追猎与噬心

本轮针对用户反馈放大追猎血蝠、略降扑袭速度，加强实际补印的接触感；奥义末段明确收割意图、夺血方向和收招，不增加伤害或回血。使用 game-feel-design，依据知识库 TIM-01/02/03 与既有血刃风格。

追猎最终使用九只错相扑翼的血蝠，单体翼展约增至原来的1.55倍，队形适度拉开；关节扑翼，不将整张图整体缩放。速度500降为420，最大扑袭时间按原最大距离450折算，避免仅因降速丢失追猎距离。接触才短促收拢血爪、血印压入、球体轻微视觉压缩和25ms短顿帧；无伤害、击退、血能或吸血，不用奥义级爆响。冷却10秒及无印6秒门槛不变；经典、奥义与团队共用模块。

奥义三刃不变。在真实贴身前增加0.32秒收割预兆：血痕向猎物收束，提示本体即将到场；随后保留原0.14秒化雾免伤及0.24秒近身蓄咬，避免慢放扩大敌人的逃离机会。真正咬中才有内收撕裂形、短白红切口、95ms命中停顿和低沉的噬咬瞬态；全盾/落空/无敌无成功血核。夺出的血核先在敌方位置形成，再沿弧线回到本体，回流延至1.65秒，噬咬致命时的无伤害收尾延至1.85秒，蝠翼在血流抵达时充盈，以两次心跳结束。伤害、治疗上限、判定距离、无敌窗口保持原值；蓄势和回收时长属于已授权节奏修改，专项检查沉默、暂停、时间减速和致命收招。

参考覆盖：重新检索并读取 [Torbach Sketch 51](https://realtimevfx.com/t/torbach-sketch-51/19787)，重看本地四姿态血蝠图和六帧流动序列，采用明确翼膜与疏密关系；重看 [Villalva Vampire](https://fvillalva.artstation.com/projects/gJJvJx) 已取得静帧、[Electric Red Slash](https://realtimevfx.com/t/electric-red-slash/18973) 六帧切击序列，分离瞬态切口与流动余痕；并实际打开已认可代码血刃。以上静帧不冒充完整视频。[Riot可读性](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/)指导形状/重要性层级；[声音主题与层次](https://www.leagueoflegends.com/en-us/news/dev/the-frequencies-of-folklore/)用于声音分工，未试听外部样本。复用上轮已观察翼膜，不新增无参考的法阵或爆炸。

验收：正常尺寸能认出血蝠，实际接触才补印并反馈；末段能读出准备/贴身/命中/夺血/回收，成功和落空不混淆；普通机制三模式同步且无奥义泄漏；真实命中、治疗、无敌边界和时钟复现通过。采集连续动作、顺序帧与声音；不能以波形代替主观试听。


## 退回与重画：vampirefeel3

用户指出放大后的血影像蝴蝶，退回feel2轮廓。问题是身躯和尖耳太弱、四个近似叶片的翼膜占主导，且整体随扑袭方向旋转成竖向四瓣。feel3重画为明显头耳/短躯干/中尾，展开长骨翼和三段内凹翼膜，关节改变翼尖和肘部，不用四瓣扇动；群体沿路径移动，但单只保持可辨识的世界朝上轮廓，只作小角度侧倾。保留拒绝版本于 `tests/arcana-lab/evidence/vampirefeel2/`，不把其截图当最终成果。

重新检索到 Ocellus Bats Evolution、Van Aarde Bat Swarm 和Sinlaire Sanguine Swarm，正文可访问，但媒体请求403；Openclipart蝙蝠剪影图像请求超时。本轮不宣称看过这些媒体，也不使用这些素材。实际再次查看Torbach所附D3群蝠静帧和四姿态图，以明确头部与翼膜凹口；新形状为独立Canvas路径，符合既有代码色块风格。

非奥义追猎的初始化、时钟、实际接触、绘制和四个合成音色均来自三种模式共同模块；在经典1v1、独立奥义、2v2的实际入口各自创建确定性场景，验证实际命中、无直接伤害、友军不挂印，并保存各模式飞行/补印截图。王城专盾、旧债记录和10%拳势保底属于奥义配套，保留模式范围；未迁移团队旧奥义或改变经典生命。常规机制跨模式同步原则已补入项目AGENTS.md。

最终密度调整：按用户追加要求从7只增至9只，横向间距比feel3收紧20%、纵向收紧20%，保留单体尺寸，先画后排再画前排。只改表现，不扩大实际补印碰撞范围。

已实际打开最终9只血蝠的录屏六帧序列、放大/实际尺寸三翼姿板、经典与团队补印截图，确认尖耳、横向骨翼和凹口可读，队形更紧密；身躯过细像昆虫的问题通过缩短尾部并明确头耳色块再修正。奥义末段实际录屏十二帧显示预兆、贴身、噬咬、血核和展开/回收翼膜的连续关系，未用长停顿充当整段动画。
