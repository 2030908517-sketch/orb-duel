# 恶魔奥义第三版：连续焚契与火幕揭晓

2026-10-26。创作者明确允许放开增加特效；目标是更大、更连贯的地狱火演出。保留前两轮未提交工作及修好的钉子拖迹，本轮前副本为work/demon-ritual-v3-before。

## 意图与方案

让观众看懂火焰从恶魔输送到魂线，烧断后转为包围灵魂的同一股火势，最后向两侧掀开，显露实际生成的仆从。主材质是翻卷的暗红/猩红火流，橙白只集中在烧点和火舌内缘；允许大面积局部光焰、余烬、灼烧波，但不把火画成红色激光或几张火苗图标。

0.32–1.12秒用连续采样的火带塑造窄根、宽头和沿程翻卷，亮纹由源头向烧点输运，末端脱落为火舌；魂线仍保持到原生cut。1.12秒以曲面火浪、冲击余烬和断索回抽形成峰值，火流顺势进入逆星周围。1.12–2秒由有前后遮挡的双股环绕火幕包裹魂体，保留脸部和原角色轮廓，逐片侵染颜色。1.78–2.4秒统一向外揭开火幕，跨过原生2秒spawn时刻不重新起火；2秒前画实际魂体，2秒后由原生仆从接续，余焰沿同一包络衰减。

法阵增加范围、流动亮纹和外围热浪，主星仍是已确认逆五芒星。用明暗层级和球体中央留白解决拥挤，不能擅自挪动真实球体、魂体或扩大攻击判定。仅恶魔奥义字幕在上方显示，避免底部遮挡，不改变字幕内容/时长或其他角色排版。

## 本轮实际检查

### 观察与自我迭代

沿用正式arcana.html、固定种子review-20261026-demon、原Engine/Clock/Renderer及实际Audio.consume。复用中心受控靶（双方巡航0，靶HP1000与伤害0）、保留巡航的移动靶及边缘场景，不代表自然平衡对局。每场约6秒、103张采样图，含原混音音轨，未出现pageerror。

已打开第一轮顺序帧，拒绝“光滑火带像发光绳圈”的候选（round1.jpg）。改为分段输运亮纹、非对称卷边/缺口与脱落火舌，并把折线轮廓改为连续曲线；规模不缩回旧版。已打开第二轮顺序帧、comparison-final.jpg和birth-continuity.jpg，检查更大火流、火幕展开及字幕位置。

末次复查发现原生spawn前后法阵符文采用了不同时间基准，且诞生法阵被画在实际仆从前方。已统一使用cinema=2+effect.age的时间，移除诞生时额外抬起的冲击圈；法阵和后半火幕进入底层，前半火幕保持独立绘制并对真实球体中央留白。最后打开final-spawn-check.jpg的1.962/2.012/2.062/2.163秒帧，实际仆从轮廓与中央标识可见，火幕继续向外退散，无第二次点火。中央留白仅绘制裁剪，不增加无敌、不移动球体或改碰撞体。

当前效果比第二版范围更大，焚断后转入同化的火势更连贯。仍不能把本轮审美判断写成创作者已经认可；未实际试听，也未宣称人工全速看完录像。录像是可供1倍速观看和试听的实际输出。
