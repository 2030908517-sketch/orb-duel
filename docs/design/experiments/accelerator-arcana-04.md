# 加速奥义 04：极境·环天压爆

2026-10-15。仅更新独立 `arcana.html` 奥义模式；普通球、经典1v1、现有2v2规则保留。目标是“速度把空气卷成压力壁，本体离开后空气才崩合”，不是再冲撞一次。用连续弧形运动与内压环面表达速度的后果，普通球的单向贯穿锋面不在这里复用。

## 设计与分镜

| 阶段 | 候选模拟时长 | 动作、视听与结算 |
| --- | --- | --- |
| 预兆 | 0.8s | 三段浅弧标出预计区域，短促气流向本体收束，升压声不抢命中重音；防御条件改变仍按原规则收势。 |
| 侧切入场 | 0.18s | 从真实位置沿弯曲路径接入轨道，避免直线切过敌人冒充冲撞；不造成接触伤害。 |
| 环天积压 | 1.05s | 本体领跑约一圈半，前段中心有限跟随目标，后段锁定。尾端薄而撕散，重叠气流逐渐构成暗金厚面、少量白色亮缘；不是等宽圆环。连续风啸分两次掠过。 |
| 切线脱离 | 约0.1s | 本体按切线恢复有限巡航速度，留在原位的压力壁向内收缩；音爆来自气流崩合，不在本体上爆炸。 |
| 内压命中/收尾 | 约0.55s | 实际移动环面扫到目标才伤害；接触处出现相向挤压的短裂面和碎气，随后抛飞。落空只有收束残流，不能出现成功闪光。 |

保留低血量≤40%、已觉醒、速度与距离资格、每局一次、25～32基础伤害与实际命中穿盾碎盾。环绕期间免伤且不结算身体碰撞，结束恢复常规物理；敌人仍正常运动，可退出范围或用无敌躲开。没有磁吸、全局减速或附赠墙伤。范围、跟随速度与阶段时长可实测微调，不用持续追踪保证命中。只在第一次实际命中短顿帧，不冻结环跑。

## 参考与验收

- 实际查看 [SEGA说明书](https://manual.sega.jp/sonicfrontiers/switch2/en/) 的 [Cyloop截图](https://manual.sega.jp/sonicfrontiers/switch2/rsc/img/en/40-02.webp)：借鉴头尾层次与连续包围轨迹，不采用其蓝色画风或玩法。
- 已看 [Atif爆破分解](https://realtimevfx.com/t/stylized-frag-launcher-explosion-overwatch-inspiration-breakdown-posted/1894?page=2) 的冲击/火花静帧；借鉴短瞬态、细长碎气与分层衰减，不复制火焰爆炸。
- 验收：弧线入场和切线退出无跳位；中心锁定后确实可躲；运动头尾与实际路径一致；命中造型区别于普通球；角落、无敌、破盾、暂停/重开、1/2/4倍速均检查。声音先作分层技术验证，未试听不宣称音色通过。

## 本轮调整与评审

第一轮的轨道半径82、中心跟随速度95、跟随0.4秒，指定移动对局中12次释放仅5次命中；已改为半径94、最多170单位/秒跟随0.75秒，最后0.30秒锁定。相同小样本12次均有命中，不代表必中或全角色平衡；移位、无敌专项仍可躲开。实际路径限速1000，闭环后按切线恢复巡航。

第一轮拒绝：命中复用通用星芒，削弱角色身份；改为三个相向内折的气压裂面，并移除奥义专用接触上重复的通用效果。最终关键帧及实际录像解码抽帧已审看：主体、头尾、内压方向可辨；没有把未试听的声音判为通过。证据：[录像与对照](../../../tests/arcana-lab/evidence/pair4-final/index.html)。
