# 时间球常规表现与来袭时删（2026-10-30）

## 本轮方案

保留领域、时钟、沉默及回溯的真实规则，奥义不重做。自动时删改为防守反应：只对即将发生的敌方身体接触、直击弹丸及直接攻击起手，不因站在毒池、陷阱、毒雾或持续负面状态中而消耗。手动中键同样要求来袭，只把择时交给玩家。预测使用短时间的真实相对运动、碰撞半径、视线与寿命约束；实际攻击包在伤害结算前作为漏检兜底，明确排除陷阱及DOT，不把名称里有“毒”的实体毒液弹误当作DOT。

现状问题：领域与弹丸只是同一钟面缩放；时钟缺少厚度和飞行方向，爆炸与侵蚀跳数都像扩圈；时删的等宽感水平亮线、圆环和细裂隙不足以传达“删去一秒”。采用统一的紫银/冷白时间材质，但分清行为：领域是低透明镜面、外缘刻度与慢速扫针；飞行时钟是有金属窄边和玻璃芯的实体，尾迹为收束的时间丝；爆裂是钟缘散开、指针解体，侵蚀是局部短促刻痕。领域回收反馈只沿实际回溯路径，不新造运动。时删以不规则真实旧帧切片错开、切口折射、断掉的刻度弧及一秒刻线被抽走为主体，避免透明分身、整齐扫描线和全屏白闪。全部几何只读，不改战斗RNG或时钟。

- Retimed实机时间泡截图已检索，图片访问超时，未列为已观察证据。项目已有时间回溯顺序帧可用于时间材质和真实帧处理的本地参照；不改奥义自身画面。

## 验收重点

1. 来袭才发动；擦肩/远离/遮挡/友方不发动；陷阱、破片和DOT不发动。
2. 实际攻击兜底在扣血前保护双方，不递归，不改变12秒结束起CD。
3. 所有常规表现读取原技能状态，四模式可用；奥义渲染不被覆盖。
4. 正式页面检查形成、飞行、爆裂、领域退出与时删前后连续帧，退回复制感或缺乏层次的候选。

## 实现与本轮复查

- 新增 `js/time-regular-art.js`，替换常规领域、时钟预警与飞行、时钟爆裂、领域侵蚀跳数及真实路径回收的渲染入口。金属窄边/暗玻璃芯、粗细刻度、局部镜面高光与受控时间丝组成统一紫银材质。普通扣血与沉默仍复用共享状态和伤害信息，不叠造新资源条。
- 觉醒的通用多边形改为刻环分段闭合、刻度成形、指针对齐与释放，跟随本体运动；只在 `spectacle.js` 增加时间球专属绘制分派，声音和觉醒逻辑不变。

- 自动时删在普通固定步之前观察约0.10秒内的相对运动。实际有效攻击包另作伤害结算前兜底；陷阱及破片、持续毒伤/灼烧、时间侵蚀、血链等持续伤害不触发。直接飞行毒液弹仍属于直击。时删结束起12秒CD及免伤模拟不改。
- 手动中键同样要求来袭；未按键不会由AI接管。面板显示“就绪·待来袭”，不是冷却一好就自动空放。
