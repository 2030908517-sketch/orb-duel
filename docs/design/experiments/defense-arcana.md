# 王城与旧债：奥义实现稿

范围：仅独立奥义模式新增护盾与反伤两招。经典与团队、其他角色、30%生命门槛及每局一次不变。只将这两球的奥义模式生命适配为护盾236、反伤250；经典原始生命值不变。2026-10-16。

## 护盾：王城·天垒封锁

观众应先看懂“堡垒落锁”，再感到退路被压缩，而非吃到凭空爆炸。四边各由厚重盾片组合，深青暗面、青绿主面、窄亮刃和金属嵌条形成体积；六边形只留在墙带内，中央保持清晰。边缘盾片在0.8秒内依次升起并闭锁，不缩放小图标；随后1.2秒匀滑收缩至原面积约41%，维持4.2秒，再0.75秒展开，盾片拆散回收0.55秒。每次阶段转换由同一战斗事件驱动动作、声音、字幕与时间线。没有全程顿帧；闭锁用低频机械重音，退出用滑轨卸压及稀疏金属尾音，避免把控场听成伤害。

发动即获得24点、最多4.5秒的独立专属盾。普通盾的时间与冷却照常。专属盾优先承伤，吸收与普通盾共用原压力上限；到期残盾仅入账一次，和同一时段已有波的储量合并，不能覆盖或复制。穿盾不耗专盾，碎盾摧毁两盾。墙的内沿是实际边界，囚笼和王城同时阻挡实体弹丸及射线穿透；移动墙只安全推回位置、不产生挤压伤害或动能墙伤，静态反弹保留原规则。两名护盾球同时施放共用一座王城、各有自己的专盾，不叠加缩小或延长。死亡、结束、重开可靠清理边界；画面大小始终不变。

## 反伤：旧债·逆命清算

观众应感到“过去承受的攻击，如今被收回”。球面伤痕随旧债增亮，但不遮蔽本体。停住0.9秒，数道不对称、尖锐的红色裂痕从本体展开；末段收束成有明确方向的清算锋，实际传播、可落空。它不是镜子或复制弹幕。命中时一记短促裂响加低频心跳、65毫秒接触顿帧，红色折轨与短链随敌人的真实转向绷紧；未命中只有裂轨散尽，没有成功冲击或锁链。施放压低其他声音以留出心跳位置，恢复有短斜坡，不长时间消音。

旧债上限60，只记录敌方造成的实际生命损失，扣掉这次即时返还的实际生命伤害；之后蓄能反伤弹实际命中同一债主，也扣除对应未清算债额，不能让已返还伤害再完整清算。墙伤与收束失血不计。成功清算消费最多40债额，伤害6+债额×0.28、最高18，不随无限累债突破上限。全盾、无敌或落空不消费旧债、不授予控制或预判。命中后1.35秒按有限角速度改写方向，保持实际速度，不瞬移；撞墙正常反弹并短暂保留反弹方向，免疫/自带特殊位移动作时不强抢运动控制。获得4秒内有效的一次预判机会，由已有威胁检测开启姿态，不能永久待机或直接强开反伤。结束回归原循环。

## 实装与评审（20261016-defense3）

- 战斗状态、边界、伤害和账本在 `js/arcana-defense.js`；代码画在 `js/arcana-defense-art.js`，独立音色在 `arcana-audio.js`。只有奥义入口与实验室加载这两个新模块。共享物理、射线、弹丸、飞行时钟、回旋刃、预瞄仅增加可选临时矩形，未启用时走原尺寸；电荷沿壁坐标临时适配该矩形，不写全局场地常量。
- 专盾优先吸收、共用原8点压力上限，残盾与同一待发波合并一次；穿盾保持专盾，碎盾清除两盾。直接敌方伤害按实际生命损失记债，减去实际即时返还；蓄能反伤弹真正扣敌人生命才偿还对应旧债。环境墙伤与反射回敬本身不再形成新债，避免往复记账；磁力排斥仍按原有“敌方来源”处理，磁吸偏航墙伤按环境来源处理。
- 清算命中不立刻开反伤。4秒内一次准备机会沿用原威胁检测；对于原检测未覆盖、但已经形成有效攻击包的技能，在该包扣血前消耗这次机会开启原姿态。环境伤害与无敌抵消不会白白触发。与清算同一步已经取样的其他攻击不会被追溯改写。
- 保留普通、吸血、加速、射手现有实现，经典与旧团队不加载新模块。两球仅在奥义模式适配236/250生命；未改经典生命与其他角色生命。

### 退回与迭代

第一版的反伤静止靶只证明了清算命中，不能展示轨迹重写；默认改成真实移动靶，使转向、反弹和后续迎撞可见。初版伤痕在开场直接全部出现，改为固定形状的局部揭示与亮度递进，末段再收束，不等比放大图标。盾墙回收与普通盾同时到期的波储量改成合并，并共用8压力上限，避免覆盖旧波或叠出超额压力。另发现清算超过15伤会叠上紫色通用重击，改由专属事件完全承担反馈，保留形变与强数字，不重复粒子或声音。面板保留盾量、充能、盾时、压力与波伤，奥义槽优先替换额外蓄力百分比；专盾显示自身剩余寿命，盾消失后显示王城剩余时间，缩短标签避免窄面板省略关键数值；受控者状态栏显示“逆命牵返”剩余时间。
