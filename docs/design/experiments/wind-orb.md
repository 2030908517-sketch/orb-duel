# 驭风球｜主风向与风暴天灾

2026-10-31首版设计卡，正式实装；数值与观感均须验证，不能以功能通过推导平衡通过。

## 意图与分期

驭风球不是高速冲刺者或换色风刃：它持续改变速度向量，让迎面冲锋受阻、实体弹偏航。导流锋面先有侧向流线汇入、短预警锁线，再展开宽弧压力层，前缘实际扫到才伤害；留下具有方向的风道，前后风向相交或高速横穿时才产生风切。觉醒用两股反向气旋构成会移动的交切走廊，提供主动扫过目标的机会。主色银白、淡鼠尾草绿，暗蓝灰密度面负责体积，亮脊只强调局部压力，禁止规则青色圆环、布条和全屏粒子雾。

奥义沿世界时间进行：0–0.8秒四周汇风、超屏云架下压；0.8–4.4秒层叠旋转风墙与透空风眼，切向速度占主导、有限径向束流维持环绕；4.4–4.65秒风场与音流收束，短暂静势不暂停世界；4.65秒释放真实扩张冲击锋，6秒内恢复。新奥义生命238，经典/团队118。沉默不能中断奥义，不能借此解除普通技能沉默。没有额外无敌、霸体或瞬移，风眼只降低自身扰动。

## 当前实际实现与初值

完整机制与模式在[驭风球档案](../../ai-design-knowledge/characters/wind.md)。基础118HP/8.5碰撞/218巡航；奥义238HP。首次锋面1.2秒，随后3.8秒间隔；普通0.38秒预警，横风拦弹0.22秒预警，7伤/510速度/半宽108/115风压。风切1.8，高速横穿2.6，共享0.8秒间隔；觉醒双涡8.5秒周期、4.3秒持续。奥义6世界秒，环切2.7/0.6秒、每敌22原伤预算，末击10伤/220击退。所有伤害乘热度、沿公共防御反伤结算；没有额外无敌或穿盾。

风向为有持续时间的速度场，顺/逆/横风通过向量真实影响常规运动。主风330、风道额外240、弹丸系数900/330；普通弹最多增加18%弹速，明确曲线回收/奥义实体不动；激光、固定机关不动，技能强制运动/霸体/失魂等保留优先级。普通能力被沉默时暂停准备，已释放风道仍正常流逝；奥义沉默豁免，未清除普通沉默。时间飞钟对风的普通冷却通过原waitingAttacks接口延后0.5秒，不改时间球规则。

## 实际自审与退回

1. 首次观察到锋面尾流等距平行、飓风像平放的环碗，拒绝。保留当次采集记录描述，重做从超屏云架向下垂落的锥状螺旋结构，尾流拆成不等距/不同长短的密度束。
2. 第二次观察到飓风过密线框，拒绝。增加按真实风场阶段推进的确定性流体密度层，减少主体压力脊与轮廓线；分开前后风墙、细流丝、稀疏卷入碎屑。材质运动不依赖战斗RNG，176×184缓存以30Hz刷新，非全场逐像素高分辨率计算。
3. 继续修正形成：云架保持高处，风墙由上向下展开，而非整个完成图等比放大；收缩前冻结旋转姿态但不冻结世界，终击用有宽度与密度变化的扩张压强环，避免仅一根细描边。
4. 实际游戏尺寸阶段图可区分预警、宽弧锋面、留下的风道、移动双涡与交切带；奥义可见超屏尺度、内外明暗、中心透空和回缩/爆发，不用大量青色粒子覆盖小球。主体体积与材质按已打开的光刃/火焰/pressure12参照审查；这是制作自审，不替代创作者最终喜好。

## 2026-10-31 第二轮：风力收敛、全套美术重做（已实施）

创作者认为现有全部风效不够好，尤其觉醒双气旋；不将上一轮制作自审当作创作者已认可。明确退回：双涡过密螺旋线像等高线，中间粗S形连接像胶带；锋面与风道仍有复制平行线感。减少敌方持续偏转/增减速，但保留敌方受影响大于驭风球的差异，伤害、击退、冷却与命中范围不改。

本轮以流动密度层、断续压力脊和局部细流重构；双气旋各有透空内核、卷入与剥离，中央由相向卷流形成清楚的交切窄带，取消实体S连接。锋面用连续弧形空气压缩体和不规则尾部；风道保持低对比、间歇性流动束；奥义同步统一材质，避免线框、软胶和厚实实体风刃。沿用已实际查看的pressure12与专业风效逐帧，补检二维游戏动作序列；来源打不开则不假装已观看。只以实际本轮画面确认质量，数值/渲染分别验证。任务起点备份位于work/wind-role/polish2/before。
