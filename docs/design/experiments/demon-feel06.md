# 恶魔局部表现06：爪、撕裂与留钉

意图：魔爪是有掌骨、长指、钩爪的抓握器官；撕裂则是魂球本身被横向扯开，两者一眼可分。穿刺成功留下实体钉，明确解释为何肉身/魂身仍被定住，直至该控制解除。普通觉醒穿魂失魂由0.8改为1秒，奥义穿身及魂仆死亡3秒不变。

已实际查看：CraftPix俯视怪物逐帧表（攻击前展臂、收拢、收招的轮廓变化）；80.lv的Hades特效分解静帧（深色实体缺口、窄亮边与有限碎屑）；补充查看PNGWing长指魔手静态剪影（掌、四长指及拇指的负空间）。只借结构与节奏，不复制素材、写实纹理、紫色调或四臂怪物。ArtStation手部作品被访问检查挡住，Sol Cesto图未加载，均不算已参考。已再次查看用户认可的代码血刃锚点。

魔爪重画为收窄手腕、暗色掌心、四根不等长分节手指和独立拇指，骨节用有限红色切面，尖爪只保留窄亮缘；张开与闭握改变手指关节，不等比放大代替抓握。保留现有飞行、预警和判定。

触魂撕裂：实际魂球命中点出现两侧错开的半透明原角色残像，中央不规则暗裂口与亮切边短促爆开，少量魂片沿撕裂方向飞散，再收束。绝不画手爪。只在实伤时强化视觉冲击与现有震屏，沿用校准的抓裂音、单次短顿，不增加伤害、冲量、CD或高频音轨。

钉子驻留从瞬时特效寿命改由真实失魂状态决定：肉身钉跟肉身；魂钉记录被穿刺魂的位置，跟随其实际位置；控制结束、霸体解控、清理时一起消失。该改动不把魂球改成新物理单位，也不额外冻结魂球运动。

检查：普通抓握展开/闭合、触魂实伤/免疫、穿魂1秒全程留钉、穿身3秒留钉与解控消失。以正式渲染器受控时间序列检查小尺寸，发现重复钉形/图案遮挡即修正。无音色修改，不声称人工试听通过。
