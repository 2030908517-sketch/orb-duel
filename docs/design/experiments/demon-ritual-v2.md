# 恶魔奥义表现第二版：焚契与叛主

2026-10-26；基于正式运行代码及本轮前未提交的激光第三版。只优化恶魔独立奥义表现，不改玩法、版本号或其他角色。

## 意图卡

让观众清楚经历“灵魂被夺走→肉身被钉住→恶魔瞬身施刑→联系被地狱火烧毁→灵魂受侵染→仆从诞生并叛主”。高潮集中在焚断与同化，使用暗红实色火焰轮廓、猩红中层、橙白高温内焰，辅以余烬与低亮烟影；不把火焰画成红色激光。保留原角色灵魂的轮廓和原色，只有同化阶段逐片侵染。大型火焰和法阵可以占据局部战场，但必须看懂真正的魂线与目标。
