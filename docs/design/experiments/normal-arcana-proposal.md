# 普通球奥义表现优化构思（未实施）

2026-10-26。用户要求先完成恶魔调整，再构思普通球；本页仅为建议，没有修改普通球代码、数值或正式机制。依据当前arcana.js的blink/punch、arcana-art.js的lance/impact及正式normal场景采集：现有瞬身后0.6秒定格蓄拳，静态两条弧形蓄势线变化很少；冲击集中在近身小范围，底部字幕可能挡住靠下的攻击。已看关键帧，不声称审美/音效通过。

## 核心方向：瞬身破阵，一击贯场

普通球的身份是近身武术与空间突袭。保留无视距离瞬身到敌后、短距重击与真实击退，不改成激光、音波或巨大拳头召唤。场面尺度来自这一拳造成的定向压力传播及后续运动，不能靠凭空增加远程判定或墙伤。

1. 消失与到位：起点残像短暂保留，目的地骤现；尾迹按真实起终点组织，避免长串圆饼。短暂同时读到旧位置和敌后新位置，突出“防线被穿过”。不把装饰轨迹说成真实多段位移。
2. 定格蓄拳：沿现有约0.6秒蓄势，用可在顿帧期间前进的既有表现时间推动；先快速收身、随后定向气流向近身发力点压缩，最后极短绷紧。球体轴向倾斜/压缩与金白锐边、蓝白气压层相配，避免静态等待，不另加战斗时停。
3. 短打爆发：实际命中一刻，球体骤然回弹、短促拳压贯过接触点；视觉核心保持贴身。环状冲击前沿沿真实击退方向扩展，宽阔空气层逐渐卷开，形成大面积但有主轴的后果。外围是表现，不是额外全场攻击。
4. 后果收束：沿敌人真实位置绘制拖迹和撕开的气流，确实撞墙才出现墙边冲击；不中、被挡、免疫分别用已有结果反馈，不能提前绘制成功爆发。主体停留片刻收势，让敌人飞出建立力量对比。

字幕移到不遮挡交战的区域；优先增强方向、发力姿态和压缩到释放的连续变化，不复用恶魔法阵或激光实体刀。音效拟为瞬身短裂响、收束的低频吸气、命中的硬瞬态与低频拳体、稍后的宽气浪；主重音必须跟随真实命中。

实施前需按项目规范补查适配二维武术瞬步/短打/气压传播的动态参考，不能将本页构思称为已参考验收。需要受控中心、贴边、被挡/落空及移动目标观察；伤害、强击退、命中范围和原时停规则默认保留。若需要改变真实位移路线或延长定格，须作为另行明确的机制调整。
