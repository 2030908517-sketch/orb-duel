# 射手球逐颗装填与弹种切换

实际弹匣和面板在装填期间按0→1→2→3更新；第三颗在总装填时间90%时完成，保留最后10%的闭锁等待（觉醒前0.52秒、觉醒后0.4秒）。装填截止时间和开火条件不变，未结束不能射击。狙击单发同样在90%时入匣。

沿用头顶圆周排列与普通弹药造型；狙击弹使用更尖、更长的弹头及壳底，适当补偿视觉重量。三颗↔一颗切换用0.28秒收拢/展开、淡出/淡入及缩放，模拟时钟驱动、暂停冻结，绘制不能改战斗状态或随机数。每颗入匣轻微弹入反馈，三颗都必须在正式开火前可见。沿用当前图标风格，不新增音色或外部素材。

检查：实际弹药与面板/图标一致、最终等待、觉醒前后、狙击双向切换、时间延缓及回溯冷却、沉默不提前开火、三入口运行和真实浏览器连续动作。
