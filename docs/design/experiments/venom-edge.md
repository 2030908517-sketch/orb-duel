# 毒池/毒雾边缘裁切修复

沿用既有血浪厚度与绿色矢量密度风格。本轮定位单雾的固定多瓣clip：它比真正雾密度外沿更小，将活动雾片直接截断。改为只保留外部安全边界与墙体遮挡，实际雾沿由自身密度逐渐减至零；低密度外沿分层更稀薄，主体不变。液体上缘微高度投影原先被地面半径裁断，外安全界仅放开高度的表现余量；墙体限距保持。接地边缘改为窄幅递进半透明裙边，减弱整圈描边感，破泡涟痕到边缘前先减弱。没有使用整团模糊、不改判定半径或连接/施毒/寿命规则。备份后定点对照普通、浓缩、单雾/连片、贴墙及转化，检查绘制只读、暂停和前后状态声音一致。
