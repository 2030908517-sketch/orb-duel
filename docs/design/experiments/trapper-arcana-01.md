# 陷阱球：机关置换与诡匣·替身收监

观众应看懂两件不同的事：普通置换是两个机械环锁定后交换现有对象；奥义是撞上替身、被关进倒计时机关，而真身已在远处重建网络。采用已有清晰代码色块、钢铁暗面、少量橙金亮边。普通节点与线保持偏红，中枢有厚底座、齿轮、四个张开的锁扣，不能只画成大地雷。

## 玩法与阶段

普通节点上限5，觉醒7；寿命10秒、布防0.55秒、常规连线180、捕获0.3秒与拉不到保留/拆除/过期返还保持。布雷间隔基础2.1秒、觉醒1.45秒，使寿命内确实可形成密网；基础爆炸9降为4.2，近邻85内可有限连锁、后续爆炸系数0.5。同一0.8秒连锁组对每敌最多两次爆炸、原始伤害最多8.5×热度，四枚低伤破片各0.45。独立的较低破片预算避免变成射手；实际碰撞、护盾、反伤和无敌继续走原战斗系统。

机关置换CD8秒，从活着未过期、未预约引爆且球体可合法落点的节点中选离当前敌人最远者（包含未布防/捕获节点，状态和寿命不重置）。与球交换位置，不额外伤害或部署。双环0.16秒显出，位置瞬换、原地短影、传输细束0.2秒、线张紧。碰撞反制在本步优先，普通置换放在身体碰撞流程后处理。

独立奥义模式陷阱球生命232。觉醒且生命≤30%进入待机，正常布雷/置换/运动；沉默不阻止奥义，真正有效身体碰撞才消费一次机会，替换双方本次普通身体伤害。真身使用战斗种子从远处合法候选随机脱身；敌人位置展开128×120钢架囚笼，实际墙从接触时生效，演出支架0.28秒翻折闭锁。囚笼与炸弹同一3秒时钟，每秒3/2/1音画提示，最后只做锁扣收紧的演出，不持续压缩判定。归零解除边界并提交一次18基础伤、明显击退的爆炸。无敌可抵消爆炸，护盾与反伤正常结算，爆炸不含独立伤害碎片。真身同时部署唯一中枢：7.2基础伤、0.3秒布防、12秒寿命、计入上限，满额替换最老普通节点；与所有可合法连通普通节点连接，仍可拆除。奥义不迁移到经典或旧团队奥义。

所有新建/重布线使用当前位置建立接触基线，不把瞬间跨过敌人算扫线；已在线上的敌人需先离开再真实触线。普通节点直撞、动态线、既有捕获继续工作。节点中心最小间距70，冷却就绪但太近时等待，不消费布雷；置换不把节点塞进其他节点。囚笼以内壁限制指定敌人，外壁也阻挡施法者及其他外部球，死亡/重开/结束会解除，已部署囚笼不因施法者沉默凭空消失；施法者死亡则解锁且不追加伤害。物理边界与王城取交集，虚化和高速运动仍不穿越墙界。
