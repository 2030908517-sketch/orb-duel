# 吸血球奥义 · 细弧刃完整演出

## 实施意图

沿用[用户已确认的代码绘制风格](../STYLE_ANCHORS.md)。观众应读到：血液沿三个方向形成刀锋，包围收拢造成真实切割，夺得的血液返回本体。冷峻、锐利、有压迫感，避免写实素材突然混入简洁 2D。

仅改实验室内吸血球的新演出。正式引擎、伤害、护盾、无敌、预瞄、弹丸位置/数量、攻击时序、回血和普通球/加速球的演出保持。旧正式演出仍可切换。新场景只是训练夹具，不能导出为正式属性。

## 阶段与通道职责

| 阶段 | 视觉 | 声音 | 规则锚点 |
| --- | --- | --- | --- |
| 预警 | 本体血流收束，三处完整尺寸的局部刀锋逐段显形 | 低心跳与克制的张力，避免提前爆响 | 正式 warning |
| 凝刃 | 认可的细弧刃分层补入，保持大小；尾部晚于锋面 | 短凝结声，留下合拢空间 | 三颗实际弹丸创建 |
| 合围 | 三个真实位置、独立朝向；短暂刀气带，尾部跟随 | 一轮掠切起音 | 实际 launched |
| 命中/防御 | 按真实命中方向产生锐利切口；无敌无成功反馈，护盾吸收单独表现 | 命中厚切声，防御不冒充血液撕裂 | 正式 combat.hit |
| 回流/恢复 | 血带从实际命中点回流，实际治疗数值；尾部收掉 | 回流声低于切割声，音尾承接恢复 | 正式 heal |

实际模拟时序沿用现有回放，长的是预警/形成，短命中驻留用于确认；不另外对每一刃增加真实停时。

## 参考与选取

主视觉锚点为项目自己的细弧 SVG，不再寻找风格不同的替代成品。[Riot 的清晰度说明](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/)用于方向、主体和信息层级；[Geri 的斩击分解](https://realtimevfx.com/t/electric-red-slash/18973)用于主形与遮罩分工。仅查阅可访问正文，不宣称观看嵌入视频。采用制作思路，不复制素材。

### 已主动退回的候选

首轮实际打开命中/角落有序帧与护盾关键帧后退回。凝形放在球体上层，角落看不清目标；大刃尾在边缘硬截断；命中切口是大硬折角；角落两次伤害数字重叠。保留 `rejected-01` 图像及理由。

修正：固定尺寸略收拢；凝形血刃放在球体后，飞行和接触在前；装饰尾部在边界淡化；切口改为窄弧面及少量血流；同轮累计数字。落空和取消都有短退出。随后用 18 个有序帧检查凝形到出手的衔接，去掉叠加缓动，减少“细线突然变完整”的突变。

### 本次验收

| 维度 | 实际证据与判断 |
| --- | --- |
| 造型/画风 | 已看：认可 SVG 与实际凝刃关键帧。运行时直接导出同一组矢量路径并校验 SHA256，深红块面/细亮刃/撕裂尾保持，无写实或生成图混入。达到本轮风格一致性门槛 |
| 形成 | 已看：局部锋面、补入、保持到发射的 18 帧。整把刃的显示缩放不随凝形进度改变；先画锋面再沿弧补入厚度，尾部随后出现 |
| 运动/结果 | 已看：有序源帧与 1× 实际录像解码帧；实际三弹朝向、运动与源片一致，切口先于回流。尚不把这些帧检查等同于人类完整连续观影的主观体验 |
| 可读性 | 已看：角落、移动靶、窄屏。角落凝形时目标保持可见，数字不再重叠；边界只淡化装饰，球体与判定不变 |
| 取消/落空/防御 | 工具与帧检查：取消不生成三弹，虚化/落空无伤害与治疗；护盾承受 30、生命伤害与治疗 0。实际录屏的防御声不含命中/吸血声；落空无命中/吸血声 |
| 音效 | 重做预警、凝形、合拢、命中、回流五层，另有护盾声；实际混音可解码、无削波。没有主观试听能力，音色与音响力量感不宣称通过 |
| 技术/兼容 | 68 项专项断言；本地文件和 HTTP、1440/390 宽浏览器运行；调参不能改变完整源片、真实弹丸不复制；不做全角色平衡结论 |

这是达到本轮已观察视觉标准的实验候选，用户尚未确认采用。风格一致不意味着每种主观口味都已通过。尚未试听、未做真实对局适配的项目明确保留；没有把暂未观察部分算作高品质完成。
