# 回旋刀声C：真实录音与分析再合成

仅处理throw/return/returnHit/moonCut。保留A原声、B合成沙噪候选与Git原始节点40c05d5、B节点80ad407，不覆盖旧实现，默认仍A，C等待用户试听。

来源：StarNinjas《20 Sword Sound Effects》（https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes），作者说明由两把刀运动录制；CYBERDEViL《Machete vs. Spatula》（https://opengameart.org/content/machete-vs-spatula），作者说明为金属铲敲击砍刀原始录音。两页标CC0。原始归档、单个WAV、SHA-256保留于聊天work/blade-audio-reference；不使用商业游戏提取音频。此处没有宣称已经听过素材。

方法：实测12个录音的有效片段、5ms能量包络、STFT、局部峰与平坦度，选择有清晰攻击及稳定金属余振的片段。实际刀声主体保留，不再用白噪声代替刀锋；从砍刀尾部提取实测模态频率与衰减，仅作小比例共享材质补充，不主导声音。适度降低小刀音高、裁掉冗长尾部、按出手/回收/切入动作整形，保留原始接触瞬态。风感沿源录音纹理处理，不新增大片噪声，不加超低频重拳或长混响。程序化部分由测量参数驱动，明确区分录音处理与纯重合成。

四声：throw保留刀具掠动的渐起并加入短次级掠过，表达旋转；return用一次更宽的弧形包络，避免“滴”式提示；returnHit保留录音切入瞬态与短摩擦，收尾干净；moonCut用更厚的实录纹理与短余振，避免变成敲钟。最终命中时序仍由原战斗调用控制，不改轨迹、命中或伤害。

C将导出标准WAV及嵌入PCM，保持file://离线入口可用，播放只读缓存；C独立校准，与A/B等基准对比。游戏切换和独立按钮增加C，旧A/B继续可选。验收包括真实输出峰值、频段/包络对比、旧声保留、同场战斗快照/声音事件一致、三个入口与加载性能；不以频谱图代替听感验收。

## 本轮结果与限制
- 实际下载StarNinjas刀声包（149512字节）与两段原始金属WAV，保留下载URL与SHA-256。分析了10段刀声及2段金属录音；查看了实测波形与频谱图。并未实际听过这些录音，选材依据作者描述与信号结构，最终声音身份仍待用户确认。
- 从砍刀录音尾部拟合到约6038、6472、5578、5092、4487Hz共振与约39～120ms衰减。C保留真实刀声主体，并以这些实测值降调重建少量共振；不再生成白噪声当刀声。时频纹理分离保留窄带余振、压低弥散摩擦，保留前18ms接触瞬态。
- 采用刀声4/1/6/8，分别用于throw/return/returnHit/moonCut，裁剪和处理参数见assets/audio/blade-c/processing.json，来源与CC0说明见同目录SOURCES.md。输出24kHz单声道PCM并内嵌JS，file://无fetch或解码失败风险。
- C四声时长约236/283/178/281ms；真实Audio.consume输出相对碰撞0/−3/0/+1.5dB，不逐段归一化。独立输出峰值约−22.4/−23.8/−20.7/−17.6dBFS；同场C对战峰值−4.23dBFS，密集样本−11.0dBFS，无削波。高频比例记录仅作诊断，不能证明实际不刺耳。
- 同一10秒实战A/C快照及事件一致，四声各有3/3/2/8次请求；导出A/B/C各四个独立试听及三份同场实战WAV。所有原声音实现与B模块字节未变；旧四声A逐样本差异为0，其他236个音色定义未变。
- 三正式入口A/B/C各12个试听按钮、外侧切换、切换/关闭清理及手机布局通过；实际打开390宽截图检查。C已生成PCM准备缓存约0.1ms（非首次素材处理耗时）；播放仅缓存缓冲源与声像节点，无实时FFT。没有宣称长期帧率或人工听感通过。
- 原声音政策294项、回旋158项通过。C作为新增候选不自动采用，默认A；音色好坏、锋利度与舒适度由用户试听决定。未改伤害、冷却、轨迹、命中或版本号，未上传GitHub。
