# 加速球奥义：超速·动能轮回

2026-10-18。只替换独立奥义模式的持续挡位；奥义生命值保留220，经典108及团队现值220不动。全局觉醒、≤30%生命、每局一次、沉默豁免沿用。

## 意图与动作

观众先看到速度从本体转移到敌人，再看到静止的本体等待高速回归，最后在零距将积蓄动能炸开。与觉醒单次撞击的区别是交换运动角色、真实多墙反弹和双向收尾，不再制造另一种追踪冲刺。

|阶段|玩法与表现|
|---|---|
|准备|低血觉醒后待机，下一次觉醒冲刺实际身体接触合适敌人时消费。未命中保留机会，不消费普通冲刺CD之外的资源。|
|交出动能|替换本次普通双向接触包，本体速度归零；金白残影沿接触方向转交。敌人900速度，按预先计算的镜像台球路线真实反弹，通常3～4次墙撞。|
|高速回归|不逐帧追踪；按墙面法线反弹，最后270单位沿既有反弹路径连续减速，约0.6秒由900降至零，再在本体前停止。墙伤调用正常动量墙伤，限制有效次数，不额外叠加奥义伤害。|
|零距制动|到达两球间隔约8单位处截停，没有接触伤害；减速开始时从敌人体侧抽出动能，汇入两球之间的狭长压缩核，停稳时达到峰值；0.12秒全局定格后立即释放。声音在减速起点开始收束。|
|轮回爆发|中心亮核裂开，横向撕裂压力面和薄冲击壳向外扩散，双方反向900飞出。敌人仅追加一次墙伤，本体首次撞墙无伤并恢复正常巡航。|

当前结算（kinetic3）：全模式觉醒冲刺倍率由0.65+0.85×速度比平方降低为0.65+0.50×速度比平方；满巡航365、900速度时基准伤害15.456（原20.16），随机浮动、蓄力、加热与防御仍保留。奥义起手直接调用同一次普通冲刺伤害计算，不再固定6点。后续逐次进入Characters.wall，按质量与实际撞墙法向速度计算正常失衡墙伤，不附加2.6或7点独立伤害；最多4次回归墙撞及1次最终墙撞。最终反弹保留0.75秒惯性衰减，本体首次撞墙后0.24秒内巡航升到365。起手等待保护状态、路线合法性及死亡清理规则保持。

### kinetic2：回归减速与凝聚延长
回归最后270单位按连续减速曲线由900降至0，正常时间流速下约0.6秒；停止后的动能凝聚延长至0.85秒，原0.14秒定格不增加。球体拉伸随实际速度回落，原路线、墙伤预算及最后900弹射保持。新增连续减速与时长断言，专项2607项通过；已复看正式游戏录像12帧顺序抽帧，页面无异常。复用原校准声音，未做新音色或批量平衡测试。当前录像与采集记录已替换为kinetic2。

### kinetic3：伤害与反馈接回正常规则
2637项专项断言、139项优先级与268项音效政策检查通过。起手仅滚动一次普通冲刺伤害；250/550/900法向速度逐项与原Characters.wall实际输出比较相同，且没有第二份墙伤包。确认最终反弹速度仍大于500并存在惯性、恢复365、停稳/凝聚同帧及无额外冻结。正式三个入口的定点敌对冲刺命中均使用1.15倍率，团队队友无伤、立柱正常阻挡反弹。已检查正式录像12帧顺序及页面无异常；正常墙伤配正常重击，最后墙撞复用已校准arcSonicHit及0.08秒命中顿帧。新录像音频峰值约0.597，无削波；未人工试听。没有批量平衡测试。相关证据已更新。

### kinetic4：减速与回流同步
意图：看清敌人的动能被抽到两球之间，而不是停止后另起蓄力。回归末段约0.6秒内，凝聚量按1−名义速度/900增长；到零速恰好满值，0.12秒峰值定格后释放，不保留0.85秒独立蓄压。复用原有冲击参考的亮核/有限亮缘，并反向组织向内汇聚（这是本项目设计推导，不声称参考本身展示了吸能）；本轮检索的Focus页面仅有图标/文字，未作为吸能动态依据。抽取带从敌人体侧弯向固定间隙中心，流速与方向明确；复用原校准压缩声音，改为减速开始时仅触发一次。伤害、路径及900弹射保持。
验收：凝聚与减速同帧起始、单调增长、停止满值、峰值短冻结、无额外接触伤害；正式页面录像与顺序帧检查。第一轮回流太细且在近身时被球遮挡，改为从两侧抽取的较宽弧束。自动机制检查通过2114项断言（含轨迹采样，非独立对局数量）；音频采集无削波，未人工试听。未运行批量平衡。
