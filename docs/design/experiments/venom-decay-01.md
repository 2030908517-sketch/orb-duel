# 毒液奥义：腐生·万毒缓蚀

毒液球用已发生但尚未扣除的伤害换取施毒时间，身份是持续腐坏的活毒囊。独立奥义模式生命初值220，经典/团队基础生命不变；首次实际生命损失跨过30%时即时降到阈值，溢出全数入池，无觉醒前置。以后所有应扣生命的伤害入池，每0.5秒扣当前池20%，最低1且不超过余量，池清空后转化继续。护盾先按原规则吸收，已经入账的池伤结算不再被盾挡、不递归入池、不二次触发反伤/吸血；正常命中附效沿既有命中结算一次。技能与运动不中断，不改变毒池、毒弹、毒爆或对手毒伤。

演出以0.12秒快速鼓胀、0.28秒错相回弹进入常驻腐化，体积形变仅属绘制，不增命中半径。深绿壳面先出现三条主裂口，再按池量增加分支；内部用两三片浅毒绿色液面上下错向翻涌，保持原水滴标识。每次真实慢扣时裂缝在0.16秒内亮起再冷却，配低频湿裂脉冲，不加停帧/震屏/大光环。池量越大，裂纹密度与内部翻动越强；清空后只留少量暗裂纹。血条用独立斜纹待扣段覆盖当前生命中将被消耗的部分，文字同时给出池量、下跳量和超过现有生命的致死风险，不伪装额外护盾，不挤动面板布局。

参考：[Riot Zac官方页](https://www.leagueoflegends.com/en-us/champions/zac/)与官方旧CDN W演示，已解码查看0.15～6.72秒六帧，取绿色凝胶深浅体块、外凸小液团及回收感，非宣称逐帧审过全部形变；膨胀/裂纹/脉冲时序由用户要求决定，结构沿用已确认护盾/旧债裂纹语言和本项目代码色块。已实际重看blood-blade代码锚点，保留主形、少量亮面与小尺度清晰度。声音复用已研究的湿裂/低频液体声音身份，合成为短低音与暗噪声尾，不冒称试听。

验收：跨阈值巨额攻击不直接致死；池按20%及最低1完整扣清，空池仍接纳新伤；沉默、无目标、护盾、热度流失、暂停重开和时间回溯不免账/递归。一次激活，普通施毒仍运行。正式页面观察鼓胀→密裂→慢扣闪烁→清池，正常速度与窄屏血条均可读。只做定点机制及少量入口检查，不跑批量平衡。

## 收敛与评审

伤害池是未偿还生命伤害，不当成普通临时资源免账：时间回溯保留池余额与支付时钟，是否已用奥义仍按历史资格处理。按已定奥义控制豁免规则，激活的常驻缓蚀不受时间减速/沉默；没有无敌、霸体或动作锁。普通命中附效在入账时沿原流程结算一次，池脉冲不再次产生附效。

正常速度实际录屏及六个解码关键帧已观察；急鼓胀、黑绿主裂纹、池量与翻涌强度、每跳闪烁、无常驻大光晕通过。池清空后正常速度状态另有实际页面关键帧，余额0但转化仍启用。原风险文字被状态槽截断，已拒绝并改为风险前置/池量分槽；桌面和390屏再次观察通过，未放宽标准。107项机制、861时间回溯、131离场及167血海回归通过；30次重绘纯度通过。合成低音/暗噪声已接入，未主观试听。达到本轮要求，停止额外打磨与平衡抽样。
