# 圣阵巨像：实体圣兵触及圆边

2026-10-23，创作者要求天使与剑枪同比放大，兵器实际触及圣阵边缘；删除攻击延伸线与离阵3秒自动护盾，羽翼进一步放大并具有羽毛层次。

## 设计与实现边界

人物尺度由约半径0.43改为半径0.86，取消旧上限；身体、兵器、握柄与握手统一倍率，剑长/人物尺度0.90、枪长/人物尺度1.45不变。身体偏移、固定骨长的肩肘腕与武器来自共用 `holy-angel-motion.js`；它是战斗和绘制共同使用的纯数据模块，不读取Canvas或渲染缓存。朝向由固定步战斗更新，出手锁定后不追着目标改朝向。

圣剑仍随整个前臂挥舞：肩、肘两级旋转共同带动固定握姿，不能独立转剑。枪先引回，再前送；根据真实枪头位置限制伸展，保证它抵达圆边附近，而非把枪头送出画面。同比放大后以浅探身配合枪刺，比例不变。所有出招延伸光线/弧线已删除，保留准备、实体挥刺、实际命中反馈和收招。

命中改用画出来的剑刃/枪头的真实扫掠胶囊近似，采样目标同一步运动；不再使用圣阵中心到圆边的旧伤害线。圣剑取剑刃、圣枪取枪头，不用枪杆扫到就当刺中。敌我、虚化、无敌、护盾、反伤、遮挡、同招去重及3/4.2基础伤和原攻击时钟保留。这个判定变化来自本次“剑打到而非线条打到”的明确要求，不当作纯美术改动。

天使主体在小球与实体攻击物后绘制，保持不透明而不遮住战斗；守护合翼、圣火与命中反馈仍在前景。羽翼在整体放大的基础上再加宽15%、加高10%，增加长初级飞羽、宽次级飞羽与两层短覆羽，圆钝不等长羽尖、轻羽轴与连贯根部。沿用之前的Valkyrie翼姿参考；本次实际查看[federn羽翼结构图](https://www.federn.org/fig/hilfe/federn_fluegel_en.jpg)，只取飞羽分组与覆盖关系，不复制写实纹理或把生物结构图当成游戏动作参考。

## 离阵护盾移除

不再累计离阵时间或周期发盾；清理相关基础参数、状态字段、面板计时及技能说明。保留普通盾的原到期处理，以及已有合法外部盾的接触灼伤兼容；不连带删除神圣灼伤、合翼减伤或修改其他角色。音色、版本号不变。
