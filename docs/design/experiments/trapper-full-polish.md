# 陷阱球全表现精修（2026-10-29）

## 意图与边界
让观众看懂一套精密机关：布防逐级展开，钢索连成网络，捕获卷索，爆炸崩开结构，置换重新锁定。普通技能小而完整，奥义通过完整机械体积与破坏提升规模，不靠全屏噪声。仅更换绘制，不改玩法、数值、时钟、音色或请求时机。

## 参考覆盖
实际再次打开光刃/同化火焰锚点，比较主轮廓、明暗层级和连续形成；复查Locomule齿轮链条四帧图（work/trapper-gather/gears-reference.png），采用轮轴/支撑/链节的机械结构。节点展开、卷索和中枢都据此组织。爆炸沿用上轮实际看过的Atif分层爆破顺序图，学习短闪/热气/烟/迟落钢件。

本轮补充检索[irmirx陷阱](https://opengameart.org/content/animated-traps-and-obstacles)与[rizzit地雷](https://opengameart.org/content/detonation-mine)。页面已核查，原图访问未完成，不能称看过这些动画，不作为动作验收依据。前者侧视不直接复制，后者像素风不直接导入。既有可见机械参考足以覆盖本次结构，不为数量反复搜索。

## 实施与自审
节点采用压铸底座、偏心卷盘与翻折支脚；武装完成才亮起核心。引线保持真实直线位置，减去调试虚线，改为暗钢索与局部反光。捕获由卷盘—钢索—闭合钩爪形成完整动作；置换使用拆分残像和两端锁具开合。普通爆破与奥义爆破共用材料，严格区分尺寸和密度。奥义修正空心齿轮遮住节点、梁架同色平面、火团周期性星形、碎件缺乏来源等问题。

## 实际修改与退回记录

- `trapper-art.js`：普通节点三支脚展开、卷盘与武装锁扣；直线钢索与端头压接件；捕获卷索和三爪锁具；置换两端机械开合；金属破片、拆除散件；四支脚机关中枢；囚笼钢梁、铰链、锁扣、分层爆破及解除收束。仅读取战斗数据，机械装饰不增加判定。
- `renderer.js` / `tactics-render.js`：上述节点、引线、布置轨迹、捕获、破片与普通爆破接入现有绘制位置；保留缺少新视图时的旧绘制回退。
- `spectacle.js`：停用新机关视图上的旧粉色光圈/方框，避免两套外观同时覆盖。
- `world.js`：现有拆除结果追加0.32秒机械散件，保留原拆除、粒子、统计和声音流程。没有改伤害、CD、物理、聚拢、生命、版本或音色。

第一次实际采集发现旧粉圈和空心大齿轮盖住节点细节，退回；去掉重复覆盖和大齿轮，仅保留真实节点与牵引链。爆破原先周期性过强，像规则星形，退回；改为低频不对称膨胀、连续热气主体、分离钢件和迟落烟层。最终没有用增加亮度或粒子掩盖这两处问题。

## 创作者反馈后的画风修订（当前版本）

创作者指出上一版机关过于写实、与游戏割裂。该反馈覆盖上面的旧版风格自审结论；制作精度不能靠写实金属细节来证明。

本轮仅修改`trapper-art.js`：金属多段反光与铆钉改为清楚的两层冷色外壳和窄边光；齿轮从细密齿牙、五根金属轮辐改为八齿、三根简洁轮辐；锁链改为统一冷色图形；普通节点与中枢以菱形能量核心呼应角色符号。囚笼、锁扣、替身外壳、散件共用这套风格化材料；烟层改为蓝灰色，保留暖色爆破的强弱层级。动作细节、聚拢位置及实际攻击范围未改。

新采集位于`work/trapper-polish/capture/stylized-ult/`、`stylized-regular/`，已打开检查普通节点、完整囚笼和爆破关键帧，并原速观看奥义组装至回到战斗。自审结果：写实金属的杂色与高频小亮点已去除；材质、轮廓和小球同画面更统一，锁扣和支脚仍有独立动作，没有为简化画风退化成静态图标。最终审美仍允许创作者反馈修订，不把自审当作创作者认可。

重新运行四模式各1,000固定步的新旧快照、绘制只读、声音请求与有限几何检查，全部通过。两次正式入口采集无页面异常。本轮没有改音效和战斗代码。修订前文件保存在`work/trapper-polish/style-before/`。
