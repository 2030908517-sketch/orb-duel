# 三球奥义演出实验 · 2026-10-15

[进入舞台](../../../tests/arcana-lab/index.html) · [实际录屏与关键帧](../../../tests/arcana-lab/evidence/index.html) · [知识库](../knowledge/README.md)

## 边界与意图

只试演普通球、加速球、吸血球已经存在的奥义。本文的“一拳定音 / 破空音爆 / 血月合围”是实验演出代号，不是角色技能改名。正式 `js/`、角色数值、全局条件、命中、伤害、动量、护盾、无敌和回血代码均不改。

设计目标：观众先理解威胁和来源，然后看清释放，最后由真实结果确认力量。夸张集中在主形与节奏，不把三个技能都做成同色大圆环，也不在每一步增加冻结。

训练场把本体设为已觉醒、35% 生命及足够资源，使用正式引擎和正式 `Clock` 预录 5 秒。靶球的普通技能和奥义停用；静止靶用于审片，另有移动靶。普通球闪身仍遵循正式 `near()` 的合法贴近位置选择，**本实验没有把它改成任何方向下都必定闪到背后**。

| 演出 | 阶段与观众感受 | 视觉与声音协同 | 取舍 |
| --- | --- | --- | --- |
| 普通球 | 短残影到位 → 稳定蓄拳建立“要出大事” → 巨拳突然前送 → 短接触驻留 → 沿方向击飞 | 移动只有残影；到位 85ms 后才显拳与张力声；预备不提前喷爆炸。释放短空气声，命中才有厚重瞬态、低频主体和衰减尾音 | 拳形大且直观，但会短时遮住攻击者；胜负目标保持可见。长的是蓄势，命中停留默认仅约 90ms |
| 加速球 | 前方压缩气流 → 真实冲刺 → 急停释放有方向的波面 → 命中与破盾 → 余压退出 | 压缩椭圆朝攻击方向收紧，冲刺用真实运动历史，实际锥形前沿有亮边；释放为气压噪声和低频爆发，命中声更短更硬 | 释放本身有声音，落空也会听到音爆；成功打中才增加受击声/数字。外层余压为装饰，不声称有额外伤害 |
| 吸血球 | 三向显形 → 巨型弯刃构成包围 → 实体飞行合拢 → 切裂 → 血液回流 | 暗红血月与三件真实飞行物；显形用心跳/暗色和声，合拢用掠切声，命中用短撕裂和低频；回血由实际治疗事件发出回流与数值 | 刃尾有装饰性长度，不能拿亮边当精确判定圈；真实弹丸仍按原规则。不同刃可能同刻命中，不人为延迟结算来凑三拍 |

## 与正式时钟的隔离

`core.js` 在固定采样间隔内通过正式 `Clock.advance()` 录下源状态，包括既有停时。冻结源回放后，`timeline()` 只建立索引到舞台时间的映射。新版本和原版本读取同一份状态，不重新计算攻击，不改原片速度属性、模拟秒数或战斗随机数。

新舞台默认：普通球既有 0.68s 蓄拳保持；源命中停时重放约 0.09s；音爆释放停留重放约 0.035s；血刃显形停留重放约 0.12s。加速球的冲刺片段以 1.6 倍时长显示；血刃实体飞行默认 1.4 倍时长。它们是**审片重定时，不是正式游戏改动**。如未来采用，真实技能时序/停时调整必须作为另一次明确玩法修改验证。

音效只在本页为既有 `G.Audio` 增加 `lab*` 配置，不覆盖原配置。原版切换调用既有 `Renderer` 与 `arc*` 音色。暂停/重放停止声部；新演出预备被沉默取消时会停止预备声；拖动只预览画面。录音捕获真实 compressor 输出，记录事件 ID、模拟时间、源片时间、舞台时间、音频调度时钟。音频调度时间不等于扬声器实际发声时间。

可调项限主形强度、镜头响应、声音音量、回放命中驻留、血刃回放慢镜。不提供伤害、命中率、无敌、护盾或动量滑块。

## 可复现与使用

直接双击 `tests/arcana-lab/index.html`，或访问现有本地服务 `/tests/arcana-lab/index.html`。无安装与构建。选择三球、原/新版本、场景；按空格播放，R 重放，时间条和阶段按钮定位。1× 审节奏与声音；慢放只审动作，音色不变。PNG/JSON/画面加混音录制都只留本地；录制最长 12 秒，锁定影响源片的控件。

场景：成功释放、移动靶、护盾（轰拳/血刃等待正式条件满足，音爆实际破盾）、出手后临时无敌、预备遭沉默。后两者不能凭释放动画假报伤害/回血。

专项工具：

```text
node tests/verify-arcana-lab.cjs
node tools/capture-arcana-lab.cjs
```

在项目正式目录执行。采集脚本复用本机已存在的 Playwright 和 Edge；普通用户使用实验室无需这些工具。采集还检查 `file:` 和现有 8799 本地服务、1440 与 390 宽视口、暂停、静音、原版切换、取消声音、静音录制、录制控件锁定和视频解码。

## 本次实际评审

**工具结果。** 3 角色 × 5 场景，共 109 项断言通过：观察开/关的每一份源状态、最终快照及两个 RNG 一致；采样/调参不改变源片；中断不消耗奥义；后置无敌无伤害/回血；正式音色配置未被改写。成功静止场景的真实奥义生命伤害：轰拳 32、音爆约 29.46、血刃共 30 且治疗 20。这是演出夹具结果，不是强度或平衡结论。

**已观察。** 检查了桌面/窄屏、阶段关键帧与从三段实际录屏解码的有序帧。能分开读到普通球残影到位与随后拳姿；音爆从本体向敌方推进；三把血刃先围住再合拢，命中后有实际回流。修复了旧位置球影滞留；不同时间的血刃数字改为短窗口累计显示，避免叠字；血刃成功反馈使用交叉弧斩而不是复用音爆前沿。大拳在接触瞬间仍会遮住一部分球体，是保留的夸张取舍。

**声音仅技术检查。** 三段 WebM 都包含有效画面和实际混音，能解码，峰值未削波；中断停止预备声，静音录制近零。未实际试听，不宣称低频够厚、音色满意或音画主观协调已通过。当前音量不是经过盲听匹配的感知响度，不能仅按谁更响判定优劣。

**性能边界。** 本机短时局部采集的绘制调用 P95 约 0.3ms；这不是全角色、2v2 或低配机器稳定帧率保证。浏览器无运行错误；不做全角色平衡测试。

**待你判断。** 普通球蓄拳是否足够压迫且不拖；音爆是否有空气突然破裂的听感；血刃尺寸、合拢速度与回流是否像围猎；三招在反复看时是否仍有层级。以上不能由存在截图/波形替代主观评审。正式游戏尚未采用任一新演出。

机器证据见 `tests/arcana-lab/evidence/verification.json`、`browser-review.json`、各角色时间线与 WebM。`scope.json` 对比本任务开始的文件哈希；已有大量未提交角色改动保留，不以当前 Git 历史差异冒充本任务范围。
