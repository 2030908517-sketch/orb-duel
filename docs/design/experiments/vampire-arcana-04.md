# 吸血奥义 04：血月·绞刃回流

2026-10-15。仅更新独立奥义模式。保留用户认可的代码细弧血刃，演出从“同时三弹射向中心”改成“有先后关系的三面猎杀”。视觉中心是深红刀身、有限亮刃与弯曲血痕；声音以心跳、切割和汲取为身份，不采用普通球的重炮爆鸣或加速球的环形空气壁。

## 设计与分镜

| 阶段 | 候选模拟时长 | 动作、视听与结算 |
| --- | --- | --- |
| 引血预兆 | 1.05s | 由本体向三个刃位抽出弯曲血丝，细亮边缘勾出未来威胁；完整尺寸从局部成形，不缩放完整图标。低心跳与血液拉伸声。 |
| 三面成刃 | 第一刃约0.42s后释放 | 三把刀按各自刃缘向内部填充暗红体块，尾部稍后撕出；短暂形成开口的包围，球体和敌人可见。尚未释放的刀无碰撞伤害。 |
| 错位绞切 | 释放间隔约0.2s | 三刃斜切、对向接入、末刃压轴；每把在自己的出手时刻独立有限预瞄，然后沿实体轨迹前进，不飞行追踪。三次斩风与对应的实际释放同步，最后一次有更低的声音主体。 |
| 命中/落空 | 每刃各一次 | 真正接触才出现锐利弯曲伤痕与小股定向血滴；不生成径向爆炸。护盾用截断的冷色接触，无敌无成功血痕；落空沿运动方向裂解，不能回流回血。 |
| 汲血归身 | 装饰约0.45s | 只有实际治疗产生回流，血流先拉长再收进本体；抵达时有局部恢复光纹。生命与数字仍在正式治疗时更新，不为动画延后救命效果。 |

沿用低血量与觉醒条件、3血能和自身血印、每局一次；准备期仍等待无敌/护盾/反伤结束。三刃各10基础伤害，80%实伤吸血，整招治疗上限20，不叠普通吸血。镜片与磁力继续影响已释放血刃；未释放部分被沉默中断，已经飞出的实体继续，死亡清理。仅首次有效接触给予很短顿帧，不逐刀冻结；不用强制束缚或新增终结爆炸补命中。

## 本轮调整与评审

拒绝第一轮的重复弹丸箭头和重叠伤害数字：箭头来自旧通用飞行物表现，已仅在新奥义模式对血刃排除；三刃伤害与治疗数字分别累加，实际伤害不合并。发现等待凝形的刀不会立即响应沉默，已改为中断时立刻清除未释放刀，飞出的实体继续。

最终关键帧及录像解码抽帧已审看：刀身保持认可的暗红体块和局部亮刃，从外缘向内成形；三次错位释放、斩痕及回流可区分。真实治疗钩子才生成回流，满血、无敌、全盾和同时死亡专项没有虚假恢复演出。音频已解码分析，无主观试听结论。证据：[录像与对照](../../../tests/arcana-lab/evidence/pair4-final/index.html)。
