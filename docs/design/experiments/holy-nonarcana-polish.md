# 神圣球常规与觉醒表现优化

2026-10-28。范围：圣阵、常规剑枪的蓄势/命中、羽翼守护后的圣火、赐福、烙印投枪、圣灼、觉醒圣柱；不改七印奥义、人物造型、兵器比例、真实动作与碰撞。修改前完整运行脚本、页面和设计文档保存在项目根 `work/holy-nonarcana-20261028/before/`，附当前 Git 状态与脚本 SHA256。

目标是清冷庄重、内聚后骤然释放的神圣力量。强度低于奥义，但每个保留形体都要有明确的材质和动作。冷白核心、蓝灰透光层、有限浅金边共同表达圣光，避免整根不透明白管、整齐重复火苗和发光圆环堆叠。人物继续使用原二维插画和持械轨迹。

已实际查看三套项目顺序帧。外部参考：[HALLOW 作者的二维动态目录](https://godboyhappy.itch.io/hallow-hd-holy-light-healing-vfx)，下载公开预览 GIF 并查看0/6/12/18/24/31帧，覆盖预警圆、光柱、枪形能量、冲击、光翼、赐福与环形波的形成和分层收尾；提取窄亮核、弱外层、主体与余光分时消退，不复制素材或大量光晕。[Divine Favor 作者动态](https://realtimevfx.com/t/divine-favor-ue5-vfx/25829)已查看127帧中8个时点，仅补充下落—接触—收束节奏，3D角色、场景、浓烟和镜头均不采用。圣火翻卷以已认可的同化火焰结构为材质校准，改为白金薄火，不照搬恶魔红黑厚火。圣水沿用固定地面湿痕，不新增流动或改变视觉覆盖。

|阶段|表现原则|
|---|---|
|形成/准备|圣阵沿实际边缘分段刻写，符纹逐处点亮；柱底预警保持真实圆形边界；枪尖能量向实体尖端汇聚|
|释放/接触|柱内不等宽光流向落点输送，底部局部散射；圣火为连贯薄膜的错相卷曲，非复制火苗；武器反馈沿真实方向|
|留场/收尾|光柱亮核先收、稀疏余光后散，伤害终止不拖假柱；波后薄焰剥离；赐福细光向本体吸收，灼伤保持小而清晰|

验收：实际场地尺寸下仍读出光/火而非白管或花边；连续动作局部结构变化；预警与落点、剑枪轨迹一致；四模式共享、墙角/密集光柱/暂停重开无残留；渲染前后及旧新版战斗快照、随机流和声音请求一致。复用正式页面定点触发与现有专项，不新增音色、不跑大规模对局。自动正确性、关键帧、原速播放与未试听分别记录。

## 实施与自审

修改 `holy-render.js`、`holy-angel-render.js`、`holy-angel-throw-render.js`、`holy-angel-rig.js`。圣水固定湿痕、人物主体、兵器比例和奥义绘制保留。成形时兵器与人物共用显现边界，避免武器提前完整悬空；剑枪短光迹从原生武器姿态采样，限在圣域内，不新增攻击延伸线。圣阵先刻边再分段点亮符纹；圣柱固定圆形落点与收敛外弧区分，内部不等宽光流向下输送，底部局部散射，密集落柱减弱整管亮度。净化波改为连续薄焰膜、非等距受力起伏和翻卷末梢；赐福向本体汇入，圣灼保持小尺寸层次。

实际观察：正式经典页和团队页的成形/剑枪、守护/圣火、投枪、赐福、觉醒密集圣柱、贴边七类定点场景；检查顺序关键帧，并在浏览器打开1倍速录像、播放并抽看动作衔接。主要边界通过：实际尺寸下保留人物与对手轮廓、波沿连续但不盖满场地、光柱留场及收束与原生时钟一致、兵器不再提前悬空。关键帧和录像在项目根 `work/holy-nonarcana-20261028/capture-after/`，原版对照在 `capture-before/`；最终哈希、专项及限制见同目录 `final-review.json`。录制和观察无页面异常，渲染前后战斗快照不变。
