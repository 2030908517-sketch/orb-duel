# 喷射衔接、常驻液面与整片生命周期

沿用已生成三态参考和现有代码明暗。本轮仅修三处实际缺陷。喷射从池内液面长出短液颈，0.20秒预备期逐渐聚起并沿真实出射方向细长化；发射头与细尾连续接续，末端保留薄液片和少量细滴，不突然贴上一颗完整毒团，不变弹道/命中/声音时机。

浓缩常驻场检查开口等值线：标量密度穿过采样边界时，当前绘制会直接封口，随着交点换位产生大块跳变。采样区扩大并于可见液面之外收至零，使每条等值线自然闭合，再裁到原液面；保留原明暗层级，不用减透明或关闭动画掩盖问题。

多片毒雾复现1-2-3传递寿命与容量替换。若已合成的雾区来源被放池/残雾上限替换，不能删除该片已合入的有效区域；将其保留为整片雾的被动组成部分，不占来源名额，不返CD，到整片最晚期限一起清理。生产来源的4池/8残雾上限、施毒共享时钟、隔墙敌我及转化结束后才能连接的边界保留。区分真的删除与噪声翻卷造成的短暂透明。

验收：闲置液面2秒逐帧无开口闭合抽动；预备/发射连续，液团从池里形成；1-2-3间接连接不同初始期限，跨旧期限及新放池替换仍保留全部区域，共同到期；四入口专项及实际原速/0.25倍观察。

## 本轮评审

先复现：旧版本达到4个主体来源后再放池，连通成员的expires虽已同步，最早成员仍被容量删除。现releasePool保留已成熟且已连通的雾区，将其从来源名额移出而不清掉物理区域；8个残雾来源替换走同一路径。单独未连雾仍依原替换规则，整体到期和来源死亡仍清理。补测中间桥来源被替换后，1-2、2-3仍连接，全部跨过旧期限、在共享期限清除。

浓缩常驻修复采样边界：域从[-1,1]扩大到[-1.4,1.4]、液面外衰减到零，提取的矢量等值线闭合后才裁到原有液面；静态微光与原梯度保持，未将动画关掉。连续90帧×四入口共360项开口/非空检查通过。局部连续16对帧的平均差最大值由0.436降到0.192，数字只辅助定位，实际图像已打开。

喷射预备期从零开始长出液颈和细长亮头，液颈收回的同时同一喷射形状接续，发射后薄液片与细滴渐显；0.20秒预备、飞行速度、命中/施毒和声音事件不改。
