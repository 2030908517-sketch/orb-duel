# 毒液V2：双毒素与三态毒液

目标：从反复毒爆转为区域经营和伤害/控制取舍。正式替换普通及觉醒机制，经典、奥义、团队共用；保留伤害池奥义和心跳，不增加独立演示界面。两个毒素共同占用4槽，单类3槽；绿色液滴代表侵蚀，紫色菱形代表麻痹，四槽固定在球体外围，下方用“侵N 麻N”补足信息，补层、到期和替换局部脉冲反馈，不遮住身体。

已实际查看项目细弧血刃代码风格锚点及 Viper Poison Cloud 静态参考：https://media.altchar.com/prod/images/gm_preview/dd2ce2c03ee1-viper-poison-cloud.jpg 。参考图可见紧贴地面的铺展液体与上方松散、透光、卷动的气体，采用材质和轮廓区别，不照搬3D球形烟幕。本次仅参考静态图，没有声称观看其动画。正式实现仍是分层Canvas形状：普通池扁平涟漪，浓缩池缩成较厚实的深绿核心，毒雾形成较大紫色云瓣。实际范围由细边界标示，云瓣在判定内漂动，不画出会误导范围的强亮外扩。

三态按模拟时钟连续变化，共鸣预警后推动每处毒液进入下一态，雾只延长有限时间；旧爆炸、毒伤折现和三向液滴均移除。音效复用现有已校准的留池/共鸣提示和轻毒伤，不增加持续噪声、顿帧、震屏。液体收缩与云瓣逐步形成使用过渡帧，表现不驱动毒伤。

参数集中在G.Venom.config。同源同目标施毒CD跨来源、跨区域共用；重叠时同源优先雾、浓缩、普通池，不按帧/池数叠层。满层异种两次施加替换对方最短剩余层，全目标替换CD2秒；期间可积进度但不替换。单类满3只刷新该类最短的一层。层到期单独移除，固定跳伤时钟不因补层重置；净化清层但不修改奥义伤害池。

验收：共享容量与替换边界、进出不重置CD/跳伤、当前侵蚀层数决定结算、霸体和专属强攻击豁免、三模式友伤/墙体遮挡、三态与四槽在实际尺寸和密集区域清楚。仅做定点验证和少量正式对局观察，不宣称平衡已定。

实现与调参见 [VENOM_V2.md](../VENOM_V2.md)。验收：共享毒层/替换/独立计时、控制隔离及三模式边界通过；实际查看三态/团队/手机截图。首轮雾团过于规则像花瓣，已拒绝并改为错落的云瓣，再次观察通过；音色复用，无主观试听。毒雾另有每0.5秒0.18低额区域伤害，与侵蚀时钟分离，同源重叠不额外结算。
