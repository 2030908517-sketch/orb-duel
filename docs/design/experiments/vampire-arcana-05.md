# 吸血奥义05：血狱·噬心回流

目标：先看见“猎物被三刃围猎”，再看见吸血鬼本体亲自夺血，最后明确生命由敌转己。沿用≤30%且觉醒、3血能、自身有效血印、每局一次，准备期等待无敌/盾/反伤。仅独立奥义模式更换；经典与旧团队不迁移。

| 阶段 | 动作与节奏 |
| --- | --- |
| 血印苏醒1.05s | 血印收紧、三处裂口向外剥开；三刃固定在完整尺寸的刃位，深红弧线组成透空三角血狱，不是墙体或必中控制。 |
| 成狱0.45s | 三刃从刃缘向体块成形，不整体缩放。低心跳与三处短促裂血音定位。 |
| 三次绞杀约1.2s | 第一刃横扫，真实命中将敌人轻推向阵心；第二刃反向交错成X；第三刃由上向下重压。三段由独立实际刀身扫掠命中，6/8/10基础伤害，各敌各刃最多一次。锁定的轨迹不追踪，目标仍能逃开。 |
| 本体收割 | 绞杀后本体化成薄血雾，瞬时贴到敌人侧前方；显出约0.25s噬咬预兆，随后在近身范围真实判定12基础伤害。只在化雾的0.14s免伤穿球，到位不无敌。临入场遇真正无敌最多等待0.7s，过期收势。 |
| 回流约0.9s | 刃伤先记账、不直接治疗；噬咬实际扣血后，按有效刃伤+咬伤的80%吸血、上限20（统一治疗即时结算）。血核从敌人体内沿弧线被拉出，抵达本体产生心跳；蝠翼骨架先开、翼膜后充盈，最后裂成薄雾。未咬中/全盾/无敌不出现成功回血。 |

新形态区别于三发远程弹和射手反击：三刃留在局部处刑场内完成有方向的摆斩，高潮由本体贴身夺血承担。使用认可的细弧血刃，压轴刃可通过角度和厚暗面表现重量，不画卡通獠牙图标。翼为清晰尖骨、凹膜轮廓，中心留白显示球体。声音分为低心跳、宽刃破风、第三刃低沉切落、化雾抽吸、噬咬低频收束与回流双心跳；不复制拳炮爆炸声，只在实际重压/咬中短停。

## 验收

三刃显形、X交错、下压、本体入场、夺血展翼均可在正常尺寸辨识；没有小图整体放大。移动/落空/晚无敌/晚盾/沉默/角落/死亡场景真实判定，不播假回血。镜片/磁力不改变血刃。暂停重开清干净、同种子多帧率/倍速复现。收招额外延长0.3s，仍不结算新的迟到攻击；如果三刃已经致命，只完成该击余效，不补噬咬和治疗。

## 首轮退回与修正

实际打开九阶段图及录像抽帧后，退回首轮：噬咬转回流的同一步重新开启身体碰撞，额外打出了普攻、受伤和吸血数字，掩盖主高潮；回流也被普通击退带向字幕。现将噬咬与1.05秒回流作为无身体接触的收招（并非无敌，其他技能仍可伤害），本体稳定承接夺血。三角刃位收紧并增加顶部/侧面余量，减少巨刃边缘裁切。首次封位命中阵心不再施加任意朝右的推力，改为削减当前速度；偏离阵心才轻牵回。X斩痕短暂保留，让两次摆斩的关系可读。

音频复核补充：[Riot SFX制作访谈](https://nexus.leagueoflegends.com/en-us/2018/07/the-stories-behind-leagues-sfx/)检索摘录提及角色声音色板与动作时序，但直接打开旧地址重定向到官网首页，未获得该篇完整正文；不把摘录当全文研究；本项目采用低心跳、抽吸、宽刃风噪与低沉噬咬组成同一声色体系。没有把该访谈中素材试听当成本轮已试听，也不照搬商业音频。

补充实际读到的音频参考：[The Frequencies of Folklore](https://www.leagueoflegends.com/en-us/news/dev/the-frequencies-of-folklore/)正文相关段落：同一主题共享素材语言、不同动作保留角色身份；连续战斗中控制尾声遮蔽。对本轮的迁移是切击短、收割低沉、回流用两次低心跳，主峰按释放/实伤/治疗分别安排；属于本项目设计推导，未试听文章示例。
