# 基础球球碰撞：三方案设计实验

日期：2026-10-15。状态：已实现、采集并完成一次视觉迭代；等待用户试听与选型，未应用到正式游戏。[交互实验](../../../tests/collision-study/index.html) · [录屏与证据](../../../tests/collision-study/evidence/index.html)。直接打开或通过已有本地服务访问即可。

## 假说与不变项

目的：用一个最基础的真实碰撞，验证知识库是否能支持从意图、设计、实现到证据与修正的完整流程。选两个普通球的首次普通碰撞，不混入重拳、觉醒与奥义。

正式 Engine 只运行一次生成固定步长回放；调用原物理与战斗结算，以原 Presentation 的只读诊断核对实际伤害。A/B/C 读取相同的不可变帧与接触事实，完全不向引擎写回。碰撞半径、速度、法线冲量、生命、种子、双方同时伤害和既有规则不改。没有额外击退、新预警或新增顿帧。时间节奏只来自表现图形、形变和声音包络。

原实验室的受控样例主要是静止摆位后调用伤害函数，不能用于本次真实球球接触的三路比较。因此增加一个专用对照视图，复用原 Engine、Presentation 诊断、Audio 解锁/总线/压缩器；不重写生产物理，不自动迁移旧反馈，也不改通用实验室原有行为。

## 方案与依据

| 项目 | A 脆响 | B 弹压 | C 冲量 |
| --- | --- | --- | --- |
| 意图 | 接触干净、短促、硬质 | 看到球在承力、回弹 | 接触后有方向明确的压力释放 |
| 视觉 | 细接触切面＋六道短火花 | 切向释放弧面，无碎屑 | 短驻留切面＋两侧压力前沿＋六道细屑 |
| 球体形变 | 约 7% 法向压缩，快速收回 | 约 23% 法向压缩、轻微反向过冲后衰减 | 约 14% 法向压缩与短促回收 |
| 体积处理 | 三方案都以法向缩放和倒数切向缩放保持绘制面积近似不变；中心与真实判定不动 | 同左 | 同左 |
| 节奏 | 主音/切面很短，视觉约 0.20 秒 | 形变领衔，视觉约 0.36 秒 | 切面有 22ms 驻留，压力前沿快速分离，视觉约 0.30 秒 |
| 声音候选 | 短带噪起音、较高的硬质音头、迅速衰减 | 较软起音、圆润下降音体 | 清楚的短起音、中低频下落主体、受控尾韵 |
| 镜头 | 无 | 无 | 可关闭的约 1.15 个世界像素响应，迅速衰减 |
| 优先适用假说 | 高频日常接触、信息密集场景 | 小球的普通相撞 | 更强调力量的局部接触，是否适合作为普攻待比较 |
| 风险 | 可能太轻、像擦碰 | 太弹可能显得橡胶或可爱 | 普攻层级可能过高，连续出现可能疲劳 |

所有数值是本次候选，**不是知识库给出的最佳值**。三种 PCM 以相同积分能量作初始控制，这不等于主观响度一致；实际总线仍经过现有压缩器，录屏需分析实际输出。

## 可复现的场景与使用

正撞、斜撞、靠角落、错身未碰四个夹具。固定初始位置和方向是夹具设置；两球所有属性与模拟规则仍由生产模块决定。右球的粉色仅用于本实验区分左右，两者都使用普通球属性与圆点图案。对比只观察短片首次接触，避免后续强化/觉醒干扰。错身夹具应当没有任何接触反馈。

页面支持三路对比、单路放大、只听一路、孤立试听、暂停、慢放、逐帧、定位接触、种子、形变/图形/音量调节、仅物理、真实碰撞圈、PNG/JSON/WAV 与带声音 WebM 导出。慢放保留声音原音色和音长，故声音品质比较用 1×。

音频计划、模拟时点和回放时点分开记录；音频调度时间不等于扬声器实际发声时间。静止定位不播放历史音效。媒体只取 Canvas 与合成输出，不取麦克风或系统屏幕。

```powershell
node outputs/orb-duel/tests/verify-collision-study.cjs
node outputs/orb-duel/tools/capture-collision-study.cjs
```

第一条验证轨迹/结算隔离、复现、边界和 PCM；第二条需要既有 Playwright 和 Edge，进行实际浏览器操作、截图、录制、解码及短性能采样。不会安装运行依赖。证据保存在 `tests/collision-study/evidence/`。

## 评审记录：客观结果

- **正式规则隔离**：四夹具 × 三种子，共 12 组回放；逐帧位置、完整最终战斗快照、战斗 RNG 与旧特效 RNG 在开/关诊断时相同；三路采样和极端表现调参不改变回放。三个接触夹具均一次真实接触、双向实际伤害，错身夹具零接触。普通碰撞没有新增真实停时。
- **默认事件**：种子 `collision-001`，正撞发生在 tick 106 / 0.441667 秒；左球实际失去约 10.9285 生命、右球约 11.9588。A/B/C 一致，并非三个版本各随机结算。
- **浏览器**：本地文件模式 Edge/Chromium 155 无运行错误；1440、1280、390 像素窗口，无横向溢出。实际操作通过播放/暂停、静音、场景/版本切换和表现调参。录制时锁定场景与参数，避免标签和媒体内容失配。
- **媒体**：三份各约 3.36 秒的 WebM，包含 Canvas 视频与实际合成总线输出；成功解码，有音频信号，无检测到的削波样本。另有原始单声道 PCM WAV、事件/调度 JSON 和截图。
- **同步证据的边界**：真实事实、表现请求、实际绘制和音频计划各有记录，统一使用接触 ID。只记录被绘制的可见版本；隐藏版本不冒充已呈现。排入音频时钟不是测得扬声器起音，具体延迟以本次 JSON 为准。
- **性能**：本机无头 Edge、DPR 1。每版本 600 次效果期绘制，P50 约 0.1ms、P95 约 0.2ms；紧循环里存在约 32–58ms 的孤立长调用。实时回放的近期样本也另存。不能把这组调用成本当作全游戏帧率保证，不能把长调用未经分析归因于某个效果或 GC。

## 实际观察与有限评价

观察材料：`comparison-ui.png`、正撞六个时间点 × 三版本的 `contact-sheet.png`、`oblique-comparison.png`、`corner-comparison.png`、`ui-390.png`、从实际 C 录屏解码的 `recorded-C-strip.png`，以及第一轮 `iteration-0-contact-sheet.png`。**这是静帧、连续时序采样和录屏抽帧观察；没有把生成了视频等同于完整观看视频，也没有试听声音。**

以下是设计者对已观察视觉的判断，不是用户评分，不含未听过的音频品质结论：

| 维度 | A 脆响 | B 弹压 | C 冲量 |
| --- | --- | --- | --- |
| 打击感（视觉） | 短、硬、干净；持续较短，在缩小画面中更容易显轻 | 形变承力最清楚，回收有前后变化；有弹性材质倾向 | 接触主切面和外侧压力前沿更显著；对普通接触可能偏重 |
| 清晰度 | 接触点最简明，球体轮廓遮挡少 | 迭代后不再出现额外圆球式轮廓；斜撞仍有方向关系 | 方向明显，但前沿占据更大，靠角落时装饰会被自然裁切 |
| 协调性 | 小形变与短图形共享接触锚点 | 形变主导，弧面沿切向展开；最终恢复至圆球 | 切面先出现，随后压力前沿向两侧走；不冻结本体 |
| 辨识度（视觉） | 细切面/短火花 | 无碎屑、切向弧面与较明显压缩 | 定向前沿、短镜头响应、较强主切面 |
| 性能 | 本次 P95 约 0.2ms | 本次 P95 约 0.2ms | 本次 P95 约 0.2ms；不能因此宣称与 A 永远等成本 |
| 音色/完整音画打击感 | 未试听，待判断 | 未试听，待判断 | 未试听，待判断 |

数字、血条和身体中心来自共用帧；未见三个版本因表现而出现不同伤害或位置。靠角落装饰裁切是边界表现，本轮未为保住装饰而移动真实接触点。窄屏按纵向排列，保留控制和所选声音入口。

## 迭代记录

1. **听觉对比偏差修正（技术证据）**：初始目标能量 0.003 时，A 先触及峰值上限，实际能量约 0.002025，B/C 约 0.003。将共同目标改为 0.002 后三者达到一致积分能量，同时保持峰值低于 0.83。不能据此声称主观等响。
2. **一次聚焦的视觉迭代（已看序列）**：B 原弧面形成几枚额外空心球，抢本体轮廓；改为切向曲线并加快中央亮斑收尾。C 原细屑像球面栅栏；调整角度分布，并让压力前沿在稍后移动到本体轮廓外。保留第一轮图，未改变真实轨迹、伤害或时间。
3. **交互与采集修正（实际失败）**：单独放大后隐藏其他卡片，导致自动点击无法切换；新增始终可见的版本选择。录屏 MIME 的编解码字符串包含逗号，初版 Base64 取段错误；实际解码抓到了问题并修复，最终三份媒体均重新生成并解码。停止将隐藏画面的请求记录成已绘制，区分请求与实际绘制。

## 推荐与待用户判断

**优先试玩 B，A 作为清爽备选，C 作为更强反馈候选。** 目前推荐 B 的依据仅是已观察到的承力形变、较少装饰与普通碰撞的层级相符；不是因为 B 默认选中，更不是已经证明最好听。

先用 1× 正撞轮流只听 A/B/C，再切斜撞、靠角落与错身。可用单独放大检查具体变化，用三路比较确认没有“更强 = 真的推得更远”的错觉。C 若被选为日常碰撞，还需要连续实战密度与上层强化攻击的相对层级检验，本轮不能凭单次事件直接推广。

尚未完成：人工音色试听、完整连续视频的流畅度判断、真实设备端到端声音延迟、2v2 多事件混音/性能、其他浏览器与长期观战疲劳。没有运行全角色平衡测试，因为规则未改变且本次是基础接触实验。
