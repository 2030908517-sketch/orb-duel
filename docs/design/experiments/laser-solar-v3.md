# 激光奥义第三版：高能光刃

2026-10-26；接续第二版未提交工作。创作者明确要求去掉刀身的机械质感，放开增加特效、追求震撼。本轮保留镜组的机械结构，把光刃彻底改成光能材质，不增加伤害、范围、时长或停帧。

## 演出卡

观众应看懂：周围光能被吸入镜组，有限空间内的亮度与流速不断攀升；炽白光核喷发成刃，横扫撕出大范围金色能量幕；切中的局部过曝、灼亮裂口与热屑构成高潮，收招后剩余光能沿切迹散尽。光刃不再有铜色背面、金属倒角或稳定硬描边；用连续白热核心、金黄辉光、流动光丝和不规则电离边界表达高能，保持主轴稳定，不能全刃随机抽搐。

| 原生阶段 | 本轮新增/重做 |
|---|---|
| 0–0.8秒 | 镜外收束光流、分层压缩波、核心渐亮；能量运动由外到内。 |
| 0.8–1.4秒 | 点火喷发、从根部延伸的光核；包层持续向刃尖输能，刃形由光的包络塑造。 |
| 1.4–1.76秒 | 原138度真实扫角；宽幅半透明能量幕、成组光丝、外缘弧光与根部反作用喷流。 |
| 1.76–2.71秒 | 白芯撤回，弧形残留逐段降亮为余辉，光屑散逸，镜组回收。 |

命中增加局部白热切口、椭圆压缩波和定向光屑；吸盾用防御色折散，免疫与挥空无成功反馈。扩散光晕与残迹纯装饰，无新增攻击包。允许高潮短暂遮盖局部，但不能长期淹没两球或用全屏白屏代替刀身。现有5段声音已按第二版校准，本次不改混音、音色或发声时机。

## 实际验收（2026-10-26）

### 已观察与修改

查看作者原始Godot光束GIF的4/8/13/17/22/27/31/36帧：亮核连续，外部光丝与发射端波层流动，外缘不呈金属硬片。它是三维示例，仅迁移亮芯/包层/散逸材质；不作为俯视二维动作参考。查看RTVFX聚能分解81帧GIF中的12个时刻，核查粒子向中心汇聚和层次分离；完整光束GIFSSL获取失败。二维画风与扫动逻辑继续沿用已实际查看的项目锚点及第二版参考，不谎称看过Youngfx的403媒体。

第一轮已观察正式页面16个阶段帧，发现6组等距断续弧线像雷达刻度，拒绝该候选（`work/laser-solar-v3/round1-sheet.jpg`）。第二轮改成3道连续、有小幅扰动的光痕，保持更多聚能、包层、拖尾、放射与命中效果，没有用减少整体规模解决问题。

最终已打开 `work/laser-solar-v3/comparison.jpg` 与 `final-sequence.jpg`，查看第二/第三版同一场景的铸刃、切中、收束对照及第三版16个顺序帧。相比第二版，观察到金属背面消失、白热光芯与外部光丝明确、横扫能量幕更大、受击位置有强烈局部发光；主体与目标在大部分阶段可辨认，命中高潮会短暂过曝局部。是否足够震撼及过曝是否合个人喜好，仍交由创作者试玩，不能由功能测试代替。
