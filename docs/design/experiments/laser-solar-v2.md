# 激光奥义：机械聚光与断界裁切，第二版

2026-10-26；基于正式版本70c5a09。仅重做已有「日轮·断界天刃」表现，不新增奥义或改变玩法。

## 意图与动作
让观众看懂：镜组收束能量，铸成极薄而坚硬的刃，承力装置带动它横扫，切中才出现热切口，随后能量回到装置。身份是精密光学机械与高能切割，区别于普通热刃、射手穿甲弹和神圣巨剑。主体保持已确认的代码二维画风，以深色承力架、金属受光面、少量金白高亮建立层次。

| 原生时间 | 表现 |
|---|---|
| 0–0.8秒 | 三片弧形外壳沿轨道展开；镜组滑入，光路逐步汇聚；中心角色仍可见。 |
| 0.8–1.4秒 | 镜组闭锁，光束收细；刃从根部向尖端传播成形；沿原有方向反向预摆，装置与刃连接。 |
| 1.4–1.76秒 | 严格跟随原生138度扫角；薄刃与有衰减的拖影表达高速，不用整片实心扇面遮住战斗。 |
| 1.76–2.71秒 | 从刃尖向根部卸能，细光流回收；核心降亮，镜组解锁归位。 |

命中使用短促锐切、定向热屑和局部热痕；盾吸收另走防御反馈，落空无命中重音。声音分为低声镜组运转、闭锁蓄能、释放破空、真实切中、卸载余响。按现有混音校准，不动普通热刃音色。原有命中顿帧、击退、18伤害、宽度、射程、目标锁定、免伤及免费短喷全部保留；画面不能使用不同于判定的缓动扫角。

## 验收
1. 同一种子前后战斗快照相同，含成功、落空、盾、无敌、沉默及暂停。
2. 镜组到光刃有连续连接；角色和敌人可读，普通热刃不变。
3. 实际扫角与渲染角一致；命中反馈只来自实际命中。
4. 观察完整顺序和关键帧，修复具体可见缺陷；音频经真实consume校准，试听另记。
5. 死亡、结束没有残留；记录采集场景、局限，不把功能通过写成观感或平衡通过。

## 最终改动边界

`laser-blade-art.js`仅重做奥义绘制与专用效果；`laser-blade.js`只给效果添加类别/方向及专用声音；`roles.js`只扩展专用视觉反馈名单；`renderer.js`只屏蔽已由专用切割绘制承担的通用星芒、圆环和粒子，保留相同impact供原镜头使用；`audio.js`和`audio-mix.js`仅相关5个音色。实际扫掠函数、18伤、宽度10、射程、0.36秒138度、总2.71秒、击退340、停帧、预瞄、防御及免费短喷逻辑不变。
