# 天使圣域03：有限肢体、十字圣兵与预先合翼

2026-10-23，按创作者对02的否决修订。02的长兵器迫使手腕离肩过远，动态骨长导致手臂外翻；离散火舌仍像排列的图标。两者不再视为通过的美术方案。

本轮观众应看清：天使握持尺寸适当的仪式武器，以正常长度的肩肘腕发力；羽翼在伤害前包住本体，承伤后释放白色圣火，火波结束才重新展开。剑为直刃、十字护手和圆首；枪为叶形尖刃、中央脊与金箍。采用宗教器物的轮廓语汇，保留代码2D色块，不复制写实材质。

实际看图：圣枪[维也纳藏品照片](https://upload.wikimedia.org/wikipedia/commons/6/6d/Heilige_Lanze_f.jpg)的窄叶刃、金包箍和翼状根部；[Coello圣米迦勒画像](https://www.philipkosloski.com/wp-content/uploads/2018/02/Claudio_Coello_-_Saint_Michael_the_Archangel_-_Google_Art_Project.jpg)的直剑、十字护手、抬臂握柄。这里只取造型与肢体关系，不作为游戏动态证据。沿用前轮已查看的火焰逐帧图和Valkyrie动作图；白火改为连根、翻卷、长短不齐的波前，拒绝圆周排列的独立小图标。

实体剑长为天使尺度0.90倍，枪总长1.45倍；双臂每段固定0.305倍尺度，手腕距肩最多0.58倍。实体兵器一直持有，超出实体可达处用圣光切刃/枪芒表达原攻击范围，不能靠伸长手臂伪装命中。原剑枪伤害、攻击范围和前后摇不改。

授权的机制变化：守护预测0.12秒内的接近威胁，已形成攻击包在结算前兜底；不能等扣血后才触发。保留6.5秒独立CD。守护减伤30%，走公共减伤入口，取较大值不额外叠加；真伤沿用原绕减伤规则。合翼0.055秒完成，0.12秒后放出原圣火波；至少保持至0.75秒且原波前已走完，再用0.4秒展开。守护优先于攻击/赐福，沉默、完全静止、暂停、退场和重开沿用系统规则。火波释放延后，范围、速度、伤害/灼伤和清理规则不变。

检查重点：各角度双臂不拉长或翻折；兵器跨阶段连续存在；威胁出现→合翼→承伤减免→白火→展开因果明确；共享盾、真伤、不叠减伤、友方/遮挡、沉默、冷却与清理保持兼容。自动检查与实际画面观察分别记录。
