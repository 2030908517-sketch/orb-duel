# 回旋球：逐刃追猎 / 交错斩 / 极限弹射

目标：普通阶段用接近和往返飞刃建立攻击机会，觉醒后让同一双刃根据距离选择合作方式。接刃奖励改为真正的有限时武器攻击，不能继续藏在身体碰撞倍率里。保留现有飞刃留印、回程斩印、命中音色和顿帧、回收返CD，奥义轮舞的运动/伤害预算保持。

机制：以出手时敌人中心距离230为有效射程门槛。觉醒前单刃沿现有弧线投返；远距单刃到最远点返程时，本体以正常巡航速度、限转向追向实际回刃，不瞬移、不免控，不压过击退/牵引。觉醒后近距两刃从相反侧切入锁定的预测位置，实际双命中才产生交错命中反馈，无额外爆炸伤害。远距两刃先沿对侧弧线到真实会合点，两刃实际相碰后主刃以560直飞、方向只在弹射时锁定，不再返程；副刃沿原返程回来。失刃、阻墙或会合失败只返剩余刃，不凭定时器伪造弹射。

初值：主/副刃4.1/2.3、去返单次与刃印倍率1.5、普通/觉醒投掷4.6/4.2秒、每轮回收返0.35秒不变。单/双接刃奖励各8秒，近身进入斩击范围后0.075秒锁向挥斩，单刃9、双刃13.5基础伤害，扇面真实判定、各敌一次、可躲避/挡盾/反伤；放出即消费，不随身体碰撞重复触发。常态身体倍率0.7，离刃再乘0.8，降低身体占比；这些作为集中可调初值，不宣称最终平衡。
