# 回天·双生轮舞：设计与实现记录

身份：人刃互为舞伴，以分离—追逐—交汇—换弧构成真实攻击，不做全屏伤害。实际机制核查：普通去程终点锁定且最多230距离，回程追主人；去程实伤留3.2秒刃印、回程×1.5，每刃每程限一次；离刃近战80%，完整/部分接回有8秒重斩及每轮0.35秒返CD；觉醒主4.1、副2.3。奥义保留这些结算语义，靠本体推进改善射程，不加必中与穿盾。

参考：已查看作者Untethered镰刀挥击GIF连续3帧，白色刃带随转身展开、尖端领先、旧轨迹迅速碎散；牵引GIF显示窄亮芯与端点收束。来源：https://vanaardekrynauw.com/blog/vo68g-untethered-stylized-vfx/ 。采用运动弧带与短时端点反馈，不照搬永久光绳。沿用已确认代码血刃的厚薄面和有限亮锋，青蓝主刃、淡银副刃，体积小且方向明确。交汇小闪与终舞闭环由真实接回事件驱动，不靠爆炸。短残影表示本体内弧，稀疏短牵引弧只在回程显形。音效沿用已校准throw/return/bladeCatch/moonCut，以破空、低掠气流、金属接刃构成动作节奏；终归叠两层既有金属/旋转声，不新增未校准音色、不声称人工试听。

流程：觉醒且生命≤30%每局一次；等待已有普通刃回手后0.36秒旋刃蓄势。四轮动态投返，第一轮外弧较舒展，本体从较短内弧追进；主刃进入回程后，以本体与刃的预测位置平滑求交汇点，双向追向会合区。真实接回才接力下一轮，换边切入；最后一轮更外展，双刃依次归环，0.35秒保留速度渐回正常。没有运动瞬移，无命中也继续追进；两秒回合失败、8.2秒整招时限兜底收势，失刃不冒充成功接刃。

初值：奥义生命228（经典/团队仍112），本体280至340，飞刃390，转向本体5.8/刃10rad/s，四轮主副刃伤害均沿原值×0.8；单敌整招最多10次、间隔0.16秒、基础总预算32再计加热。全程霸体但不无敌，普通碰撞照旧，不增加专属碰撞伤害，末环无伤害。投返碰撞复用原扫掠、墙、盾、反伤、刃印接口；舞步计时不受沉默和时间延缓重置。角色死亡、离场目标、对局结束及回溯需明确清理；经典与团队不接入此模式专属奥义。

验收：远距实际缩距、近距无需绕远、交汇有次数且动量连续；双刃轨迹互补非同心绕圈；墙角/墙牢无越界卡死，落空/目标离场有期限；护盾/无敌/反伤真实结算且无高频刷伤；霸体可受伤；接力和末归环可读，结束普通投返恢复。复用正式页与定向脚本，不做批量平衡；版本号保持不变。

## 实装、退回与最终评审

核心位于 `js/arcana-dance.js`，表现位于 `js/arcana-dance-art.js`，仅奥义入口加载。`arcana.js` 增加角色路由，普通技能在轮舞接管期间暂停自动投刃；飞刃仍沿 `World.update → sweep → bladePacket → resolveBatch → bladeRemoved` 实际结算，保留去回程单次命中、刃印、反伤及盾。普通技能只影响自身原控制，独立轮舞时钟不受普通减速/沉默暂停。主体位移与刃位移都经速度积分、限转向、墙扫掠，不设置本体到目标的坐标。墙牢采用实际bounds，飞刃为受保护奥义实体，奥义级实体裁切仍可摧毁并进入失刃兜底。

交汇点来自本体速度预测与回刃位置/速度预测的加权估计，再以5Hz指数平滑；本体转向会合区，回刃又跟随本体预测位置与该区，因此一方移动确实改变另一方路线。首轮身体内弧推进，外刃去程仍不超过原230初始投射距离，下一轮从新位置换侧出手。近距降低目标速度至约207～252、提高限转向30%、缩短外弧幅度，减少绕远。四轮都以实际接回/失刃触发，不是固定演出坐标。中途接刃返还冷却保留，重斩资格暂存，最终收势后恢复余下时长；不会在连续投返间隙反复消耗重斩。

初版视觉退回：普通moon、觉醒飞刃圈、接刃大圈与新刀光重复，实际画面像多组圆环。已在轮舞专属路径关闭重复绘制，刃带改连续收尖的填充带；斩印保留实际伤害和推力，但使用专属切割反馈，不叠通用爆光与停帧。最终归环只绘制两段互补光轨，不调用伤害接口。实际查看了最终远距分离/追逐/回归、近距、墙角、移动敌人、末环及手机画面；与参考的窄亮锋、连贯曲率、迅速收尾对照通过。普通接刃等旧技能本身没有改数值。

已运行 `verify-blade-dance.cjs`：少量定向场景反复检查有限坐标/边界，不是两万局平衡；远距接近至约46、四轮8次接回且无失刃，普通样本约4.6秒收势。覆盖近距、墙牢、盾、无敌、反伤、全程霸体但可受伤、沉默/驱散、动态双向影响、缺刃/硬时限、死亡/结束/重开、正常投刃恢复、表现只读、生命值模式隔离及已校准音色。270项音效政策、141项既有优先级检查通过。

正式页面四场景、14个顺序关键帧和正常速度连续运行的8个采样帧无浏览器错误，证据在本任务 `outputs/blade-dance/`。采集曾误复用暂停函数导致时间不前进，已修正助手，未据此修改产品；本机缺录屏ffmpeg，改用连续运行采样，没有声称看过完整录屏。声音采用既有已校准音色，波形未新增；未进行人工试听，最终金属共鸣层次及长期实战平衡待用户体验确认。未上传GitHub，既有版本标记保持不变。
