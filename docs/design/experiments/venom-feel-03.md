# 毒液第三轮：自然外缘、连续演变与布池间距

沿用已查看的用户黏液参考、Toxic Blob 连续帧和上一轮毒气体积截图，不新增无关研究。毒雾采用麻痹菱形同色#c6a2ff，通过暗紫密度底、淡紫气丝和局部亮边表达厚薄。移除圆形基底；液面与雾以不同频率的不规则轮廓收边，雾的密度在不规则边缘提前稀释，避免硬圆剪裁。普通→浓缩的绘制体积用缓动收紧，浓缩→雾先抬升汽化再扩散；仅表现尺寸连续变化，判定仍沿现有阶段规则。
