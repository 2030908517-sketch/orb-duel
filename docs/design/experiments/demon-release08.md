# 恶魔出门动作08：先开门，再出手

意图：让门成为攻击的明确来源。沿用既有0.45/0.55秒预警，在预警前60%内展开门，余下时间保留完整门与锁线；预警结束才由门口裁切逐渐露出爪或钉子。不开辟新的战斗阶段，不改变判定时间、伤害、锁点或控制。

造型：爪后改为连续暗红前臂，以收窄手腕、肌肉切面与两条局部筋线连接手掌，不使用金属链节；束魂本身的锁链不变。钉子在飞行、命中和持续定身阶段统一使用原留钉0.85尺度，不随第二门放大。

参考：重新实际查看已收录的CraftPix俯视怪物逐帧攻击表（work/demon-monster06-reference.png，来源 https://craftpix.net/product/tds-monster-character-sprites/ ），采用臂到掌的连续实体轮廓与关节方向，不移植绿色、像素纹理或完整怪物。再次查看已认可代码血刃锚点，保持有限亮边与红色切面。补充检索2D demon hand arm portal attack animation sprite；结果多为宣传插画及不合视角静帧，未作为动态依据，Bogleech图片读取失败，不声称已观察。门展开仍沿用原门结构，不新增法阵/粒子/音色。

验证：正式arcana.html加载实际脚本，固定种子release08，普通魔爪、普通穿魂钉、奥义穿身钉共27帧；11个预警帧均无爪、钉或手臂，12个含钉帧统一0.85，3帧含连续前臂。每次正式Renderer.draw前后snapshot相同，页面错误0。先前夹具直接替换页面导致ResizeObserver找不到arena，已改为追加评审画布，无产品修复。实际查看sequence.png及claw-0.65/0.8.png：门先展开、爪后连续前臂、命中阶段尺寸通过定点静帧与有序阶段评审；未进行完整实时播放评审，未试听、未声称长期性能或平衡通过。证据位于work/demon-release08-review/；修改前源文件位于work/demon-release08-before/。
