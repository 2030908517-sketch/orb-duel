# 激光球：热刃自卫 / 日轮·断界天刃

常规刃填补射后近身空窗，奥义是有重量的机械挥剑清场，两者均不是飞出去的月牙弹。沿用已确认Canvas代码色块：深铜机械面、暖黄刀身、近白核心和单侧刀锋，保留方向与实体厚度，不靠满屏白光。

常规全期同步三模式：每次主炮真正射完后获得一次自卫机会，仍在扫射、瞄准、沉默或奥义中不抢动作。敌球/敌对实体弹丸/飞行时钟/陷阱进入约112距离并预判0.06秒后位于刃程时触发，预备0.035秒、弧扫0.15秒、收刃0.12秒，刃长100、扫幅约126度。只沿锁定方向挥一次，每敌4基础伤；实际扣血后移动速度降至45%、1.1秒，无击退。消耗15%电容，不足部分以等量充能时间延后散热，不能免费出刀；下一次主炮释放才重新取得机会。扫中敌对实体则切断，不切光束、波面或队友物件。

奥义沿用低于30%且觉醒、每局一次、沉默豁免。奥义模式生命210，经典及团队保持105。日轮展开0.8秒：停身，三层分段机械环依次外展、反向旋转锁定，局部压暗背景，光粒吸入。光铸0.6秒：细引导光先伸出，再从刃根向尖端沿骨架铸出厚刀身，末段后仰并锁定方向。断界0.36秒：机械环驱动约138度真实扇扫，刃长为场地对角线的88%，薄拖尾只记录已经扫过部分；每敌一次18基础伤、强击退与仅命中短顿帧。只有挥斩前0.14秒免伤；蓄势和回收可受伤。全奥义期间霸体，免疫碰撞、击退和拉拽等强制位移，墙壁仍约束；霸体本身不减伤。激光刃与本体判定分开，不触发陷阱球本体碰撞奥义。万光归零0.95秒：先显分段裂纹，沿刀身逐段剥离碎光，先外散再逆向回到核心，三环依次收拢，恢复原移动与正常充能。死亡/重开/结束清理，不追加迟到伤害。
