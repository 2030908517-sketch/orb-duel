# 动画回看

目标：逐帧看清实际动作和命中反馈；退出后仍停在原来的暂停位置。历史画面与实时战斗必须明确分离，不恢复战斗快照，不改规则，不重复发声音。

## 使用

- 三个正式模式均自动缓存最近约20秒实际画面。点击「回看 V」或按 V 进入，运行中先走现有暂停入口；开场尚无画面时不进入。
- ← / → 前后一张已记录帧；Shift 加方向键跳10帧；按钮跳回5秒、10秒，或向前5秒；拖动时间轴定位。
- ¼×、½×、1×播放；空格播放/暂停**回看**。V 或「返回对局」退出，之后空格才继续实时对局。R 退出回看并重开，缓存清空。
- 结束后也可回看；F 的横屏、竖屏、退出循环仍可使用。控制条出现时完整画面会缩小避让。

## 实现边界

`js/animation-review.js` 在正式渲染及UI刷新之后抓取Canvas和对应战斗面板；画面静音压缩为WebP，最长边宽800像素，按浏览器实际完成的采集帧记录。重放只解码压缩图并叠加只读面板，保留实时DOM与选择框。

缓存按**观看时间**保留约20秒（暂停间隔不计），不是固定20个模拟秒；8倍速时模拟时间跨度更长。卡顿、编码耗时或高倍速下不存在的画面不插帧。时间轴显示原对局时间、距最新画面的观看秒数及帧序号。加速播放不是更精细的采集；检查高速动作宜用1倍速。

上限为1250张、64 MiB压缩图及面板文本估算量；先到上限先淘汰旧帧，复杂场景可能不足20秒。估算不包含浏览器编码器与DOM内部开销，因此不等于进程总内存限制。只保留一张解码显示图；没有后台录音、文件导出或战斗分支重演。

重开采用代次标识丢弃异步旧帧；进入回看也丢弃未完成编码，避免时间轴在选择后移动。回看暂停期间检查引擎快照保持一致，退出时不恢复、不重置或推进实时引擎。

## 本次验证（2026-10-19）

浏览器检查三模式的缓存、单步、跳转边界、慢放、状态隔离、横竖屏入口和重开；真实Canvas采集夹具验证20秒淘汰、结局只采一次及重开丢弃异步结果。实际检查回看截图，发现控制条遮挡场地后加入缩小避让，并修正速度选择框过宽。1080×1920竖屏检查完整画面在控制条上方。

本轮证据位于工作区 `work/animation-review/`。声音刻意不回放；未进行长时间性能基准或所有浏览器兼容性评估，用户需主观确认复杂技能慢放的观感。
