# 毒液球 V2：正式机制与调参

当前机制（不变更入口版本号）：经典1v1、奥义模式常规部分、2v2共用；奥义「腐生·万毒缓蚀」、血量和心跳保持原机制。旧自动毒爆、剩余毒伤折现、旧共鸣范围伤害与三向液滴生成路径已移除。

## 毒层与时钟

侵蚀与麻痹共用4槽、单类最多3层，每层保存类型、来源、创建时刻与到期时刻。每个来源对同一目标的碰撞、毒弹和全部区域共用1.1秒施毒间隔；换区域、反复进出、净化均不返还已消耗的间隔。两名毒液球各自拥有施毒间隔，但共享目标容量、替换进度和替换冷却。

未满槽时新增；同类已达3层时只刷新该类剩余最短的一层，其他层不刷新。满槽且该类仍有容量时，每次有效施加累积一次进度，2次后只替换对方剩余最短的一层。替换后目标进入2秒冷却，期间进度最多积到2，但要等冷却结束后的下一次有效施毒才替换。掉层、补层仍正常；所有层自然到期也不会提前返还替换冷却。非满槽时清空不再适用的替换进度。

侵蚀每0.5秒按当时有效侵蚀层数结算，不消耗层数、不折现被替换层，不因新施毒、替换或进出区域重置时钟。净化清掉毒层和替换进度，但不清奥义伤害池、不返还已花费的施毒/替换CD；重新施毒仍沿原固定结算相位。毒雾低额区域伤害另有时钟，不靠反复进出加快，也不按重叠毒雾数量叠加。

## 三态与控制

普通池主要施侵蚀；浓缩池变小，侵蚀层持续更久，每两次有效施毒额外施加一次麻痹（可补层或积替换进度）；雾变大，主要施麻痹、低额区域毒伤及只在雾内的普通瞄准扰动。同源区域重叠优先选择雾、浓缩、普通池，每次只处理一处。同源同目标毒雾低额伤害也只结算一次。池及雾不能穿过团队障碍、陷阱囚笼和护盾奥义城墙；离场/无敌/虚化及友伤按现有规则处理。

麻痹降低实际移速，不改存储的基础速度、超速挡位、技能CD或时间流速。仅降低对外普通身体碰撞伤害；冲刺、重拳、压力强化、接刃重击、动能强撞及奥义等专属强攻击排除。普通瞄准转向与雾中扰动接入现有瞄准，兼容激光、射手、飞行时钟、毒弹、反击预瞄，以及加速/幽魂的预瞄；霸体免疫移动与瞄准控制，奥义瞄准不受影响。

觉醒「万毒·同巢共鸣」：携侵蚀接触液池触发2.6秒活体缠缚，向外阻力45%、有限回拉、侵蚀增伤15%；携麻痹进入毒雾触发3.2秒附身毒群，离开原区域仍跟随并尝试侵染。两类共鸣各4.5秒再次触发间隔，共用原1.1秒施毒CD。净化可清除、霸体免疫缠缚，奥义伤害池独立保留。旧定时催化路径已移除，三态仍自然按时间演变。

区域施毒由实际捕食代替：普通触须、浓缩弹跳毒团、毒雾汇聚侵染，接触后短暂附着再入体。可以落空；不跨墙。麻痹、毒雾、附身和菱形全部绿色，用形状区分双毒。参数见 `js/living-venom.js` 的config及[实现记录](experiments/living-venom.md)。

## 观察和验证

93项新机制定点检查；原伤害池107项、心跳14项、奥义交互141项、时间回溯861项、声音政策270项通过。只将时间回溯专项的旧毒爆冷却断言换成新共享施毒冷却断言，没有改时间球规则。

正式三个入口各运行10秒定向对战，未出现异常数值、页面错误或旧毒爆。实际打开并查看三态同场、自然演变的有序帧、团队画面与手机尺寸截图。首轮毒雾形状过于规则像花瓣，已改错落云团并重新观察；绿点/紫菱形槽位在球旁可读，毒层增减实时跟随战斗。截图与调用结果在本聊天outputs/venom-v2。没有主观试听（音色沿用已校准资源）、没有进行大规模平衡测试。

开发者控制台可用 `OrbDuel.Venom.inspect(目标球, 当前引擎)` 查看各层类型/来源/剩余时长、替换进度与冷却、施毒门限和跳伤时钟；不会新增游戏UI。

## 自然毒区与布池间距（20261017-venomfeel3）

毒雾统一麻痹菱形紫色#c6a2ff；视觉外缘自然起伏，收缩/汽化连续演变，进入反馈增强。新增可调 `G.Venom.config.poolGap=8`：同一来源新区域按双方最大形态半径留空，优先原位、否则最近合法空位，不跨城墙/牢笼/掩体；实在无处可放则不生成，原放池CD沿用。上限检查找到新位置后才回收最早池。旧区域不移动，跨来源重叠沿既有结算，不改双毒与奥义机制。

附身毒群当前追赶速度：`LivingVenom.config.swarmSpeed = 220`；从原毒雾位置追赶，首次追上后同步宿主位置，不再以指数滞后追随。寿命和施毒CD保持。浓缩池最多3个气泡；普通触须以固定隆起点、持续挤出材料与阻尼曲线表现，附着后仍保留带身，不绕珠旋转。


## 觉醒永久成长：毒素兴奋

觉醒后，携侵蚀的敌人进液池并成功建立缠缚，侵蚀强度本局增加2%；携麻痹的敌人进毒雾，追猎毒群实际追上附身后，麻痹强度本局增加2%。两项分别累计，各上限20%，按原始效果相对增加，非每次增加1个百分点减速。

成长归属触发共鸣的毒液球；对其当前及之后施加的对应毒层生效。侵蚀成长与缠缚15%增伤相乘；固定毒伤周期不变，毒雾0.18区域伤害与毒弹直击不额外增强。麻痹成长放大减速、普通对外碰撞削弱、普通瞄准转速削弱和雾中扰动；保持霸体与专属强攻击例外，不改CD。

同一池/雾的一次进区访问、同类毒素只奖励一次，持续停留、输送、刷新、净化不刷成长；离开后再进入仍须实际通过原共鸣冷却和成功条件。未觉醒、无对应毒层、牵引被霸体阻止、毒群未追上或失效均不奖励。普通净化不删除成长，时间回溯保留永久成长，重开清零。源球状态栏显示两项当前增幅，敌方状态百分比按实际强度计算。

参数集中在`js/venom-evolution.js`的config：step=0.01（存储单位，允许半单位），resonanceGain=0.02，collisionGain=0.01，vampireCollisionGain=0.015，pactGain=0.005，cap=0.20。经典、奥义、2v2共用，队伍多个毒液球独立成长，混合毒层按各自来源计算。新增脚本不变更已有入口版本号。


身体碰撞成长：仅觉醒后，真实接触敌人时，按该敌人在此次碰撞前已有的毒种，各+1%；与共鸣+2%共享各20%的封顶。持续贴住不重复，同一模拟步的同一对接触不重复，不把飞行物/技能命中当身体接触；友军不触发。永久成长归属规则沿用上节，不改毒层或施毒CD。

触须根部：连接处透明衔接池面底色，取消异色硬边；根点与最初3.5逻辑单位的出液朝向固定，目标运动只影响后续带身。


### 吸血球交互补充

沿用觉醒后的成长条件：真实身体碰撞吸血球时，按其碰撞前已有毒种，各增加1.5%；其他敌人仍为1%。吸血球血契对毒液球每段有效伤害（含护盾吸收及收束伤害）使侵蚀、麻痹各增加0.5%，完全免疫或失效不增加；两类仍分别封顶20%。血链新增绿色黏液向吸血球传递的表现，不额外加毒层。原收束净化保持，永久强化不被净化；状态显示支持半个百分点。
