# ORB DUEL｜视觉参考素材规范

在设计或实现任何角色技能、奥义、攻击动作、运动轨迹、打击反馈及视觉特效时，如需搜索外部参考素材，必须遵守以下原则。

## 1. 优先匹配游戏表现形式

ORB DUEL 是一款小型竞技场中的 **2D 平面自动战斗游戏**。

搜索参考素材时，优先选择：

- 2D 游戏实机画面、2D 游戏特效、逐帧动画、Sprite VFX
- 俯视角和平面竞技场战斗
- 2D 动作游戏、弹幕游戏、Arena Combat、Twin-stick Shooter
- 风格化的刀光、冲击波、能量、闪电、火焰、拖尾、碰撞反馈等游戏特效
- 高质量的游戏战斗动画 GIF、视频片段及特效演示

**不要因为图片包含相同的技能元素，就认为它适合参考。**

例如，搜索斩击特效时，3D 人物在房间里挥剑产生一道光圈，并不等于它适合 2D 平面游戏。

## 2. 必须考虑表现形式是否兼容

筛选参考素材时，依次判断：

1. **视角是否兼容**：能否在 2D 平面竞技场中自然呈现？
2. **动作是否兼容**：是否符合小球的运动、碰撞和技能机制？
3. **视觉语言是否兼容**：是否适合当前游戏的画风、线条、色彩和特效层次？
4. **规模是否兼容**：缩小到实际竞技场和角色尺寸后，是否仍然清楚？
5. **效果是否可迁移**：能否提炼其特效造型、动画节奏、运动规律或打击反馈，而不依赖原作品的 3D 场景与人物骨骼？

## 3. 排除低相关性素材

不要优先使用以下素材作为核心参考：

- Roblox 风格、3D 沙盒、3D 测试房间中的技能演示
- 写实人物动作、影视特效、真人拍摄
- 单纯展示粒子系统或引擎功能的通用素材
- 只有技能图标、宣传插画或静态概念图，没有实际战斗表现的素材
- 只有颜色或技能名称相似，但动作逻辑完全不同的素材
- 充满无意义粒子、遮挡角色或难以判断攻击范围的效果

并非完全禁止使用 3D 参考。如果某个 3D 特效的节奏、冲击、形状或运动规律非常优秀，可以提取这些抽象设计原则，但不能直接照搬其镜头、空间结构或模型表现。

## 4. 根据具体技能动态搜索

不要对所有技能使用同一套关键词。

先分析当前技能最重要的表现需求，再组合英文关键词进行针对性搜索。

例如：

- 高速移动：2D dash trail / speed lines / afterimage VFX
- 碰撞打击：2D impact VFX / hitstop / impact frame
- 回旋武器：2D boomerang attack / spinning blade trail
- 闪电：2D lightning strike VFX / electric arc animation
- 激光：2D laser beam VFX / beam charging effect
- 毒液：2D poison VFX / slime animation / toxic mist
- 防护：2D shield impact / barrier break VFX
- 爆炸：2D explosion spritesheet / stylized explosion animation

根据需求继续追加 top-down、gameplay、pixel art（仅在像素风适用时）、hand-drawn、stylized、animation、GIF 等限定词。

优先查找真实游戏中的成功案例，其次是专业游戏特效作品和教学演示。

## 5. 重点学习动态表现

对于需要运动或时间变化的技能，优先参考视频、GIF、逐帧动画，而不是单张截图。

关注：

- 前摇、蓄力和危险预告
- 角色及攻击的运动轨迹
- 加速、减速、停顿与爆发
- 命中瞬间的停帧、形变、闪光和震动
- 特效的扩散、消散和收束
- 音效与画面动作的同步关系
- 战斗信息的清晰度

不要只模仿素材的外观，要理解它为什么能够产生力量感、速度感、重量感或爽感。

## 6. 参考素材必须经过筛选

搜索后先判断参考素材的实际相关性，而不是直接采用搜索结果排名靠前的图片。

每个被采用的参考都应明确说明：

- 具体参考什么
- 为什么适合当前技能
- 哪些部分不应该照搬
- 应如何适配 ORB DUEL

对于明显不匹配的素材，应主动舍弃并继续搜索。

不要虚构参考来源或把未经确认的图片描述成某款游戏的实际效果。

## 7. 最终原则

**参考素材是为了学习优秀作品的视觉设计规律，而不是复制一张表面相似的图片。**

宁可少找几张真正适合的 2D 游戏参考，也不要大量收集风格不符、视角不符、无法应用的素材。

最终实现必须服务于 ORB DUEL 本身的画风、角色机制、运动逻辑、战斗节奏与观赏体验。
