# 来源登记与阅读边界

检索与访问日期：2026-10-15。优先采用原作者论文、开发者自己的讲义、官方文章和制作团队访谈。网页可能变更；记录的是本次实际取得的内容，不保证未来持续可访问。PDF 页码默认从 1 开始，非工具内部的零起始编号。

“正文相关章节”表示取得正文并读了用于本库的部分，**不表示逐字读完所有页面**。视频嵌在文章里也不表示已观看。下列摘要均为简短转述，知识卡中的项目推导由本库承担。

<a id="s01"></a>
## S01 · Good Game Feel: An Empirically Grounded Framework for Juicy Design

Kieran Hicks、Patrick Dickinson、Jussi Holopainen、Kathrin Gerling，DiGRA 2018。
[论文与元数据](https://dl.digra.org/index.php/dl/article/view/936/) · [17 页正文](https://dl.digra.org/index.php/dl/article/download/936/936/933) · DOI：10.26503/dl.v2018i1.936。

- 阅读：方法、框架迭代、Candy Crush Saga / Downwell 分析、讨论与局限，尤其 PDF 第 10–15 页。
- 可支持：Juice 需要与主题、游戏状态和反馈的重要性协调；不是后期撒一层粒子。框架来自 17 名开发者问卷及研究者分析。
- 边界：小规模质性研究；不能据此给出最佳粒子数量或证明某个手段一定愉悦。商业游戏案例是论文作者的分析，本次未实玩。

## S02 · How does Juicy Game Feedback Motivate? Testing Curiosity, Competence, and Effectance

Dominic Kao、Nick Ballou、Kathrin Gerling、Heiko Breitsohl、Sebastian Deterding，CHI 2024。
[作者提供的正文](https://people.csail.mit.edu/dkao/pdf/3613904.3642656.pdf) · DOI：10.1145/3613904.3642656。

- 阅读：摘要、实验设计概述、讨论、设计启示及局限，特别 PDF 第 12–14 页。
- 可支持：预注册、1,699 人的动作 RPG 实验中，与成功关联的反馈有益；放大反馈并非一致有益。作者提出因果归属及信息层级受损的解释，但没有直接证明该中介机制。
- 边界：特定实现，不能外推为“华丽特效不好”；作者明确不主张结果代表所有 Juice 定义或工业级打磨。没有直接测试 ORB DUEL 观众。

## S03 · Juicy Haptic Design: Vibrotactile Embellishments Can Improve Player Experience in Games

Tanay Singhal、Oliver Schneider，CHI 2021。
[作者实验室项目页、方法和结果](https://uwaterloo.ca/haptic-experience-lab/projects/juicy-haptic-design-vibrotactile-embellishments-can-improve)。

- 阅读：项目页全文；未观看视频，未取得并精读完整论文。
- 可支持：38 人组内 Breakout 实验比较视觉与触觉装饰；有触觉优于无触觉的一些体验指标，但低、高装饰多数指标没有显著区别。
- 边界：触觉研究，不能当作 Canvas 视觉或声音强度的直接结论；只能交叉提醒“更多不必然更好”。

## S04 · Principles of Traditional Animation Applied to 3D Computer Animation

John Lasseter / Pixar，SIGGRAPH 1987，Computer Graphics 21(4):35–44。
[原论文的大学课程存档](https://www.cs.utexas.edu/~fussell/courses/cs384g-spring2010/projects/animator/lasseter.pdf)。

- 阅读：原则列表及形变、时间、预备、布局、跟随和逐帧/关键姿势相关正文。
- 可支持：动作时序、姿势和形变共同传达重量、意图与连续性；实例含 Luxo Jr.。
- 边界：该论文列出 **11 项**，不能谎称它完整列出了今天常见的十二原则；“扎实造型”由 S05 补充。电影动画经验不等于交互战斗的时长标准。

## S05 · 12 Principles of Animation

Adobe 官方动画教育文章，未据页面确认首发年份。
[正文](https://www.adobe.com/creativecloud/animation/discover/principles-of-animation.html)。

- 阅读：十二项的解释，特别辅助动作、时间、夸张、扎实造型、吸引力。
- 可支持：十二原则的当代教学分类；吸引力不限于可爱角色，辅助动作不应抢主动作。
- 边界：教育性概述，不是十二条效果的受控实验。文中的审美概括不能当作关于性别、性格或形状的普遍心理定律。

## S17 · A Century of Gestalt Psychology in Visual Perception: I

Johan Wagemans 等，Psychological Bulletin，2012。副标题：Perceptual Grouping and Figure–Ground Organization。
[47 页作者论文的学术存档](https://dev.ipol.im/~blusseau/biblio/psychophysics/2012-wagemans--A-century-of-Gestalt-I.pdf)。

- 阅读：分组与图底关系概述、接近/相似/共同命运、同步性，特别 PDF 第 9–11 页。
- 可支持：同时变化、共同运动等线索会影响知觉分组；多个分组线索可能合作或竞争。
- 边界：视觉研究综述；不直接证明某种球的配色最爽，也不能把“靠近就一定被看成一组”当绝对规则。

Robert Sekuler、Allison B. Sekuler、Renee Lau，Nature 385:308，1997。DOI：10.1038/385308a0。

## S20 · Habituation Revisited

Catharine H. Rankin 等，Neurobiology of Learning and Memory 92(2):135–138，2009 卷期 / 2008 在线。DOI：10.1016/j.nlm.2008.09.012。
[作者稿全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC2754195/)。
