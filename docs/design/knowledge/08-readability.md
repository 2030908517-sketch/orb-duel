# 08 · 高速战斗中的视觉可读性与信息层级

[索引](README.md) · 关联：[VFX](04-vfx-and-visual-language.md)、[音效](05-audio-and-mixing.md)

“清楚”不等于无特效，也不等于能同时看见全部细节。目标是在有限注意力下读到当前最有意义的信息，并保留继续追踪的条件。以下建议是面向中立观众的设计推导。

## READ-01 · 先回答谁、哪里、朝哪、何时和结果

**原理与心理。** 高速事件不给观众反复辨认的时间，稳定的身份与方向线索能减少重建成本。圆球几乎没有朝向，尤其需要把本体移动方向与武器发射方向区分。

**适用与协同。** 小球交叉、弹射、瞬移和多角色战斗。静态轮廓帮助识别，头尾关系帮助看方向，预警帮助看时点，受击结果帮助看因果；不要让同一个光点承担全部信息。

**误用反例。** 弹丸前后完全对称，转播暂停后看不出往哪飞；武器朝敌人，但装饰尖端跟着移动方向，造成相反暗示。

**案例与来源。** League 文章要求飞行物即使静止也能表达方向，并用角色轮廓承载识别。将其用于圆球是本库迁移。[S07](SOURCES.md#s07)。

**ORB 建议。** 保留用户对射手外形等已确定取舍；需要方向线索时优先利用攻击本身和已有标识，不擅自加回凸出枪管或本体光晕。

## READ-02 · 冗余编码与一致分组，避免颜色独自承担含义

**原理与心理。** 相似、接近和共同运动会影响对象分组；一个属性不足或被遮挡时，第二个独立线索可以补充。但多个线索若互相冲突，反而让分组更难。

**适用与协同。** 2v2 队伍、角色身份、持续状态。队伍、角色、技能功能最好分别有合适的线索组合；例如队伍标记与角色图案分别承担不同含义，不让一种颜色同时表达三件事。

**误用反例。** 同色粒子自动看起来属于同一人，而实际来自双方同种球；连接线越过障碍仍像有效伤害线；只靠红绿区分队伍。

**案例与来源。** S17 综述分组线索及其相互作用；S07 的轮廓与动画识别提供生产侧对照。研究没有证明任意两个提示都会改善识别。[S17](SOURCES.md#s17)、[S07](SOURCES.md#s07)。

**ORB 建议。** 保留既有队伍标识和角色图案的职责。魂影、彗星等脱离本体对象需要可解释的归属；装饰连线不应看起来像另一条有效感应线。

## READ-03 · 持续信息保持稳定，瞬时信息抢占后应归还注意

**原理与心理。** 频繁变化容易吸引注意；长期存在的区域若内部一直高强度变化，会和每次真正出手争抢。稳定不代表不可见，而是让变化本身具有信息价值。

**适用与协同。** 地面危险、护盾存续、长蓄力和状态栏。持续区用清楚的边界与有限内部运动；命中瞬间才有局部强调；UI 的状态位置保持稳定，减少与战场之间的重新定位。

**误用反例。** 毒结束就收起一行面板，页面上下跳；水渍像虫子移动；持续领域每帧闪烁，奥义反而不突出。这些是历史需求的诊断情境，不是本次浏览器观察结果。

**案例与来源。** S14 的视觉层次、S07 的噪声预算和 S20 的重复刺激讨论为本卡提供不同角度；具体面板稳定性是工程与体验推导。[S14](SOURCES.md#s14)、[S07](SOURCES.md#s07)、[S20](SOURCES.md#s20)。

**ORB 建议。** 延续始终留出状态栏的约定；地面场应能在外观低动态时仍被读作危险。不能为了安静而删掉有效范围，或改变状态持续时间。

## READ-04 · 高速可读性依赖连续线索，不只依赖减速

**原理与心理。** 帧间位移很大时，观众难将离散位置连成同一运动。方向性拖迹、关键姿势和清楚的接触后果可帮助跟随；整体减速不是唯一方法，而且会影响节奏。

**适用与协同。** 高速冲刺、沿墙雷化、弹射彗星。让路径连续地说明经过何处，实体头部交代此刻位置；转角保留运动连续关系，音头与重要接触点提供标记。

**误用反例。** 轨迹由突然出现/消失的大圆串组成，像在抽动；拖迹比本体更像实体；为了看清而把高速技能随意减速，改变其玩法效果。

**案例与来源。** S04 讨论高速帧间跳跃与运动拉伸；S06 的格斗拉伸帧示例说明图像可为运动连续性服务。不是所有攻击都应该模糊。[S04](SOURCES.md#s04)、[S06](SOURCES.md#s06)。

**ORB 建议。** 区分用户要求保留的本体拖尾与技能留下的魂影路径，两者职责不同。任何轨迹重做要先说明是危险路径、历史经过还是未来预警，不混用。

## READ-05 · 同时事件需要竞争规则，不能靠“全部延迟一点”解决

**原理与心理。** 观众注意不是无限的。多个技能同时发生时，每个事件的装饰都按单独演出最大化，会失去比较基础；但把所有反馈排队又会破坏真实时序。

**适用与协同。** 2v2、同帧碰撞与反伤、多人持续伤害。重要预警、实际目标和关键接触保留，次级碎屑可减少；声音与 UI 采用相近的语义层级，但不要求它们选择完全相同的主角。

**误用反例。** 为避免拥挤，把反伤数字延迟到敌人下次被打，造成错因；永远只突出左队，右队关键事件被淹没；表现限流顺带漏算伤害。

**案例与来源。** S07 的技能重要性层级和 S10 的音频分桶提供跨通道对照。本库不照搬第一人称的距离排序。[S07](SOURCES.md#s07)、[S10](SOURCES.md#s10)。

**ORB 建议。** 对称地分配注意，以事件战斗意义和当前上下文为依据。表现降级应只减少装饰；必要的结果线索仍跟真实事件时点走。

## READ-06 · 大演出仍需要输出尺度与舒适性检验

**原理与心理。** 在大显示器上可读的细节，缩小视频后可能消失；震动、全屏高对比闪烁可能压倒目标追踪。舒适性和可读性不是对壮观的否定，而是决定壮观能否被持续观看。

**适用与协同。** 全屏奥义、多次闪爆、长时间观战。采用大轮廓与明确运动实现规模，避免只依赖高频闪白；在实际页面、较小视频尺寸和密集对局中检验。

**误用反例。** 静态关键帧很漂亮，连续观看却找不到球；把减少闪光理解成奥义必须很小；仅依据闪烁次数就声称安全。

**案例与来源。** S23 给出光敏相关风险与检测方向，S07 强调重要事件可以醒目；两者需要同时考虑。本文不提供医学保证或认证。[S23](SOURCES.md#s23)、[S07](SOURCES.md#s07)。

**ORB 建议。** 未来分别检查“信息看清”“可连续观看”“闪烁风险”；截图无法覆盖后两项。降低装饰闪烁时保留巨大主体、方向和冲击后果，不退回小而弱的演出。
