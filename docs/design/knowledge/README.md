## 证据如何阅读

- **研究**：论文中的实验结果或综述。有效范围受样本、任务和刺激材料限制；相关关系不是因果，实验中的因果也不自动适用于本项目。
- **实践**：开发者对自己作品、流程和设计意图的说明。能提供有效方法，不等于普遍的心理学定律。
- **推导**：本库基于上述资料提出的解释、反例和 ORB DUEL 建议。需要之后观察或实验，不包装成来源原话。
- **待证**：尚无足够资料，或必须看片、试听、用户测试才能判断。

各章知识卡中的“心理与原理”“适用与协同”“误用”“ORB”默认是**设计推导**；外部研究结论和游戏制作事实会单独标明来源。案例分为开发者记录的案例和本库提出的假设对照，后者不声称是商业游戏的真实做法。

本次读取了可访问的论文、讲义文字和开发者文章的相关章节；**没有完整观看 GDC 视频，没有进行商业游戏实机体验或音频试听，也没有评定现有 ORB DUEL 的视听品质**。来源登记具体写明“正文相关章节”“摘要”“检索摘录”“未取得”，不把能打开一个页面算作读完一本书。

## 本项目的迁移边界

ORB DUEL 的观众不操控角色，因此“按键响应快，所以有掌控感”不能直接移植。这里优先关心的是：角色意图能否预期、攻击过程能否跟随、结果能否解释、重要事件能否留下记忆。

本库里的击退、顿帧、护盾、范围等均以**现有战斗事实**为前提。位移、受击硬直、模拟暂停、目标选择、伤害和碰撞半径属于玩法；任何有关它们的修改，不能只凭表现建议实施。动画插值、音色、装饰碎屑也不能制造假的命中事实。

夸张不是禁忌。一个很大的血刃、一拳的长蓄势、遍及场地的超新星都可能恰当。应判断它们是否表达了角色与事件，而不是把“简洁”误解为所有技能都小、短、轻。

## 知识的保存方式

知识卡用稳定编号引用，例如 `IMP-02`、`AUD-03`；来源用 `S01` 等编号。以后补充研究时保留编号，记录条件和反证，不把单次审美反馈升级成永久定律。推荐把具体改动记录留在任务评审中，只把可迁移的新认识提炼回本库。

第一版覆盖八个专题；它是一份有边界的研究综合，不是穷尽所有论文的系统综述，也没有做元分析。未完成的证据工作见第 09 章。
