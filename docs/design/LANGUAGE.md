# 表现语言

## 视觉、角色与信息

- 保留深色竞技场、清晰球体轮廓和现有角色标识。颜色同时配合形状、方向与运动规律区分角色，不能只换颜色。原拖尾与“去掉常驻光晕”决定保留。
- 预警说明未来危险：位置、方向、范围、锁定时刻；命中说明已经发生的结果。装饰尾迹、余波不得伪装成新的伤害判定。真实范围与视觉核心尽量对齐，装饰区要更弱。
- 为每个角色选择一组稳定词汇：例如锐利切面与扫掠、流体合围与回流、压缩空气与破音。这些是设计例子，不重命名或替换现有机制。
- 强度按“普通接触→强化/高伤→觉醒关键动作→一次性奥义”建立明显差异；持续低伤、连段碎片与多根同时落柱要合并次要反馈，保留主节拍。
- 先设计主形、明暗和留白，再加边缘细节。夸张可以很大，但应有一个主视觉中心，避免数个同强度光环、斩线、闪白互相遮盖。检查球体大小参照、画面缩小后和2v2叠放时仍否可辨。
- 生命、护盾、状态与冷却使用已有固定槽位；提示放在面板或场外。禁止状态出现/消失挤动场地，禁止全程遮住危险区。区分伤害、吸收、免疫、落空和收益，避免所有结果都播“命中成功”。

## 动作与状态衔接

按需使用“预警→移动→蓄势→释放→接触→反应→收势”。不是每个技能必须七段，也不是每段都必须暂停。明确每段由哪个**战斗事实**进入，何时锁定方向、攻击是否仍存在、打断后剩下什么。

| 阶段 | 表现目的 | 常见错误 |
| --- | --- | --- |
| 快速位移 | 读懂路径与落点，突出速度 | 位移途中卡住、攻击未出拳影先覆盖敌人 |
| 到位蓄势 | 姿态、留白和声音制造“接下来危险”的预期 | 每招强制长冻结，背景仍伤害或偷偷推进CD |
| 释放 | 速度反差、明确轮廓和主声音 | 长蓄力后仍轻飘，放大却更难实际命中 |
| 接触 | 命中点、方向与能量转移 | 落空也播命中重音，持续伤害每帧顿一下 |
| 反应/收势 | 击飞、回流、碎裂、恢复正常节奏 | 全部特效瞬间消失，或余效一直占屏 |
| 取消/免疫 | 清楚收起未释放部分，保留已经释放实体的规则 | 为演出取消伤害、自动追踪或绕过防御 |

**蓄势停顿**是为了建立预期；**命中顿帧**是为了强调接触。先确定用途，再决定是否需要。普通接触通常不需要额外顿帧；多段攻击选关键落点，不逐段累加。镜头震动与顿帧也不是一回事。

已有真实击退、位移、无敌、控制和技能计时属于玩法。新表现事件无权改变这些数值，也无权暂停模拟。若要引入真实动作阶段、全局停顿或更远击退，先明确这是玩法/时序改动，按用户授权走战斗模块及专项测试。原有时钟停顿不在本规范任务中重新调参。

## 声音语言

全局分级、逐音色校准、压低与峰值规范见 [AUDIO_MIX.md](AUDIO_MIX.md)。

- 先用文字描述声音：材质、重量、攻击瞬态、主体、余韵、听觉位置。例如“短裂响+可听见的中低频撞击+衰减轰鸣”，比“更大声”可执行。
- 预警、位移、释放、命中、盾吸收、免疫和恢复应有不同职责。奥义拥有独立的起势、主体和尾音，不能简单重复普攻或把所有小技能都盖住。
- 重要冲击需要瞬态与中频主体；只加极低频在普通扬声器上可能听不清。混响和长尾服务空间及余力，不能填满整场。避免把钟声等高辨识音在一轮多实体中重复几十次。
- 共用事件标识与阶段时间调度音画；同一轮齐落只播放合适的组声音。申请声音不等于实际播放：记录被合并、受并发/冷却影响及真正排入音频时钟的情况。
- 使用原有并发、优先级、限幅和奥义压低普通声机制；静音、暂停和重开立即清理。不要用无上限增益表达升级。
- 素材与合成均可用；采用素材需记录来源、许可与处理。没有试听能力时只做技术分析和候选，明确“未试听”，不凭名字断言合适。

## 打击感与正反馈

把“接触前的预期→接触瞬间的反差→接触后的真实结果”连起来。击退先核对真实速度方向与距离，再加冲击图形、受创姿态和镜头；不能靠拖长闪白伪装动能。高伤与强化可加强反馈，但阈值和实际推动由战斗规则决定。

反馈让观众理解因果：资源累积有渐进变化，满格有清楚准备状态，技能成功后有明确兑现；防御成功与攻击成功要各自可读。补偿机制等玩法不由表现评审擅自新增。

## 舒适度与性能

全屏高对比闪烁要少且短，优先用局部能量、轮廓、形变与明暗反差。不把“夸张”变成连续白屏；尊重现有减少动态效果设置。新事件相机响应提供独立关闭/降幅，不能改变胜负。

新事件默认最多24个活动表现、每帧256颗装饰粒子、800条诊断时间线；超量合并或丢弃低优先级表现，不能丢战斗伤害。它们是**新通道的预算**，不声称已限制所有旧角色渲染。记录设备、分辨率和实际采样；渲染函数耗时不等于真实帧率。
