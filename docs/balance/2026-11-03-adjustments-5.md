# 2026-11-03：回血、护盾存续、麻痹近战与减速跟瞄

本轮基于第四轮调整后的版本。此前780局报告仍为本轮改前统计；本轮只做定点与相关回归，不据此宣称胜率或平衡已通过。不改版本号，不提交或推送。

## 当前规则

| 项目 | 本轮行为 |
| --- | --- |
| 吸血球普通吸血 | 实际生命伤害的34%→32% |
| 吸血球奥义吸血 | 72%→78%；血海每浪4、总计20的回血上限不变，仍在重生时统一结算。共用该配置的团队旧版血刃同步78% |
| 血契连接距离 | 已连接最大距离300→270；起手220、预警结束235、超距连续0.12秒断链不变；每跳76%、收束90%回血不变 |
| 普通护盾存续 | 普通时间领域不再延长盾的存续期限；护盾技能CD仍按原冷却速率减速。完全失魂/强制静止继续冻结盾计时；王城专盾规则不改 |
| 神圣球失魂 | 核实既有实现：天使剑枪攻击、投枪动作进程及守护CD一同停止，不独立继续输出 |
| 麻痹削伤 | 普通身体碰撞保留每层8%；强化重击、冲刺/高速冲撞、回旋重斩、普通光刃、恶魔爪击/降临双爪、天使近战剑枪按每层4%。进化麻痹使用真实层权重，只计算一次 |
| 麻痹边界 | 上述削伤不因冲刺或普通霸体而消失，不因此改变原有运动免控。远程弹丸、飞行回旋刃、激光炮、投掷钉子、DOT、真伤及奥义攻击不新增此项削伤 |
| 普通光刃与回旋刃 | 普通热切光刃不销毁飞行回旋刃，不虚报丢刃或改变回收计数；奥义巨刃仍按已有规则切除。其他可清理弹丸、陷阱规则保留 |
| 时间减速与瞄准 | 有限速跟瞄按角色动作时间降速，可移动瞄准窗口按同一时间比例延长。加速冲刺、反伤弹、飞行时钟改为独立锁线期限，与已有激光、狙击的方式一致；锁定后不重新追踪 |

普通时间领域的动作速率20%意味着跟瞄角速度约为原来的20%、可跟瞄窗口约为5倍。冷却速率仍为原80%，不是把技能CD也改成5倍。退出领域后的剩余阶段恢复正常速率，不额外补偿一次瞄准。

常规改动通过共用系统覆盖经典、团队、独立奥义和手动入口，保留手动输入与AI归属。没有把原本直接指定方向、位置或瞬时锁定的技能统一改造成新的跟瞄技能。
