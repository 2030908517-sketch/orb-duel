# 本轮五档对阵关系统计

沿用390局结果，终局剩血≥13%算碾压，不重新对战。

- 明显优势：5局全胜，或己方碾压对手至少3局。
- 较大优势：未达到明显优势，但赢了4局。
- 均势：双方均未达到优势阈值。
- 较大劣势：对手对己方有较大优势。
- 明显劣势：对手对己方有明显优势。

明显优先，同一方向只归一档。均势仅表示本轮五局双方未达到优势阈值，不代表已经证明长期平衡。
