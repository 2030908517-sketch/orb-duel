# 2026-11-03：11组明显优势的定向调整研究

状态：研究与隔离试算，**未采纳、未修改正式游戏代码**。基线为[第四轮调整后780局](2026-11-03-arcana-10-post4/index.html)，源码快照 `5792e22645d99ebe83aef2a67a1f398004e63bcc28c58376e47c676f4382e88b`。胜率不含平局；明显优势仍按9～10胜或至少6次碾压判定。

## 边界

保留其他角色的通用参数，与保证其他所有对阵胜负不变，是两件事。通用链长、回血、CD等会影响该角色的多个对手；只有显式限定的对阵修正才能严格限制到指定组合。具体技能交互可以显著缩小波及范围，但同类仆从、团队或后续新机制也可能复用它，不能提前承诺零影响。

当前存在“时间→激光→回旋→毒液→时间”的明显优势闭环。整体加减某角色血量/伤害，容易加剧其另一端的优势或劣势，应优先处理具体交互。

观察摘要：

- 吸血对普通的两局，吸血实际平均恢复约124.8，平均5.5次血契中4.5次完整汲取。与此前同种子的比较中，这两组参与角色唯一相关的新增玩法变量是链长260→300：吸血对普通由6胜2负2平变成10胜，对恶魔由8胜变成9胜。
- 护盾对时间的两局，护盾平均吸收约109。`Temporal` 的计时表含 `shieldUntil`，而该字段按运动/施法减速率推迟，意味着普通时间场会延长敌方护盾持续时间；护盾CD本身则按80%速率推进。这是需要单独讨论的交互，不直接判为已经确认的程序错误。
- 激光对回旋的两局，主炮平均约141.6实伤，普通光刃与奥义光刃合计平均拆掉3把回旋刃；两局主炮分别7发、8发全部有记账命中。不能把优势完全归因于拆刃，但拆刃消融试验有明显效果。
- 时间对激光的两局，激光也打出平均7.5发主炮，但主炮实伤平均约85.4，并有较多免疫抵消。领域减速、沉默、时删避伤共同存在，不能简化成“激光完全充不出炮”。
- 时间对神圣的两局，神圣受约8.7秒普通沉默，天使圣枪每局只形成一次实伤命中；普通控制、招式重启、场地位置与觉醒圣裁输出均需分开研究。
- 神圣对陷阱的两局，圣火平均清掉3.5枚普通节点，净世平均另清1枚；未观察到这两种清场删除已标记节点。9次胜局中有4次终局剩血不足5%，并非每局大幅压制。
- 回旋对毒液的两局，普通/奥义飞刃平均99.8实伤、重斩87.2；普通身体约39.8。当前麻痹对普通身体伤害的削弱不覆盖这套武器伤害。
- 加速对毒液是7胜3负，6次碾压决定了分类；其胜局平均剩血15.9%，相对13%门槛只高2.9个百分点。应避免仅为消除标签而大幅削弱加速。
- 毒液对时间两局的毒伤平均约177，占主要伤害来源；10局中只有一次碾压，4次胜局终局不足5%HP。新回溯已经清除毒层及附着效果，回放没有证明这是旧毒残留导致的胜负。
- 补采中，吸血在恶魔仆从身上取得过约3及16.4的请求回血量；这不是实际净治疗的精确分摊，不能全部当成额外实收回血。神圣对仆从的伤害主要来自身体接触/圣水，未在这4局看到圣枪被仆从吸走，不能将此当成已经观察到的主要原因。

## 建议顺序及影响范围

1. **优先讨论时间场与普通护盾存续计时。** 改为世界时间消退，保留护盾CD减速、伤害与阈值冲击波。范围主要是护盾与时间场的交互，也要检查团队和拥有同类基础能力的仆从。
2. **优先讨论普通切弹与可回收主武器的区别。** 已试“普通光刃不销毁回旋刃”，效果明确。若改成“被挡回/强制返航”，则属于另一种尚未试验的实现，不能套用上表6胜4负结果。奥义级切断仍保留。主要涉及激光/回旋，仆从复用也是边界。
3. **血契270有依据，但属于通用参数，不能承诺其余吸血对阵不变。** 若要求更严格的局部性，可另试“重击/较长穿刺控制打断普通血契”的交互，让普通和恶魔获得反制；此方案没有实现或验证，不等同于270试算。
4. **时间→激光：电容续充不足以解决。** 可继续研究锁线完成后的最后放电预警是否仍应被普通时间场拖为五倍，以及主炮AI是否可利用时删冷却窗口。保留沉默与完全静止的限制；这些方案尚未试验，不能直接确定数值。
5. **神圣涉及三组明显关系，应先核对既定设计执行。** 当前 `HolyThrow` 对阵内带印目标回退为近战保证命中，而非此前要求的一次15伤投枪后该天使停攻；`HolyThrow.hit` 的投枪仍对灼伤加2秒。应先确认并修正这些与此前要求的差异，再评估整体参数。独立天使/已经投放的圣裁是否继续按世界时钟行动，是可讨论的控制边界，不应以“修bug”名义未经确认改变。
6. **加速/回旋→毒液：优先考虑麻痹与特殊近战的交互，不增加毒液总毒伤。** 例如让麻痹对高速身体冲撞、普通接刃重斩产生半幅的出力削弱，先从每层约4%试起，保留奥义豁免、冲刺无敌及速度规则。当前代码刻意排除了若干特殊攻击，改变它是新的设计决定，不是已确认缺陷；未试验。
7. **毒液→时间：目前没有验证出符合“其他对阵零变化”的通用改法。** 不应削弱毒液全局来处理一个多数险胜的对阵，否则可能加剧毒液对加速/回旋的劣势。时间对持续伤害是否增加有限反制，或采用透明的局部对阵修正，需要创作者选择；不擅自新增免毒或改变时删禁止由DOT触发的规则。

## 下一步的最小验证

先决定上述交互是否符合角色设计，再实施获准部分。只检查受影响对阵及相邻复用路径；通用血契参数还需检查吸血的其他对手。用未参与本次选择的新种子作留出检验，逐项记录是否新产生明显优势/劣势。若严格要求其他组合逐位不变，只能接受明确的对阵特定调整，并限定相应模式；不能把通用机制调整宣称为严格隔离。
