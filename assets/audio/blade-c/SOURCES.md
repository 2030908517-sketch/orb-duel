# Blade audio C sources and processing

StarNinjas — 20 Sword Sound Effects (Attacks and Clashes)
https://opengameart.org/content/20-sword-sound-effects-attacks-and-clashes
License on source page: CC0 1.0 https://creativecommons.org/publicdomain/zero/1.0/
Author describes moving two knives against each other, followed by Audacity editing.
Used sword.4 (throw), sword.1 (return), sword.6 (returnHit), sword.8 (moonCut).

CYBERDEViL — Machete vs. Spatula
https://opengameart.org/content/machete-vs-spatula
License on source page: CC0 1.0.
Author describes raw recordings of a spatula striking a machete.
File machete_vs_spatula_1.wav used to estimate metallic modal frequencies and damping; small modal resynthesis contribution, not a claim that the result is a pure recording.

Derivatives by ORB DUEL: trimmed, pitch/speed adjusted, time-frequency texture separation, measured modal supplement, edge fades, offline 24kHz PCM export. Original downloads remain in the development workspace. All four derivatives are CC0-compatible; this credit is retained for provenance.
No commercial game audio extracted. A and B remain available; C awaits listening approval.
